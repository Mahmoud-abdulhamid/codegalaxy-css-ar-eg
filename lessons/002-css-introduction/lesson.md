# مقدمة في CSS

المصدر: https://www.w3schools.com/css/css_intro.asp

## ما هي CSS؟

تعد CSS اللغة الأساسية المستخدمة لتصميم وتنسيق صفحات الويب.

- CSS هي اختصار لـ Cascading Style Sheets
- تستخدم للتحكم في مظهر صفحات الويب
- تضيف الألوان والخطوط والتخطيطات

## لماذا نستخدم CSS؟

تساعد CSS في تحديد التصميم والتخطيط وتكييف المحتوى مع مختلف الشاشات.

- التحكم في التصميم والخطوط
- تنسيق التخطيط العام للصفحة
- التوافق مع مختلف أحجام الشاشات

## هيكلية CSS الأساسية

تتكون قواعد CSS من Selector وخصائص وقيم داخل أقواس.

```css
body {
  background-color: lightblue;
}
```

## تنسيق النصوص

يمكن تنسيق العناوين h1 بسهولة عبر تحديد اللون والمحاذاة.

```css
h1 {
  color: white;
  text-align: center;
}
```

## تنسيق الفقرات

نستخدم font-family و font-size لتنسيق الفقرات النصية.

```css
p {
  font-family: verdana;
  font-size: 20px;
}
```

## كفاءة CSS

استخدام ملفات CSS خارجية يسهل إدارة وتحديث تصميم الموقع بالكامل.

- حفظ التنسيقات في ملف .css خارجي
- تغيير مظهر الموقع بالكامل من ملف واحد
- تقليل التكرار في الكود البرمجي

## خاتمة

جربوا الأكواد بأنفسكم لتطوير مهاراتكم في تصميم الويب.

- CSS هي أداة قوية لكل مطور ويب
- مارسوا كتابة الأكواد بانتظام
- راجعوا الرابط في الوصف للتطبيق العملي
