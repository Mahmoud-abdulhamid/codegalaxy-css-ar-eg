# طرق إضافة CSS إلى صفحات الويب

المصدر: https://www.w3schools.com/css/css_howto.asp

## مقدمة حول إضافة CSS

عندما يقرأ Web Browser ملف التنسيقات، فإنه يهيكل صفحة HTML بناء على هذه التعليمات. هناك ثلاث طرق لإدراج التنسيقات.

- تستخدم CSS لتنسيق صفحات الويب
- يقرأ Web Browser ملفات التنسيق لتشكيل الصفحة
- توجد ثلاث طرق لإضافة CSS إلى HTML

## مفهوم External CSS

باستخدام External CSS يمكنك تغيير مظهر موقع الويب بالكامل عبر تعديل ملف واحد فقط. يجب ربط كل صفحة HTML بهذا الملف داخل عنصر link في قسم head.

- تغيير مظهر الموقع بالكامل من ملف واحد
- يتم الربط باستخدام عنصر <link>
- يجب وضع عنصر <link> داخل قسم <head>

## كود ربط ملف CSS

نستخدم <!DOCTYPE html> لتعريف نوع المستند. داخل قسم <head> نكتب <link> مع Attributes rel و href لتحديد مسار ملف mystyle.css.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="mystyle.css">
  </head>
  <body>
    <h1>This is a heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## محتوى ملف mystyle.css

ملف CSS يجب أن يحفظ بامتداد .css ولا يحتوي على أي HTML Tags. هنا نحدد لون خلفية <body> وتنسيقات <h1>. تذكر ألا تضع مسافة بين القيمة والوحدة مثل 20px.

```css
body {
  background-color: lightblue;
}
h1 {
  color: navy;
  margin-left: 20px;
}
```

## أفضل الممارسات

من الضروري الانتباه للتفاصيل. عند كتابة Property Value، لا تضع مسافة بين الرقم والوحدة. مثال خاطئ هو 20 px، والصواب هو 20px.

## خلاصة الدرس

تعلمنا اليوم كيفية ربط ملفات CSS خارجيا بصفحة HTML. هذه الطريقة هي الأفضل لإدارة مواقع الويب. أدعوكم لتجربة هذه الأكواد بأنفسكم عبر الرابط الموجود في وصف الفيديو.

- استخدام External CSS يسهل صيانة الموقع
- يتم الربط عبر عنصر <link> في <head>
- تأكد من عدم وجود مسافات بين القيم والوحدات
- قم بزيارة الرابط في الوصف للتطبيق العملي
