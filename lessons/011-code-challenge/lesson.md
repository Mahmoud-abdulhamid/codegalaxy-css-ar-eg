# CSS How To Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_howto.asp

## مقدمة في تحدي CSS

مرحبا بكم في درس تحدي CSS العملي لاختبار مهاراتكم في تنسيق صفحات الويب.

- مراجعة طرق إضافة CSS
- تطبيق التحدي البرمجي
- تعزيز الفهم العملي

## طرق إضافة CSS

تتعدد طرق إضافة CSS إلى صفحات الويب بين External و Internal و Inline CSS.

- External CSS باستخدام ملف خارجي
- Internal CSS داخل قسم head
- Inline CSS داخل العناصر مباشرة

## هيكل التحدي البرمجي

نبدأ التحدي بتجهيز هيكل HTML والتركيز على كيفية دمج CSS.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>CSS Challenge</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>
```

## تطبيق التنسيق

تطبيق تنسيق CSS على عنصر h1 باستخدام خاصية color.

```css
h1 {
  color: blue;
  text-align: center;
}
```

## أفضل الممارسات

يعد فصل CSS في ملف خارجي من أفضل الممارسات البرمجية.

- استخدام ملفات CSS خارجية
- تنظيم الكود وتنسيقه
- تحسين سرعة تحميل الصفحة

## خلاصة التحدي

شكرا لمتابعتكم، جربوا الأكواد بأنفسكم عبر الرابط في الوصف.

- راجعوا التحدي عبر الرابط
- طبقوا الأكواد عمليا
- استعدوا للدرس القادم
