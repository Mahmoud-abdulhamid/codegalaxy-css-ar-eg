# CSS Comments

المصدر: https://www.w3schools.com/css/css_comments.asp

## مقدمة حول CSS Comments

تستخدم Comments لشرح كود CSS وتسهيل صيانته وتعديله لاحقا.

- تساعد Comments في توثيق الكود البرمجي
- تسهل عملية فهم الكود عند العودة إليه لاحقا
- تجاهل تام من قبل Web Browser
- تستخدم لتعطيل أجزاء من الكود مؤقتا

## بناء جملة التعليقات

يبدأ تعليق CSS بالرمز /* وينتهي بالرمز */.

```css
/* هذا تعليق سطر واحد */
p {
  color: red;
}
```

## التعليقات داخل الأسطر

يمكن وضع التعليقات في أي مكان داخل الكود، حتى في منتصف السطر.

```css
p {
  color: red;
  /* تحديد لون النص */
}
```

## التعليقات متعددة الأسطر

يمكن للتعليقات أن تمتد عبر عدة أسطر لتغطية شروحات مفصلة.

```css
/* هذا تعليق
   يمتد لعدة أسطر
   في ملف الـ CSS */
p {
  color: red;
}
```

## الدمج بين HTML و CSS

تستخدم HTML تعليقات <!-- --> بينما تستخدم CSS تعليقات /* */.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <style>
      p {
        color: red; /* تعليق CSS */
      }
    </style>
  </head>
  <body>
    <!-- تعليق HTML -->
    <p>Hello World!</p>
  </body>
</html>
```

## خلاصة الدرس

استخدم التعليقات بانتظام لجعل الكود أكثر احترافية وسهولة في الصيانة.

- CSS Comments تبدأ بـ /* وتنتهي بـ */
- HTML Comments تبدأ بـ <!-- وتنتهي بـ -->
- التعليقات لا تظهر في Web Browser
- استخدم التعليقات لتوثيق الكود وتعطيله مؤقتا
