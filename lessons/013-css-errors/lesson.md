# تجنب أخطاء CSS الشائعة

المصدر: https://www.w3schools.com/css/css_errors.asp

## مقدمة حول أخطاء CSS

مرحبا بكم في درس تجنب أخطاء CSS الشائعة التي قد تؤدي إلى سلوك غير متوقع في صفحات الويب.

- الأخطاء البرمجية تؤدي لسلوك غير متوقع
- فهم الأخطاء يساعد في كتابة كود احترافي
- تجنب الأخطاء يضمن تطبيق التنسيقات بدقة

## مشكلة الفواصل المنقوطة

نسيان Semicolon في نهاية Property Declaration يؤدي إلى كسر قاعدة التنسيق.

```css
.bad {
  color: red
  background-color: yellow;
}
```

## أسماء الخصائص غير الصحيحة

المتصفح يتجاهل أي Property غير موجودة، لذا يجب التأكد من صحة الأسماء.

```css
.bad {
  colr: blue;
  font-size: 16px;
}
```

## القيم غير الصالحة

القيم غير الصالحة تؤدي إلى تجاهل السطر البرمجي من قبل المتصفح.

```css
.bad {
  width: -100px;
  color: green;
}
```

## الأقواس غير المغلقة

عدم إغلاق الأقواس Braces يؤدي إلى تجاهل قاعدة التنسيق بالكامل.

```css
.bad {
  padding: 20px;
  margin: 10px;
}
```

## الأخطاء المطبعية

الأخطاء المطبعية مثل تكرار النقطتين تؤدي إلى كسر قواعد CSS.

```css
.bad {
  color:: blue;
}
```

## خلاصة الدرس

تجنب الأخطاء الشائعة يضمن استقرار وتنسيق صفحات الويب بشكل احترافي.

- استخدم Semicolon دائما
- تحقق من أسماء الخصائص
- تأكد من صحة القيم
- أغلق الأقواس دائما
