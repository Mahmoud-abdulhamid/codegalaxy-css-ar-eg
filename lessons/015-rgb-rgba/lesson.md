# CSS RGB and RGBA Colors

المصدر: https://www.w3schools.com/css/css_colors_rgb.asp

## مقدمة في ألوان RGB

مرحبا بكم في درس CSS الجديد حول استخدام نظام الألوان RGB و RGBA لتصميم صفحات الويب.

- نظام RGB يمثل مصادر الضوء الأحمر والأخضر والأزرق
- يستخدم CSS هذه القيم لتحديد ألوان العناصر
- نظام RGBA يضيف قناة الشفافية Alpha

## فهم صيغة RGB

تعتمد صيغة RGB على ثلاث قيم تتراوح بين 0 و 255 لتحديد شدة اللون الأحمر والأخضر والأزرق.

```css
/* الصيغة العامة */
rgb(red, green, blue);
/* مثال للون الأحمر */
rgb(255, 0, 0);
```

## أمثلة على قيم RGB

توضيح قيم RGB للحصول على الألوان الأساسية مثل الأحمر والأسود والأبيض.

## مفهوم RGBA والشفافية

قناة Alpha في RGBA تتحكم في شفافية اللون بقيم تتراوح من 0.0 إلى 1.0.

```css
/* الصيغة العامة لـ RGBA */
rgba(red, green, blue, alpha);
/* مثال للون شفاف */
rgba(255, 0, 0, 0.5);
```

## شرح قيم Alpha

تأثير قيمة Alpha على شفافية العناصر في تصميم الويب.

- 0.0: شفاف تماما
- 0.5: شفافية متوسطة
- 1.0: غير شفاف إطلاقا

## خلاصة الدرس

خلاصة: استخدم RGB للألوان الثابتة و RGBA للتحكم في الشفافية في تصميماتك.

- RGB يحدد شدة الضوء الأحمر والأخضر والأزرق
- RGBA يضيف قناة الشفافية Alpha
- استخدم القيم بين 0 و 255 للألوان
- استخدم القيم بين 0.0 و 1.0 للشفافية
