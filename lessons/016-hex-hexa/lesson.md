# CSS HEX and HEXA Colors

المصدر: https://www.w3schools.com/css/css_colors_hex.asp

## مقدمة عن الألوان في CSS

تعتبر HEX values من أكثر الطرق شيوعا لتحديد الألوان في CSS.

- تحديد الألوان باستخدام نظام Hexadecimal
- استخدام الصيغة #RRGGBB
- التحكم في قيم الأحمر والأخضر والأزرق

## هيكلية HEX Value

تتكون صيغة HEX من #RRGGBB حيث تمثل كل خانتين لونا أساسيا.

- مفهوم RR: Red (00-ff)
- مفهوم GG: Green (00-ff)
- مفهوم BB: Blue (00-ff)
- مثال: #ff0000 يمثل اللون الأحمر الخالص

## الاختصار المكون من 3 أرقام

الاختصار المكون من 3 أرقام هو صيغة مبسطة لبعض قيم HEX.

- يستخدم عندما تكون قيم R و G و B متطابقة
- مثال: #ff00ff يصبح #f0f
- مثال: #bb5588 يصبح #b58

## تطبيق عملي في CSS

تطبيق قيم HEX المختصرة على عناصر HTML.

```css
body {
  background-color: #fc9;
}
h1 {
  color: #f0f;
}
p {
  color: #b58;
}
```

## مفهوم HEXA Value

تضيف HEXA قناة Alpha للتحكم في شفافية اللون.

- الصيغة: #rrggbbaa
- aa: Alpha channel للشفافية
- 00: شفاف تماما
- ff: غير شفاف تماما

## أفضل الممارسات

استخدم HEXA عند الحاجة للشفافية وHEX للألوان الصلبة.

- استخدم أدوات اختيار الألوان عبر الإنترنت
- حافظ على تباين جيد بين النص والخلفية
- جرب قيم Alpha المختلفة للحصول على تأثيرات مميزة
