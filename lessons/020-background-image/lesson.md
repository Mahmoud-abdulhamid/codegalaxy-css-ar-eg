# التحكم في خلفيات العناصر باستخدام CSS background-image

المصدر: https://www.w3schools.com/css/css_background_image.asp

## مقدمة حول background-image

مرحبا بكم في درس جديد حول استخدام خاصية background-image في CSS لتحسين مظهر صفحات الويب.

- خاصية background-image تضيف صورة كخلفية للعنصر
- تعتبر أداة قوية لتصميم واجهات الويب
- تؤثر بشكل مباشر على تجربة المستخدم البصرية

## مفاهيم أساسية في خلفيات CSS

يجب الانتباه إلى أن المتصفح يكرر الصورة افتراضيا، لذا اختر صورا لا تعيق قراءة النصوص.

- السلوك الافتراضي هو تكرار الصورة
- يجب مراعاة تباين النص مع الخلفية
- تجنب الصور المزدحمة التي تشتت الانتباه

## تطبيق الصورة على عنصر body

تطبيق صورة خلفية على كامل صفحة الويب باستخدام محدد body.

```css
body {
  background-image: url("paper.gif");
}
```

## تطبيق الصورة على عناصر محددة

يمكن تطبيق خاصية background-image على عناصر محددة مثل الفقرات p.

```css
p {
  background-image: url("paper.gif");
}
```

## أفضل الممارسات في التصميم

اختر صورا هادئة لضمان سهولة قراءة النصوص وتجنب التداخل البصري.

- استخدم صورا ذات تباين مناسب
- اختبر سهولة قراءة النص فوق الخلفية
- تجنب الصور التي تشتت المستخدم

## خلاصة الدرس

تعلمنا اليوم كيفية استخدام background-image. جربوا الأكواد بأنفسكم عبر الرابط في الوصف.

- تم شرح خاصية background-image
- تم تطبيقها على body و p
- تم التأكيد على أهمية وضوح النص
- شجعنا على التطبيق العملي
