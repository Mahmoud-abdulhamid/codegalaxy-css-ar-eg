# CSS Backgrounds Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_background.asp

## مقدمة في تحدي CSS Backgrounds

مرحبا بكم في درس تحدي CSS Backgrounds لتطبيق مهارات تصميم خلفيات عناصر الويب.

- التعرف على خصائص Background في CSS
- تطبيق التحديات البرمجية لتعزيز الفهم
- تحسين مظهر صفحات الويب عبر الخلفيات

## المفاهيم الأساسية للخلفيات

تعد خصائص Background أساسية في CSS مثل background-color و background-image و background-repeat.

- background-color: تحديد لون الخلفية
- background-image: إضافة صورة للخلفية
- background-repeat: التحكم في تكرار الصورة
- background-position: تحديد موقع الصورة

## كتابة كود الخلفية

نبدأ بتحديد Selector مثل body وتطبيق خصائص Background داخل أقواس التنسيق.

```css
body {
  background-color: lightblue;
  background-image: url('bg.jpg');
  background-repeat: no-repeat;
}
```

## شرح تفصيلي للخصائص

شرح الخصائص: background-color للون، background-image للصورة، و background-repeat لمنع التكرار.

- background-color: يحدد لون خلفية العنصر
- url('bg.jpg'): مسار الصورة المستخدمة
- no-repeat: يمنع تكرار الصورة في الصفحة

## استخدام Background Shorthand

يمكن اختصار خصائص الخلفية في سطر واحد باستخدام خاصية background لجعل الكود أكثر نظافة.

```css
body {
  background: lightblue url('bg.jpg') no-repeat;
}
```

## أفضل الممارسات البرمجية

أفضل الممارسات: اختيار صور مناسبة الحجم وتحديد لون خلفية احتياطي لضمان تجربة مستخدم جيدة.

- تحسين حجم الصور لسرعة التحميل
- توفير لون احتياطي background-color
- استخدام Shorthand لتنظيم الكود

## خلاصة الدرس

خلاصة: تعلمنا التحكم في الخلفيات واختصار الأكواد. جربوا الأكواد بأنفسكم عبر الرابط في الوصف.

- تمت تغطية خصائص Background
- تم شرح استخدام Shorthand
- تم التأكيد على أفضل الممارسات
