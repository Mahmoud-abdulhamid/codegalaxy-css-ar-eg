# CSS Border Sides

المصدر: https://www.w3schools.com/css/css_border_sides.asp

## مقدمة في CSS Border Sides

مرحبا بكم في درس التحكم في جوانب الـ border بشكل مستقل باستخدام CSS.

- التحكم في كل جانب من جوانب الـ border على حدة
- استخدام الخصائص الفردية لكل اتجاه
- تطبيق الاختصارات لتنظيم الكود
- تطبيق المفاهيم على الـ width والـ color

## الخصائص الفردية للـ border

نستخدم الخصائص الفردية للتحكم في كل جانب من جوانب الـ border.

## تطبيق الخصائص الفردية

مثال برمجي يوضح استخدام الخصائص الفردية للـ border.

```css
p {
  border-top-style: dotted;
  border-right-style: solid;
  border-bottom-style: dotted;
  border-left-style: solid;
}
```

## مفهوم الاختصار في border-style

استخدام border-style كاختصار لتحديد أنماط الجوانب الأربعة.

- قيمة واحدة: تطبق على جميع الجوانب
- قيمتان: الأولى للأعلى والأسفل، الثانية لليمين واليسار
- ثلاث قيم: الأعلى، اليمين واليسار، ثم الأسفل
- أربع قيم: الأعلى، اليمين، الأسفل، ثم اليسار

## أمثلة على قيم border-style

مثال يوضح استخدام قيمتين داخل خاصية border-style.

```css
p {
  border-style: dotted solid;
}
```

## تعدد القيم في الاختصارات

تطبيق مفهوم تعدد القيم على خصائص العرض واللون للـ border.

```css
/* أربع قيم */
p { border-style: dotted solid double dashed; }
/* ثلاث قيم */
p { border-style: dotted solid double; }
```

## خلاصة الدرس

خلاصة: التحكم في جوانب الـ border يمنحك مرونة عالية في التصميم.

- استخدم الخصائص الفردية للدقة العالية
- استخدم الاختصارات لتقليل حجم الكود
- تذكر ترتيب القيم: الأعلى، اليمين، الأسفل، اليسار
- طبق نفس المنطق على border-width و border-color
