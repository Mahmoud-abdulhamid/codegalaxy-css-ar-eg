# CSS Shorthand Border Property

المصدر: https://www.w3schools.com/css/css_border_shorthand.asp

## مقدمة في CSS Shorthand

مرحبا بكم في درس CSS Shorthand Border Property، سنتعلم اليوم اختصار خصائص الحدود.

- التعامل مع الحدود في CSS
- مشكلة تعدد الخصائص للحدود
- مفهوم Shorthand Property
- تحسين جودة الكود البرمجي

## مفهوم Shorthand Property

بدلا من كتابة خصائص الحدود بشكل منفصل، نستخدم border لدمجها في سطر واحد.

- border-width: سماكة الحد
- border-style: نمط الحد
- border-color: لون الحد
- دمج الكل في border

## تطبيق خاصية border

مثال على استخدام خاصية border المختصرة لتحديد السماكة والنمط واللون.

```css
p {
  border: 5px solid red;
}
```

## تحديد جانب واحد

يمكننا أيضا تطبيق الحدود على جانب واحد فقط باستخدام border-left.

```css
p {
  border-left: 6px solid red;
}
```

## تحديد الحافة السفلية

استخدام border-bottom لإضافة حد في الأسفل فقط.

```css
p {
  border-bottom: 6px solid red;
}
```

## خلاصة الدرس

خلاصة: تعلمنا اختصار الحدود وتطبيقها على جوانب محددة. جرب الأكواد بنفسك!

- تمت تغطية border المختصرة
- تم شرح border-left و border-bottom
