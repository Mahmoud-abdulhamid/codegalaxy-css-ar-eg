# CSS Borders Challenge

المصدر: https://www.w3schools.com/css/css_challenges_border.asp

## مقدمة في تحدي الـ Borders

مرحبا بكم في تحدي CSS Borders. سنقوم اليوم باختبار مهاراتكم في تنسيق حدود العناصر.

- أهمية الـ Borders في تصميم الـ Web
- استعراض تحدي البرمجة الخاص بـ CSS
- تطبيق عملي للخصائص الأساسية

## مفاهيم الـ Borders الأساسية

تتطلب خاصية border تحديد العرض، النمط، واللون لضمان ظهور الحدود بشكل صحيح.

## كود الـ CSS المبدئي

نبدأ بتطبيق خاصية border-style على العنصر المستهدف داخل ملف الـ CSS.

```css
div {
  border-style: solid;
  border-width: 5px;
  border-color: blue;
}
```

## شرح تفصيلي للخصائص

شرح الخصائص: border-style يحدد النمط، border-width يحدد السمك، وborder-color يحدد اللون.

- solid: إطار متصل
- dashed: إطار متقطع
- dotted: إطار منقط
- border-width: يتحكم في سماكة الإطار
- border-color: يحدد لون الإطار

## المعاينة المرئية

يظهر العنصر في المتصفح بإطار أزرق سميك ومحدد بوضوح.

```html
<div style="border: 5px solid blue;">
  هذا عنصر يحتوي على Border
</div>
```

## أفضل الممارسات

استخدام الاختصار border: 5px solid blue يقلل من تكرار الكود ويزيد من كفاءته.

```css
/* الطريقة المختصرة */
div {
  border: 5px solid blue;
}
```

- طبقوا الكود المختصر
