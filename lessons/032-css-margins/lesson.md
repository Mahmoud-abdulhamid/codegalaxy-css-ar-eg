# التحكم في المسافات الخارجية باستخدام CSS Margins

المصدر: https://www.w3schools.com/css/css_margin.asp

## مقدمة حول CSS Margins

تستخدم خاصية margin في CSS لإنشاء مسافات خارجية حول العناصر خارج حدود الـ border.

- تحدد margin المسافة بين حدود العنصر والعناصر المحيطة
- توفر CSS تحكما كاملا في المسافات لكل جانب
- يمكن ضبط المسافات للجهات الأربع بشكل منفصل أو مختصر

## تحديد المسافات لكل جانب

يمكن تحديد المسافات لكل جانب من جوانب العنصر الأربعة بشكل منفصل.

```css
p {
  margin-top: 100px;
  margin-bottom: 100px;
  margin-right: 150px;
  margin-left: 80px;
}
```

## خاصية الاختصار margin

تسمح خاصية الاختصار margin بتحديد المسافات الأربعة في سطر واحد.

```css
p {
  margin: 25px 50px 75px 100px;
}
```

## تنوع قيم الاختصار

تتغير دلالة القيم في خاصية margin بناء على عدد القيم المدخلة.

```css
p {
  margin: 25px 50px 75px; /* 3 قيم */
  margin: 25px 50px; /* قيمتان */
  margin: 25px; /* قيمة واحدة */
}
```

## استخدام القيمة auto

تستخدم القيمة auto لتوسيط العناصر أفقيا داخل الحاوية.

```css
div {
  width: 300px;
  margin: auto;
  border: 1px solid red;
}
```

## استخدام القيمة inherit

تسمح القيمة inherit للعنصر بوراثة قيمة margin من العنصر الأب.

```css
div {
  margin-left: 100px;
}
p.ex1 {
  margin-left: inherit;
}
```

## خلاصة الدرس

مارسوا كتابة الأكواد لتتقنوا التحكم في المسافات وتصميم صفحات الويب.

- استخدم margin للتحكم في المسافات الخارجية
- جرب خاصية الاختصار لتقليل حجم الكود
- استخدم auto للتوسيط و inherit للوراثة
- راجع الرابط في الوصف لمزيد من التمارين
