# CSS Margin Collapse

المصدر: https://www.w3schools.com/css/css_margin_collapse.asp

## مقدمة حول Margin Collapse

مفهوم Margin Collapse هو ظاهرة دمج الهوامش الرأسية لعنصرين متجاورين في هامش واحد.

- Margin Collapse يحدث للهوامش الرأسية فقط
- يتم دمج الهامشين في هامش واحد يساوي الأكبر بينهما
- لا يؤثر هذا المفهوم على الهوامش الأفقية

## قواعد دمج الهوامش

قاعدة ذهبية: Margin Collapse يقتصر على الهوامش الرأسية (Top و Bottom) ولا يشمل الهوامش الأفقية.

## مثال عملي على h1 و h2

في هذا المثال، يتم دمج الهوامش لتكون النتيجة هي القيمة الأكبر (50px) بدلا من مجموع الهامشين.

```css
h1 {
  margin-bottom: 50px;
}
h2 {
  margin-top: 20px;
}
```

## تحليل النتيجة

المتصفح يختار القيمة الأكبر بين الهامشين المتجاورين لضمان عدم تضاعف المسافات بشكل غير مقصود.

- المسافة المتوقعة: 70px
- المسافة الفعلية: 50px
- السبب: Margin Collapse يختار القيمة الأكبر

## مثال على عناصر p

تطبيق Margin Collapse على عناصر الفقرات p حيث يتم دمج الهوامش المتجاورة.

```css
p {
  margin-top: 30px;
  margin-bottom: 30px;
}
```

## أفضل الممارسات

يجب مراعاة سلوك Margin Collapse عند تحديد المسافات بين العناصر لتجنب نتائج غير متوقعة في التصميم.

- خطط للمسافات مع مراعاة دمج الهوامش
- استخدم Padding كبديل إذا كنت لا تريد دمج الهوامش
- اختبر التصميم في Web Browser للتأكد من المسافات

## خلاصة الدرس

Margin Collapse هو جزء أساسي من نموذج الصندوق في CSS. جرب الأكواد بنفسك لتتقن التحكم في المسافات.

- Margin Collapse يدمج الهوامش الرأسية
- يتم اختيار القيمة الأكبر دائما
- لا يؤثر على الهوامش الأفقية
- مهم جدا لتنسيق صفحات الويب
