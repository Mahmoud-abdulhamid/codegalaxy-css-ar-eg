# CSS Margins Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_margin.asp

## مقدمة في تحدي الـ Margins

مرحبا بكم في درس تحدي الـ CSS Margins، حيث سنقوم بتطبيق المفاهيم البرمجية عمليا.

- التعرف على أهمية الـ Margin في CSS
- تطبيق التحدي البرمجي الخاص بالمسافات الخارجية
- تحسين مهارات التنسيق في صفحات الويب

## مفهوم الـ Margin في CSS

تستخدم خاصية margin لإنشاء مسافات خارجية حول الـ Elements، مما يساعد في تنظيم التخطيط.

- الـ Margin يقع خارج حدود الـ Element
- يؤثر على المسافة بين العناصر المتجاورة
- يمكن التحكم في كل اتجاه على حدة

## كود التحدي البرمجي

نستخدم الـ Selector مع خاصية margin لتحديد المسافات الخارجية المطلوبة.

```css
div {
  margin: 20px;
  border: 1px solid black;
}

p {
  margin-top: 10px;
}
```

## شرح تفصيلي للـ Syntax

شرح تطبيق الـ margin على الـ div والـ p للتحكم في المسافات بدقة.

- margin: 20px يطبق المسافة على جميع الجهات
- margin-top يحدد المسافة العلوية فقط
- استخدام الـ pixels كوحدة قياس أساسية

## المعاينة المرئية

تظهر المعاينة المرئية المسافات المطبقة التي تمنح التصميم مظهرا احترافيا.

```html
<div>
  <p>هذا العنصر يحتوي على margin</p>
</div>
```

## أفضل الممارسات

أفضل الممارسات: حافظ على تناسق قيم الـ margin لضمان تصميم متوازن.

- استخدم قيم margin متناسقة
- اختبر التصميم على مختلف أحجام الشاشات
- تجنب المسافات المفرطة

## خلاصة الدرس

خلاصة: لقد أتقنا التحكم في الـ margin. جربوا الأكواد بأنفسكم عبر الرابط في الوصف.

- تمت تغطية مفاهيم الـ margin
- تم حل التحدي البرمجي بنجاح
- استمروا في الممارسة لتطوير مهاراتكم
