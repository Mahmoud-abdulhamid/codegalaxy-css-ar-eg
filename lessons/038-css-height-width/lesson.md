# CSS Height and Width

المصدر: https://www.w3schools.com/css/css_height_width.asp

## مقدمة عن CSS Height and Width

مرحبا بكم في درس CSS Height and Width لتحديد أبعاد عناصر الويب.

- تستخدم لغة CSS لتنسيق صفحات الويب
- نحدد الطول والعرض باستخدام height و width
- نتعلم التحكم الكامل في أبعاد العناصر

## القواعد الأساسية للأبعاد

تحدد خصائص height و width أبعاد العنصر الداخلية بعيدا عن الحواف والهوامش.

- height يحدد ارتفاع العنصر
- width يحدد عرض العنصر
- لا تتضمن المساحات الداخلية والحواف

## كتابة الكود البرمجي الأول

تطبيق خصائص الارتفاع والعرض مع لون خلفية على عنصر div.

```css
div {
  height: 200px;
  width: 50%;
  background-color: powderblue;
}
```

## شرح تفصيلي للقيم

استخدام وحدات القياس المختلفة مثل البكسل والنسب المئوية.

- وحدة px للبكسل الثابت
- وحدة للنسب المئوية المرنة
- تحسين تجربة التجاوب مع الشاشات

## مثال برمجي ثاني

مثال آخر لتحديد ارتفاع ثابت وعرض ثابت لعنصر div.

```css
div {
  height: 100px;
  width: 500px;
  background-color: powderblue;
}
```

## فهم الصندوق الداخلي

الخصائص تحدد مساحة المنطقة الواقعة داخل الحواف والهوامش.

- التركيز على المساحة الداخلية للعنصر
- التحكم الكامل في تصميم المكونات
- تجنب الأخطاء الشائعة في تنسيق الأبعاد

## أفضل الممارسات البرمجية

استخدام النسب المئوية لتحقيق مرونة أعلى في التصميم المتجاوب.

- استخدام النسبة المئوية للمرونة
- مراعاة حجم الشاشات المختلفة
- كتابة كود نظيف ومنظم

## خلاصة الدرس

خلاصة استخدام خصائص الأبعاد في CSS ودعوة للدروس القادمة.

- ملخص شامل لخصائص الأبعاد
- أهمية تطبيق الأمثلة بشكل عملي
- انتظرونا في الدرس القادم
