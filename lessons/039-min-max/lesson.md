# التحكم في أبعاد العناصر باستخدام CSS

المصدر: https://www.w3schools.com/css/css_height_width_min_max.asp

## مقدمة حول أبعاد العناصر

مرحبا بكم في درس التحكم في أبعاد العناصر باستخدام خصائص min-width و max-width و min-height و max-height.

- التحكم في الحد الأدنى والأقصى للعرض
- التحكم في الحد الأدنى والأقصى للارتفاع
- تحسين تجربة المستخدم في المتصفحات
- تجنب مشاكل التمرير الأفقي

## مفاهيم min و max

تمنع خاصية max-width العنصر من تجاوز عرض معين، مما يحسن من عرض الصفحة في النوافذ الصغيرة.

- max-width يحدد الحد الأقصى للعرض
- min-width يحدد الحد الأدنى للعرض
- تجنب ظهور شريط التمرير الأفقي
- تحسين التعامل مع النوافذ الصغيرة

## مثال على max-width

مقارنة بين استخدام max-width وتحديد width ثابت للعنصر.

```css
.div1 {
  max-width: 500px;
  background-color: powderblue;
}
.div2 {
  width: 500px;
  background-color: powderblue;
}
```

## الدمج بين width و max-width

استخدام width بنسبة 100 مع max-width لضمان مرونة العنصر.

```css
.div1 {
  width: 100%;
  max-width: 900px;
  background-color: powderblue;
}
```

## ملاحظات تقنية

ملاحظة: إذا تعارضت قيمتا width و max-width، فإن الأولوية دائما لـ max-width.

- الأولوية لـ max-width عند التعارض
- استخدام القيم المرنة مثل النسبة المئوية
- اختبار التصميم في أحجام شاشات مختلفة
- استخدام min-height للتحكم في الارتفاع

## خاتمة الدرس

شكرا لمتابعتكم. جربوا الأكواد بأنفسكم عبر الرابط في الوصف لتطوير مهاراتكم في CSS.

- راجعوا خصائص min-height و max-height
- طبقوا الأمثلة في محرر الأكواد
- تابعوا الدورة لمزيد من الدروس المتقدمة
- الرابط متاح في وصف الفيديو
