# CSS Height and Width Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_height_width.asp

## مقدمة في تحدي الأبعاد

مرحبا بكم في تحدي CSS للتحكم في أبعاد العناصر باستخدام height و width.

- التحكم في أبعاد العناصر هو أساس تصميم الويب
- خصائص height و width تحدد مساحة العنصر
- التحدي البرمجي يساعد في تثبيت المعلومات

## مفاهيم أساسية

تستخدم خاصية width و height لتحديد أبعاد العناصر ضمن Box Model.

- width: تحدد عرض محتوى العنصر
- height: تحدد ارتفاع محتوى العنصر
- Box Model: يحيط بالعنصر ويشمل padding و border و margin

## كتابة الكود البرمجي

نبدأ بتحديد أبعاد عنصر div باستخدام قيم محددة.

```css
div {
  width: 200px;
  height: 100px;
  background-color: blue;
}
```

## تطبيق القيم النسبية

استخدام النسب المئوية يجعل التصميم متجاوبا مع أحجام الشاشات.

```css
div {
  width: 50%;
  height: auto;
  border: 2px solid black;
}
```

## معاينة النتيجة

تظهر النتيجة النهائية للعنصر بناء على القيم المعطاة في CSS.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <!-- العنصر بعد التنسيق -->
    <div style="width:200px; height:100px;">
      محتوى العنصر
    </div>
  </body>
</html>
```

## أفضل الممارسات

استخدم min-width و max-width لضمان مرونة التصميم.

- استخدم الوحدات المناسبة (px, , rem)
- جرب دائما قيم min و max
- اختبر التصميم على متصفحات مختلفة
