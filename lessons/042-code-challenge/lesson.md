# CSS Box Model Challenge

المصدر: https://www.w3schools.com/css/css_challenges_boxmodel.asp

## مقدمة في Box Model

مرحبا بكم في درس CSS الجديد حول مفهوم Box Model الأساسي في تصميم صفحات الويب.

- مفهوم Box Model هو جوهر تصميم الويب
- يتحكم في أبعاد ومساحات العناصر
- فهم هذا المفهوم يسهل عليك تنسيق الصفحات
- سنقوم بحل تحدي عملي لترسيخ المعلومات

## مكونات Box Model

يتكون كل Element في صفحات الويب من أربعة أجزاء رئيسية: Content وPadding وBorder وMargin.

## هيكل الكود البرمجي

نستخدم CSS لتحديد خصائص Box Model مثل padding وmargin وborder لكل Element.

```css
div {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
}
```

## شرح تفصيلي للخصائص

توضيح تأثير كل خاصية: width يحدد العرض، padding للمساحة الداخلية، border للإطار، وmargin للمسافة الخارجية.

- width يحدد عرض المحتوى
- padding يضيف مساحة داخلية شفافة
- border يحيط بالمحتوى والـ padding
- margin يحدد المسافة خارج الـ border

## المعاينة المرئية

تظهر النتيجة النهائية للعنصر بعد تطبيق خصائص Box Model في المتصفح.

## أفضل الممارسات

استخدام box-sizing: border-box يجعل التحكم في أبعاد العناصر أكثر دقة وسهولة.

- استخدم box-sizing: border-box دائما
- تحقق من القيم في الـ browser inspector
- جرب تغيير القيم لملاحظة التأثير
- حافظ على تناسق المسافات
