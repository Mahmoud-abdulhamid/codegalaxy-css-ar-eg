# التحكم في عرض الـ Outline باستخدام CSS

المصدر: https://www.w3schools.com/css/css_outline_width.asp

## مقدمة حول outline-width

مرحبا بكم في درس التحكم في سماكة الـ outline باستخدام خاصية outline-width في CSS.

- خاصية outline-width تحدد عرض الإطار الخارجي للعنصر
- تستخدم لتحسين التباين والتركيز على العناصر
- لا تؤثر على أبعاد العنصر أو تخطيط الصفحة

## قيم خاصية outline-width

تقبل خاصية outline-width قيما نصية مثل thin وmedium وthick، أو قيما رقمية بوحدة px.

## تطبيق الكود العملي

نبدأ بتحديد نمط ولون الـ outline للعناصر قبل تطبيق السماكات المختلفة.

```css
p {
  padding: 5px;
  outline-style: solid;
  outline-color: green;
}
```

## تخصيص السماكات

تطبيق سماكات مختلفة باستخدام الكلاسات ex1 إلى ex4.

```css
p.ex1 {
  outline-width: thin;
}
p.ex2 {
  outline-width: medium;
}
p.ex3 {
  outline-width: thick;
}
p.ex4 {
  outline-width: 8px;
}
```

## تحليل النتائج

يظهر الـ outline حول العناصر دون التأثير على تخطيط الصفحة أو أبعادها.

- الـ outline يرسم خارج حدود الـ border
- لا يؤثر على تدفق العناصر في الصفحة
- يعد أداة ممتازة للتركيز البصري

## نصائح برمجية

استخدم الـ outline لتحسين تجربة المستخدم وإمكانية الوصول.

- استخدم outline-width للتركيز على العناصر النشطة
- تأكد من التباين اللوني الجيد
- لا تعتمد على الـ outline كبديل أساسي للـ border
