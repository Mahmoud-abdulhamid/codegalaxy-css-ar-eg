# CSS Outline Shorthand

المصدر: https://www.w3schools.com/css/css_outline_shorthand.asp

## مقدمة حول Outline Shorthand

نتعرف اليوم على الخاصية المختصرة outline وكيفية استخدامها بكفاءة عالية.

- شرح الخاصية المختصرة outline في CSS
- توفير الوقت والجهد في كتابة الأكواد
- تحديد عدة خصائص في سطر برمجي واحد

## قواعد القيم والترتيب

يمكن تحديد قيمة أو قيمتين أو ثلاث للخاصية ولا يشترط ترتيب معين للقيم.

- تحديد قيمة واحدة أو قيمتين أو ثلاث
- ترتيب القيم غير مهم نهائيا
- التحكم الكامل في شكل العناصر

## أمثلة على outline مختصرا

تطبيق أنماط مختلفة للخاصية outline مثل dashed و dotted red و solid.

```css
p.ex1 {
  outline: dashed;
}
p.ex2 {
  outline: dotted red;
}
```

## استكمال أمثلة outline

متابعة الأمثلة لاستخدام ألوان وأنساق متقدمة مثل thick ridge pink.

```css
p.ex3 {
  outline: 7px solid yellow;
}
p.ex4 {
  outline: thick ridge pink;
}
```

## الزوايا الدائرية مع outline

يمكن دمج الإطار الخارجي مع الخاصية border-radius لعمل زوايا دائرية.

- إضافة زوايا دائرية للإطارات الخارجية
- استخدام الخاصية border-radius بفعالية
- تحسين المظهر الجمالي لعناصر الويب

## تطبيق border-radius مع outline

دمج الخاصية outline مع border-radius للحصول على تصميمات مميزة.

```css
p.ex1 {
  outline: dashed;
  border-radius: 8px;
}
p.ex2 {
  outline: dotted red;
  border-radius: 5px;
}
```

## أمثلة إضافية للزوايا الدائرية

تطبيق مثال إضافي مع إطار سميك أخضر وزوايا دائرية بمقدار 10px.

```css
p.ex5 {
  outline: thick solid green;
  border-radius: 10px;
}
```

## خلاصة الدرس والدعوة للتجربة

خلاصة استخدام outline المختصرة ودمجها مع الزوايا الدائرية لتصميم جذاب.

- اختصار كتابة خصائص outline في سطر واحد
- دمج الإطارات الخارجية مع الزوايا الدائرية
- تدرب على الأكواد لتعزيز مهاراتك البرمجية
