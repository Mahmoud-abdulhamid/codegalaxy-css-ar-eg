# CSS Outline Challenge

المصدر: https://www.w3schools.com/css/css_challenges_outline.asp

## مقدمة حول CSS Outline

مرحبا بكم في درس CSS Outline. سنتعلم اليوم كيفية استخدام خاصية outline في تصميم صفحات الويب من خلال حل تحدي برمجي.

- خاصية outline تستخدم لإضافة خط حول العناصر
- تختلف عن border في أنها لا تشغل مساحة
- تعتبر أداة هامة لتحسين تجربة المستخدم
- سنقوم بحل تحدي عملي لتطبيق هذه المفاهيم

## مفاهيم اساسية حول Outline

خاصية outline تشبه border لكنها لا تؤثر على أبعاد العنصر. نستخدمها لتحديد العناصر بوضوح مع التحكم في style و width و color و outline-offset.

- outline-style: تحدد نمط الخط مثل solid أو dashed
- outline-width: تحدد سمك الخط
- outline-color: تحدد لون الخط
- outline-offset: تضيف مسافة بين الخط والعنصر

## كتابة كود CSS Outline

تطبيق خاصية outline على عنصر div باستخدام النمط solid واللون الأحمر وعرض 5px.

```css
div {
  outline-style: solid;
  outline-color: red;
  outline-width: 5px;
}
```

## شرح خاصية outline-offset

استخدام outline-offset لإضافة مسافة بين الخط وحافة العنصر لتحسين المظهر الجمالي.

```css
div {
  outline: 2px solid blue;
  outline-offset: 10px;
}
```

## افضل الممارسات

نصائح هامة: خاصية outline لا تشغل مساحة، لذا يجب الانتباه لتداخلها مع العناصر الأخرى.

- لا تسبب إزاحة للعناصر المجاورة
- مفيدة جدا لتحسين إمكانية الوصول Accessibility
- تجنب استخدامها بشكل مفرط يشتت الانتباه
- تأكد من تناسق الألوان مع تصميم الموقع
