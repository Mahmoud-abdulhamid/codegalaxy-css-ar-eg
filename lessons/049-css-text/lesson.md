# تنسيق ألوان النصوص باستخدام CSS

المصدر: https://www.w3schools.com/css/css_text.asp

## مقدمة في تنسيق ألوان النصوص

مرحبا بكم في درس تنسيق ألوان النصوص باستخدام CSS، سنتعلم اليوم التحكم في ألوان النصوص باستخدام خاصية color.

- تنسيق النصوص يعزز تجربة المستخدم
- استخدام خاصية color لتغيير لون النص
- التحكم في ألوان العناصر المختلفة
- أهمية التباين بين النص والخلفية

## استخدام خاصية color

تستخدم خاصية color لتحديد لون النص، ويمكن تطبيقها على عناصر مثل body أو h1.

- خاصية color تغير لون النص
- تحديد اللون الافتراضي في body
- تطبيق الألوان على العناوين والفقرات
- الرجوع إلى CSS Color Values للمزيد

## تطبيق الألوان على العناصر

مثال عملي لتطبيق ألوان مختلفة على عناصر body و h1 و h2.

```css
body {
  color: blue;
}
h1 {
  color: green;
}
h2 {
  color: red;
}
```

## دمج لون الخلفية مع النص

يمكن دمج background-color مع color، مع ضرورة مراعاة التباين العالي.

- استخدام background-color للخلفيات
- دمجها مع color لتباين أفضل
- ضمان سهولة القراءة للجميع
- تجنب الألوان المتشابهة

## مثال التباين العالي

مثال يوضح استخدام background-color و color لضمان تباين عال.

```css
body {
  background-color: lightgrey;
  color: blue;
}
h1 {
  background-color: black;
  color: white;
}
```

## أفضل الممارسات

أفضل الممارسات: تأكد دائما من وجود تباين عال بين لون النص والخلفية لضمان سهولة القراءة.

- التباين العالي يحسن الوصولية
- اختبار الألوان على شاشات مختلفة
- استخدام أدوات فحص التباين
- الالتزام بمعايير التصميم

## خاتمة الدرس

تعلمنا أساسيات تنسيق ألوان النصوص، جربوا الأكواد بأنفسكم عبر الرابط في الوصف.

- تمت تغطية خاصية color
- تمت تغطية خاصية background-color
- أهمية التباين في التصميم
- جرب الأكواد من الرابط
