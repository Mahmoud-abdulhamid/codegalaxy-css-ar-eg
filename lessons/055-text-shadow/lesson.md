# CSS Text Shadow

المصدر: https://www.w3schools.com/css/css_text_shadow.asp

## مقدمة حول text-shadow

تعد خاصية text-shadow أداة قوية لإضافة تأثيرات الظل للنصوص في صفحات الويب.

- خاصية text-shadow تضيف ظلالا للنصوص
- تزيد من جاذبية التصميم البصري
- تتحكم في اتجاه ولون ووضوح الظل

## الاستخدام الأساسي للظل

يتم تحديد الإزاحة الأفقية والعمودية للظل باستخدام قيم بكسل بسيطة.

```css
h1
{
  text-shadow: 2px 2px;
}
```

## إضافة اللون وتأثير التمويه

يمكن تحسين الظل بإضافة اللون وقيمة التمويه blur لزيادة واقعية التأثير.

```css
h1
{
  text-shadow: 2px 2px 5px red;
}
```

## تأثير النيون المتوهج

تأثير النيون يتم عبر ضبط الإزاحة على صفر واستخدام قيم تمويه عالية.

```css
h1 {
  text-shadow: 0 0 3px #ff0000;
}
```

## استخدام ظلال متعددة

يمكن تطبيق أكثر من ظل على نفس النص باستخدام الفاصلة للفصل بين القيم.

```css
h1 {
  text-shadow: 0 0 3px #ff0000,
               0 0 5px #0000ff;
}
```

## خلاصة الدرس

جرب تغيير القيم بنفسك لاستكشاف إمكانيات text-shadow في تصميماتك.

- استخدم text-shadow لإضافة عمق للنصوص
- جرب دمج ظلال متعددة لتأثيرات إبداعية
- راجع دروس CSS Fonts للمزيد من التنسيقات
