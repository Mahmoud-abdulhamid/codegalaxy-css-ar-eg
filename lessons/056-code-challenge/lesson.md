# CSS Text Styling Challenge

المصدر: https://www.w3schools.com/css/css_challenges_text.asp

## مقدمة في تحديات CSS

مرحبا بكم في درس تحدي CSS Text لاختبار مهاراتكم في تنسيق النصوص.

- مراجعة خصائص CSS للنصوص
- تطبيق التحدي العملي
- تحسين تجربة المستخدم عبر النصوص
- تعزيز مهارات البرمجة

## المفاهيم الأساسية لتنسيق النصوص

تعتمد تنسيقات النصوص على خصائص مثل color و font-size و text-align للتحكم الكامل في العناصر.

## هيكلية الكود البرمجي

نبدأ بكتابة كود CSS عبر تحديد Selector وتطبيق الخصائص داخل الأقواس المجعدة.

```css
h1 {
  color: blue;
  text-align: center;
}
p {
  font-size: 20px;
}
```

## شرح تفصيلي للخصائص

شرح الخصائص: تغيير لون h1 ومحاذاته، وتحديد حجم الخط لعنصر p.

- color: blue يغير لون النص
- text-align: center يوسط النص
- font-size: 20px يحدد حجم الخط
- استخدام الفاصلة المنقوطة ضروري

## المعاينة في متصفح الويب

تظهر النتائج مباشرة في متصفح الويب مثل Chrome أو Edge.

```html
<h1>Welcome</h1>
<p>This is a test.</p>
```

## أفضل الممارسات البرمجية

أفضل الممارسات: تنظيم كود CSS في ملف خارجي لسهولة الصيانة.

- استخدام ملفات CSS خارجية
- كتابة كود نظيف ومنظم
- استخدام التعليقات لتوضيح الكود
- اختبار التنسيق في متصفحات مختلفة

## خلاصة الدرس

خلاصة: تعلم تطبيق خصائص CSS. جرب التحديات عبر الرابط في الوصف.

- تمت مراجعة خصائص النصوص
- تم تطبيق كود عملي
- تم عرض النتائج في المتصفح
- شجعنا على الممارسة المستمرة
