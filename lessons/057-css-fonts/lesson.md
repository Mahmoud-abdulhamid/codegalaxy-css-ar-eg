# CSS Fonts

المصدر: https://www.w3schools.com/css/css_font.asp

## أهمية اختيار الخطوط

اختيار الخط المناسب يعزز هوية العلامة التجارية ويحسن تجربة القراءة في صفحات الويب.

- الخطوط تؤثر بشكل مباشر على تجربة المستخدم
- الخط المناسب يبني هوية قوية للعلامة التجارية
- يجب اختيار خطوط سهلة القراءة مع ألوان وأحجام مناسبة

## خاصية font-family

تستخدم خاصية font-family لتحديد الخط، ويفضل توفير قائمة خطوط بنظام fallback لضمان التوافق.

- خاصية font-family تحدد نوع الخط للعنصر
- نظام fallback يضمن ظهور الخط البديل عند عدم دعم الأول
- يجب الفصل بين أسماء الخطوط باستخدام الفاصلة

## تطبيق عملي على الخطوط

مثال يوضح كيفية كتابة font-family للفقرات مع مراعاة الخطوط المتعددة.

```css
.p1 {
  font-family: "Times New Roman", Times, serif;
}
.p2 {
  font-family: Arial, Helvetica, sans-serif;
}
```

## استكمال أمثلة الخطوط

يجب دائما إنهاء قائمة الخطوط بعائلة عامة مثل serif أو sans-serif.

```css
.p3 {
  font-family: "Lucida Console", 
  "Courier New", monospace;
}
```

## عائلات الخطوط العامة

يوجد خمس عائلات عامة للخطوط في CSS تساعد في تحسين التوافق البصري.

- توجد 5 عائلات عامة للخطوط في CSS
- كل اسم خط ينتمي لعائلة عامة محددة
- تستخدم العائلة العامة كخيار أخير في fallback

## الفرق بين Serif و Sans-serif

تعتبر خطوط sans-serif أكثر وضوحا وسهولة في القراءة على شاشات الأجهزة الرقمية.

- خطوط sans-serif مفضلة للقراءة على الشاشات
- خطوط serif تحتوي على زوائد في أطراف الحروف
- اختيار نوع الخط يؤثر على تجربة القراءة

## خلاصة الدرس

تذكر دائما استخدام نظام fallback وتجربة أنواع خطوط مختلفة لتحسين تصميم موقعك.

- استخدم font-family لتحديد الخطوط
- وفر دائما خطوط بديلة بنظام fallback
- جرب العائلات العامة لتحسين التوافق
- اختر خطوطا سهلة القراءة للمستخدم
