# CSS Font Fallbacks

المصدر: https://www.w3schools.com/css/css_font_fallbacks.asp

## مقدمة حول Font Fallbacks

مرحبا بكم في درس CSS الجديد حول مفهوم Font Fallbacks لضمان توافق الخطوط عبر المتصفحات.

- التحكم في الخطوط عبر CSS
- أهمية Font Fallbacks في تصميم الويب
- ضمان تجربة مستخدم متسقة

## ما هو الـ Font Fallback

يعمل Font Fallback كخطة بديلة للمتصفح في حال عدم توفر الخط الأساسي على جهاز المستخدم.

- تحديد قائمة خطوط في font-family
- المتصفح يختار أول خط متاح
- تجنب ظهور خطوط غير مرغوبة

## الـ 5 Generic Font Families

تعتمد CSS على 5 عائلات خطوط عامة لضمان استبدال الخطوط بشكل منطقي وجمالي.

## كتابة الكود البرمجي

مثال عملي لكتابة خاصية font-family مع توفير خيارات بديلة للمتصفح.

```css
p {
  font-family: "Times New Roman", Times, serif;
}
```

## شرح تفصيلي للكود

يتبع المتصفح ترتيب الخطوط في القائمة حتى يجد الخط المتاح للعرض.

- الترتيب مهم جدا
- الخطوط المحددة بين علامتي تنصيص
- الخط العام في نهاية القائمة

## أفضل الممارسات

استخدم دائما Generic Font Family كخيار أخير، واستكشف Google Fonts لخيارات تصميمية أوسع.

- دائما أضف Generic Font Family
- استخدم Google Fonts للخطوط المخصصة
- اختبر التصميم على متصفحات مختلفة

## خلاصة الدرس

شكرا لمتابعتكم، لا تنسوا تجربة الأكواد بأنفسكم عبر الرابط المرفق.

- مراجعة مفهوم Font Fallbacks
- تطبيق العائلات العامة
- تجربة الأكواد عبر الرابط
