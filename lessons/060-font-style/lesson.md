# شرح خصائص الخط في CSS وتنسيق النصوص

المصدر: https://www.w3schools.com/css/css_font_style.asp

## مقدمة عن تنسيق النصوص في CSS

مرحبا بكم في درس تنسيق النصوص وخصائص الخط في لغة CSS.

- تنسيق النصوص باستخدام خصائص CSS
- التحكم في نمط الخط وسمكه
- تحسين المظهر البصري لصفحات الويب

## استخدام خاصية font-style

تحدد خاصية font-style نمط النص بين العادي والمائل.

- خاصية font-style تحدد نمط النص
- قيمة normal للنص العادي
- قيمة italic و oblique للنص المائل

## كود أمثلة font-style

تطبيق قيم font-style المختلفة على عناصر الفقرات.

```css
p.normal {
  font-style: normal;
}
p.italic {
  font-style: italic;
}
```

## استخدام خاصية font-weight

تحدد خاصية font-weight سمك وحجم الخط في النصوص.

- خاصية font-weight لتحديد سمك النص
- استخدام normal و bold و lighter
- استخدام القيم الرقمية مثل 900 للثخانة

## كود أمثلة font-weight

أمثلة عملية على تطبيق سمك الخطوط باستخدام font-weight.

```css
p.thick {
  font-weight: bold;
}
p.thicker {
  font-weight: 900;
}
```

## استخدام خاصية font-variant

تعمل خاصية font-variant على تحويل الحروف الصغيرة إلى حروف كبيرة مصغرة.

- خاصية font-variant لتحويل نمط الحروف
- تفعيل وضع small-caps للحروف الصغيرة
- إعطاء مظهر فريد وجميل للنصوص

## كود أمثلة font-variant

كود CSS يوضح استخدام font-variant بقيمة small-caps.

```css
p.normal {
  font-variant: normal;
}
p.small {
  font-variant: small-caps;
}
```

## خلاصة الدرس

خلاصة شاملة لخصائص الخط في CSS وكيفية استخدامها باحترافية.

- ملخص خصائص الخط الثلاث الأساسية
- أهمية تنسيق النصوص في تطوير الويب
- تابعونا في الدروس القادمة لاستكمال الدورة
