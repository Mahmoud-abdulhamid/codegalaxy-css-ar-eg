# التحكم في حجم الخط باستخدام CSS

المصدر: https://www.w3schools.com/css/css_font_size.asp

## مقدمة حول font-size

تعد خاصية font-size من أهم الخصائص للتحكم في حجم النصوص داخل صفحات الويب.

- التحكم في حجم الخط ضروري لتجربة المستخدم
- يجب استخدام HTML tags المناسبة للعناوين والفقرات
- تتوفر وحدات قياس مطلقة ونسبية للخطوط

## استخدام وحدات px

تمنح وحدة px تحكما دقيقا ولكنها تفتقر للمرونة في التكيف مع الشاشات المختلفة.

```css
h1 { font-size: 40px; }
h2 { font-size: 30px; }
p { font-size: 16px; }
```

## استخدام وحدة em

وحدة em تعتمد على حجم خط العنصر الأب، مما يجعلها خيارا مرنا للمستخدمين.

```css
body { font-size: 16px; }
h1 { font-size: 2.5em; }
p { font-size: 1em; }
```

## استخدام وحدة rem

تعتبر وحدة rem مثالية للتصاميم المتجاوبة لأنها ترتبط دائما بRoot Element html.

```css
html { font-size: 16px; }
h1 { font-size: 2.5rem; }
p { font-size: 1rem; }
```

## وحدة vw للمساحات

وحدة vw تجعل حجم النص يتناسب ديناميكيا مع عرض نافذة المتصفح.

```css
h1 { font-size: 10vw; }
p { font-size: 5vw; }
```

## خلاصة الدرس

اختر وحدة القياس المناسبة لمشروعك لضمان أفضل تجربة للمستخدم.

- px للتحكم المطلق
- em للنسبية مع الأب
- rem للنسبية مع الجذر
- vw للتجاوب مع عرض الشاشة
