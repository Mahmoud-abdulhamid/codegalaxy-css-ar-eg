# CSS Fonts Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_font.asp

## مقدمة في تحديات CSS

مرحبا بكم في درس تحدي CSS للخطوط. سنقوم اليوم باختبار مهاراتكم في تطبيق خصائص الخطوط المختلفة.

- تحدي عملي لتطبيق CSS
- التركيز على خصائص الخطوط
- تحسين تجربة المستخدم عبر النصوص
- تطبيق عملي مباشر

## المفاهيم الأساسية للخطوط

تعتمد خصائص الخطوط على font-family و font-size و font-weight للتحكم الكامل في شكل النص.

## هيكل الكود البرمجي

هيكل مستند HTML الأساسي مع قسم head لتضمين قواعد CSS وقسم body للمحتوى.

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      body {
        font-family: Arial;
      }
    </style>
  </head>
  <body>
    <h1>CSS Fonts</h1>
  </body>
</html>
```

## تطبيق التنسيقات

تطبيق قواعد CSS على عنصر h1 لتغيير خصائص الخط بشكل مباشر.

```css
h1 {
  font-family: Verdana;
  font-size: 30px;
  font-weight: bold;
}
```

## معاينة المخرجات

هكذا يظهر النص في المتصفح بعد تطبيق قواعد CSS المحددة.

```html
<h1>CSS Fonts</h1>
```

## أفضل الممارسات

نصائح هامة: اختر خطوطا واضحة، واستخدم أحجاما متناسبة لتحسين تجربة المستخدم.

- استخدم خطوطا آمنة للويب
- حافظ على تباين جيد للنصوص
- جرب أحجاما مختلفة للخطوط
- اختبر التصميم على متصفحات مختلفة

## خلاصة الدرس

لقد تعلمنا أساسيات تنسيق الخطوط في CSS. جرب الأكواد بنفسك عبر الرابط في الوصف.

- تمت تغطية font-family و font-size
- تم شرح كيفية تطبيق التنسيق
- تم عرض المخرجات المتوقعة
- شجعنا على الممارسة المستمرة
