# CSS Lists Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_list.asp

## مقدمة في تحدي القوائم

مرحبا بكم في درس تحدي القوائم ضمن دورة CSS، حيث سنقوم بتطبيق مهاراتنا في تنسيق القوائم.

- فهم هيكلية القوائم في HTML
- تطبيق خصائص CSS على ul و ol
- حل تحديات برمجية عملية

## المفاهيم الأساسية للقوائم

تعتمد خصائص القوائم في CSS على list-style للتحكم في شكل العلامات وموقعها.

## كود تنسيق القوائم

مثال برمجي لتغيير شكل علامات القائمة إلى مربعات باستخدام CSS.

```css
ul {
  list-style-type: square;
  padding: 20px;
}
li {
  color: darkblue;
  margin-bottom: 10px;
}
```

## التحكم في موقع العلامات

الفرق بين inside و outside في خاصية list-style-position.

- inside: العلامة داخل مساحة النص
- outside: العلامة خارج مساحة النص
- تأثير مباشر على المحاذاة

## أفضل الممارسات

استخدام الاختصارات في CSS يجعل الكود أكثر نظافة وكفاءة.

```css
/* استخدام الاختصار */
ul {
  list-style: square inside url('icon.png');
}
```

## خلاصة الدرس

خلاصة الدرس: تعلم التحكم في القوائم وتطبيق التحديات البرمجية.

- تمت تغطية خصائص list-style
- تم شرح الفرق بين المواقع
- تم تقديم أمثلة عملية
- شجعنا على الممارسة المستمرة
