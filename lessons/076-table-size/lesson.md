# التحكم في أحجام الجداول باستخدام CSS Width و CSS Height

المصدر: https://www.w3schools.com/css/css_table_size.asp

## مقدمة حول تحكم أحجام الجداول في CSS

مرحبا بكم في درس التحكم في أحجام الجداول باستخدام خصائص width و height في CSS.

- التحكم في عرض وارتفاع الجداول في CSS
- استخدام خاصية width لتحديد العرض
- استخدام خاصية height لتحديد الارتفاع

## استخدام النسبة المئوية لتحديد العرض

استخدام النسبة المئوية في width لتغطية كامل الشاشة أو نصف الصفحة.

```css
table {
  width: 100%;
}
table {
  width: 50%;
}
```

## تحديد عرض ثابت بالبكسل

إنشاء جدول بعرض ثابت محدد باستخدام وحدة بكسل مثل 500px.

```css
table {
  width: 500px;
}
```

## استخدام القيمة auto للحساب التلقائي

استخدام قيمة auto لكي يقوم متصفح الويب بحساب العرض تلقائيا.

```css
table {
  width: auto;
}
```

## التحكم في ارتفاع عناصر الجدول باستخدام height

استخدام خاصية height لتحديد ارتفاع خلايا رؤوس الجدول مثل عنصر th.

```css
th {
  height: 70px;
}
```

## خلاصة أحجام الجداول في CSS

خلاصة درس التحكم في أحجام الجداول وخصائص width و height في CSS.

- استخدام width للنسب المئوية والقيم الثابتة و auto
- استخدام height لتحديد ارتفاع الخلايا والرؤوس
- تحسين المظهر العام لتصميم الجداول
