# CSS Table Alignment

المصدر: https://www.w3schools.com/css/css_table_align.asp

## مقدمة محاذاة الجداول في CSS

مرحبا بكم في درس محاذاة محتوى الجداول باستخدام خصائص CSS المختلفة.

- التعرف على محاذاة الجداول في CSS
- فهم خصائص المحاذاة الأفقية والرأسية
- تطبيق القواعد على عناصر th و td

## المحاذاة الأفقية باستخدام text-align

تستخدم خاصية text-align لتحديد المحاذاة الأفقية للنصوص في عناصر th أو td.

- استخدام property باسم text-align
- المحتوى الافتراضي لـ th في المنتصف
- المحتوى الافتراضي لـ td نحو اليسار

## توسيط محتوى td بالعرض

نستخدم text-align: center لتوسيط محتوى عناصر td أفقيا.

```css
td
{
  text-align: center;
}
```

## جعل محاذاة th إلى اليسار

يمكننا إجبار عناصر th على المحاذاة نحو اليسار باستخدام text-align: left.

```css
th
{
  text-align: left;
}
```

## المحاذاة الرأسية باستخدام vertical-align

تتحكم خاصية vertical-align بالمحاذاة الرأسية للنصوص مثل أعلى أو أسفل أو منتصف.

- التحكم بالمحاذاة الرأسية عبر vertical-align
- القيم المتاحة تشمل top و bottom و middle
- الوضع الافتراضي للمحاذاة الرأسية هو middle

## تطبيق vertical-align bottom

نحدد ارتفاع الخلايا ونطبق vertical-align: bottom لجعل النص في أسفل الخلية.

```css
td
{
  height: 50px;
  vertical-align: bottom;
}
```

## خلاصة درس محاذاة الجداول

خلاصة شاملة لخصائص المحاذاة الأفقية والرأسية في جداول CSS.

- استخدام text-align للمحاذاة الأفقية
- استخدام vertical-align للمحاذاة الرأسية
- تخصيص العرض والارتفاع لخلايا الجدول
