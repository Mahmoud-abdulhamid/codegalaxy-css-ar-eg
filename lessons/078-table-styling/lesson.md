# CSS Table Styling

المصدر: https://www.w3schools.com/css/css_table_style.asp

## مقدمة في تنسيق الجداول

مرحبا بكم في درس تنسيق الجداول باستخدام CSS لجعل بيانات الويب أكثر احترافية.

- تحسين مظهر الجداول باستخدام CSS
- إضافة مسافات داخلية باستخدام padding
- تنسيق الصفوف والأعمدة بأساليب تفاعلية

## إضافة مسافات داخلية

استخدام خاصية padding على عناصر td و th لإضافة مساحة مريحة حول المحتوى.

```css
th, td {
  padding: 10px;
  text-align: left;
}
```

## الفواصل الأفقية

إضافة فواصل أفقية باستخدام خاصية border-bottom لتحسين قراءة بيانات الجدول.

```css
th, td {
  border-bottom: 1px solid #ddd;
}
```

## تأثير التفاعل Hover

تفعيل تأثير hover على الصفوف tr لتغيير لون الخلفية عند تمرير الماوس.

```css
tr:hover {
  background-color: coral;
}
```

## الجداول المخططة

استخدام nth-child(even) لتطبيق لون خلفية مختلف على الصفوف الزوجية.

```css
tr:nth-child(even) {
  background-color: #f2f2f2;
}
```

## تنسيق ألوان الرؤوس

تخصيص ألوان الخلفية والنص لعناصر th لإبراز رؤوس الجدول.

```css
th {
  background-color: #04AA6D;
  color: white;
}
```

## خلاصة الدرس

شكرا لمتابعتكم. جربوا الأكواد بأنفسكم لتطوير مهاراتكم في تصميم الجداول.

- استخدام padding و border-bottom
- تطبيق hover و nth-child
- تنسيق الألوان لعناصر th
- ممارسة الأكواد عبر الرابط في الوصف
