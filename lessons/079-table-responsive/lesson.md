# CSS Responsive Tables

المصدر: https://www.w3schools.com/css/css_table_responsive.asp

## مقدمة حول الجداول المتجاوبة

مقدمة حول كيفية جعل الجداول Responsive في صفحات الويب.

- الجداول المتجاوبة تحسن تجربة المستخدم
- تظهر شريط تمرير أفقي عند ضيق الشاشة
- تمنع تداخل البيانات أو خروجها عن الإطار

## المفهوم الأساسي للحل

نستخدم حاوية div مع خاصية overflow-x للتحكم في التمرير.

- تغليف عنصر table داخل div
- استخدام خاصية overflow-x: auto
- تفعيل التمرير الأفقي التلقائي عند الحاجة

## تطبيق الكود البرمجي

كود CSS لتفعيل التمرير الأفقي للحاوية.

```css
div.tablecontainer {
  overflow-x: auto;
}
```

## هيكلة HTML المطلوبة

هيكلة HTML الصحيحة لتغليف الجدول.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="tablecontainer">
      <table>
        <tr>
          <th>الاسم</th>
          <th>البيانات</th>
        </tr>
      </table>
    </div>
  </body>
</html>
```

## معاينة المخرجات

المعاينة المرئية للجدول المتجاوب مع شريط التمرير.

```text
[ الاسم ] [ البيانات ]
[  ...  ] [  ...  ]
---------------------
[  <-- Scroll -->   ]
```

## ملاحظات تقنية هامة

ملاحظة حول سلوك أشرطة التمرير في نظام OS X.

- أشرطة التمرير قد تكون مخفية في Mac
- تظهر فقط عند التفاعل مع المحتوى
- هذا سلوك نظام التشغيل وليس خطأ في الكود

## خلاصة الدرس

خلاصة الدرس: الجداول المتجاوبة ضرورية لتصميم الويب الحديث.

- استخدام div كحاوية للجدول
- تطبيق overflow-x: auto
- تحسين تجربة المستخدم على الأجهزة المحمولة
