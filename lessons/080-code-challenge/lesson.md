# CSS Tables Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_table.asp

## مقدمة في تحدي الجداول

مرحبا بكم في درس تحدي الجداول. سنتعلم اليوم كيفية تنسيق الجداول باستخدام CSS بشكل احترافي.

- تنسيق هيكل الجداول باستخدام CSS
- التحكم في خصائص table و th و td
- تطبيق التحدي البرمجي لتعزيز الفهم

## المفاهيم الأساسية للجداول

تعتمد جداول HTML على عناصر table و th و td. نستخدم CSS للتحكم في الحواف والمسافات الداخلية.

## هيكل الكود الأساسي

هيكل الكود الأساسي لتنسيق الجدول باستخدام CSS.

```css
table {
  width: 100%;
  border-collapse: collapse;
}
th, td {
  border: 1px solid black;
  padding: 8px;
  text-align: left;
}
```

## تنسيق الخلايا والصفوف

استخدام خصائص CSS المتقدمة مثل nth-child لتحسين تجربة المستخدم.

```css
th {
  background-color: #f2f2f2;
}
tr:nth-child(even) {
  background-color: #f9f9f9;
}
```

## معاينة الجدول في المتصفح

النتيجة النهائية للجدول بعد تطبيق تنسيقات CSS.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <table>
      <tr>
        <th>الاسم</th>
        <th>المهنة</th>
      </tr>
      <tr>
        <td>محمود</td>
        <td>مطور</td>
      </tr>
    </table>
  </body>
</html>
```

## أفضل الممارسات

أفضل الممارسات لضمان تجاوب الجداول مع مختلف الشاشات.

- استخدام overflow-x: auto للجداول الكبيرة
- تجنب العرض الثابت للعناصر
- اختبار الجدول على Chrome و Firefox

## خلاصة الدرس

خلاصة الدرس: استمر في التدريب وحل التحديات البرمجية.

- تم تغطية أساسيات تنسيق الجداول
- تم شرح كيفية استخدام CSS للتحكم في الخلايا
- شجعنا على حل التحدي البرمجي
