# CSS Display Property Challenge

المصدر: https://www.w3schools.com/css/css_challenges_display.asp

## مقدمة حول خاصية display

مرحبا بكم في درس جديد من دورة CSS. اليوم سنحلل تحدي display، وهو أحد أهم المفاهيم للتحكم في كيفية ظهور العناصر داخل صفحة الويب.

- خاصية display تحدد سلوك العنصر في التخطيط
- تؤثر على كيفية ترتيب العناصر بجانب بعضها أو تحت بعضها
- تسمح بإخفاء العناصر تماما من الصفحة

## قيم خاصية display الأساسية

تعد قيم display مثل block وinline وnone أدوات قوية. العناصر بقيمة block تحتل سطرا كاملا، بينما inline تسمح بتجاور العناصر، وnone تخفي العنصر تماما من الصفحة.

## هيكل الكود البرمجي

لننظر إلى هذا الكود. نبدأ بـ DOCTYPE HTML ثم نحدد العناصر داخل body. نستخدم CSS لتطبيق display على الـ Elements لتحقيق التخطيط المطلوب في التحدي.

```html
<!DOCTYPE html>
<html>
  <head>
    <style>
      .box {
        display: block;
      }
      .hidden {
        display: none;
      }
    </style>
  </head>
  <body>
    <div class="box">Element 1</div>
    <div class="hidden">Hidden</div>
  </body>
</html>
```

## شرح تفصيلي للأكواد

في هذا المثال، قمنا بتعريف class باسم box وأعطيناه display: block. هذا يجعل العنصر يبدأ في سطر جديد. أما class باسم hidden فيستخدم display: none لإزالته من الرؤية.

- display: block يفرض فاصلا قبل وبعد العنصر
- display: none يزيل العنصر من تدفق الصفحة
- تغيير هذه القيم يغير شكل الصفحة جذريا

## معاينة المخرجات

عند تشغيل هذا الكود في متصفح Chrome، سترى العنصر الأول فقط. العنصر الثاني لن يظهر لأننا استخدمنا display: none، وهذا هو الهدف من هذا التحدي.

```text
Element 1
```

## أفضل الممارسات

يا أصدقائي، احرصوا دائما على استخدام display بحكمة. تجنبوا إخفاء العناصر المهمة عن محركات البحث، واستخدموا القيم المناسبة لتحسين تجربة المستخدم في صفحة الويب.

- استخدم display: none لإخفاء العناصر غير الضرورية
- استخدم block للعناصر التي تحتاج مساحة كاملة
- اختبر دائما التخطيط في متصفحات مختلفة

## خلاصة الدرس

في ختام هذا الدرس، تعلمنا كيفية التحكم في العناصر بواسطة display. أدعوكم لتجربة الأكواد بأنفسكم عبر الرابط الموجود في الوصف لتتقنوا هذه المهارة الأساسية.

- تمت تغطية مفاهيم display الأساسية
- تم تطبيق كود عملي بسيط
- راجع الرابط في الوصف لمزيد من التحديات
