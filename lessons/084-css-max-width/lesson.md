# CSS max-width Property

المصدر: https://www.w3schools.com/css/css_max-width.asp

## مقدمة حول max-width

تعد خاصية max-width أداة أساسية للتحكم في العرض الأقصى للعناصر وضمان مرونة التصميم.

- تحدد max-width الحد الأقصى لعرض العنصر
- تمنع العنصر من تجاوز قيمة معينة
- تساهم في إنشاء تصميمات متجاوبة Responsive Layouts
- تضمن سهولة قراءة المحتوى عبر مختلف الشاشات

## مشكلة استخدام width الثابت

استخدام width الثابت قد يؤدي إلى مشاكل في العرض عند تصغير نافذة المتصفح.

- تحديد width ثابت قد يسبب تجاوز المحتوى لحدود الشاشة
- ظهور شريط تمرير أفقي Horizontal Scrollbar
- صعوبة في قراءة المحتوى على الشاشات الصغيرة

## مقارنة الكود البرمجي

مقارنة بين استخدام width الثابت و max-width في CSS.

```css
div.ex1 {
  width: 500px;
  margin: auto;
  border: 3px solid #73AD21;
}
div.ex2 {
  max-width: 500px;
  margin: auto;
  border: 3px solid #73AD21;
}
```

## شرح div.ex1

تحديد width ثابت يجعل العنصر غير مرن في الشاشات الصغيرة.

- width: 500px يفرض عرضا ثابتا
- العنصر لا يتكيف مع أحجام الشاشات المختلفة
- يؤدي إلى ظهور شريط تمرير عند ضيق الشاشة

## شرح div.ex2

تسمح خاصية max-width للعنصر بالتكيف مع أحجام الشاشات المختلفة.

- max-width: 500px يحدد الحد الأقصى فقط
- العنصر يتقلص تلقائيا إذا كانت الشاشة أصغر
- تحسين تجربة المستخدم في التصميمات المتجاوبة

## المعاينة المرئية

المعاينة المرئية توضح الفرق في سلوك العناصر عند تغيير حجم النافذة.

```html
<div class="ex1">Fixed Width</div>
<div class="ex2">Max-Width</div>
```

## خلاصة الدرس

استخدم max-width دائما لضمان مرونة عناصر موقعك.

- استخدم max-width بدلا من width للتحكم المرن
- تأكد من اختبار تصميمك على أحجام شاشات مختلفة
- قم بزيارة الرابط في الوصف لتجربة الكود
