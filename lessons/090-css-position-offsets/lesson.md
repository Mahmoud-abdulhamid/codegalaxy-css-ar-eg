# CSS Positioning Offsets

المصدر: https://www.w3schools.com/css/css_position_offset.asp

## مقدمة في CSS Position Offsets

مرحبا بكم في درس جديد من دورة CSS. سنتعلم اليوم كيفية التحكم في مواقع العناصر بدقة عالية باستخدام خصائص الإزاحة top و right و bottom و left في لغة الويب.

- التحكم في تموضع العناصر
- استخدام خصائص الإزاحة الأربعة
- تطبيقها على عناصر الويب

## متطلبات عمل خصائص الإزاحة

لكي تعمل هذه الخصائص، يجب أن يكون العنصر مهيأ للتموضع. هذا يعني أن خاصية position يجب أن تكون محددة بقيمة غير static، مثل relative أو absolute أو fixed أو sticky.

- يجب ضبط خاصية position
- القيم المسموح بها: relative, absolute, fixed, sticky
- لا تعمل الخصائص مع القيمة الافتراضية static

## مثال عملي على استخدام الإزاحة

لنشاهد هذا الكود. نقوم بتحديد position كـ relative، ثم نحدد top بقيمة 50px، و left بقيمة 30px. هذا يؤدي إلى إزاحة العنصر عن موقعه الأصلي بهذه المسافات.

```css
.box {
  position: relative;
  top: 50px;
  left: 30px;
  background-color: blue;
  color: white;
}
```

## تموضع النصوص فوق الصور

من التطبيقات الشائعة هي وضع النصوص فوق الصور. نجعل الحاوية relative، ثم نجعل النص absolute، ونستخدم bottom و right لتحديد موقعه بدقة داخل الصورة.

- الحاوية: position: relative
- النص: position: absolute
- استخدام bottom و right للتحكم في الموقع

## معاينة النتيجة

عند تطبيق هذه القيم، سيظهر النص في الزاوية المحددة فوق الصورة كما نرى في هذه المعاينة التوضيحية. هذا يعطي تصميما جذابا ومحترفا لصفحة الويب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <img src="image.jpg">
      <div class="text">مرحباً بالعالم</div>
    </div>
  </body>
</html>
```

## أفضل الممارسات

يجب أن نتذكر أن استخدام position: absolute ينقل العنصر خارج التدفق الطبيعي للصفحة. لذا، كونوا حذرين عند التصميم لتجنب تداخل العناصر مع بعضها البعض.

- تجنب التداخل غير المقصود
- استخدام الوحدات المناسبة مثل px أو
- اختبار التصميم على مختلف الشاشات

## خلاصة الدرس

في ختام درسنا، تعلمنا أهمية خصائص الإزاحة في CSS. أدعوكم لتجربة الأكواد بأنفسكم عبر الرابط الموجود في وصف الفيديو لتتقنوا هذه المهارة الأساسية.

- تمت تغطية top, right, bottom, left
- تم شرح شرط الـ position
- راجعوا الرابط في الوصف للتطبيق العملي
