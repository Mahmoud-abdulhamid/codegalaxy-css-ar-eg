# CSS z-index Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_z-index.asp

## مقدمة حول z-index

مرحبا بكم في درس CSS z-index. سنتعلم التحكم في ترتيب تراكب العناصر في صفحة الويب.

- خاصية z-index تحدد ترتيب العناصر في المحور Z
- تعمل الخاصية فقط على العناصر التي لها position محدد
- تساعد في تصميم واجهات مستخدم متقدمة

## قواعد العمل مع z-index

يجب تحديد position للعنصر لكي تعمل خاصية z-index. القيم الأعلى تظهر العنصر في المقدمة.

- القيم الافتراضية لـ z-index هي auto
- يمكن استخدام قيم موجبة أو سالبة
- العنصر ذو القيمة الأعلى يغطي العناصر ذات القيم الأقل

## كود تجريبي لـ z-index

نستخدم position: absolute مع z-index للتحكم في ترتيب العناصر.

```css
.box1 {
  position: absolute; z-index: 1;
}
.box2 {
  position: absolute; z-index: 2;
}
.box3 {
  position: absolute; z-index: 3;
}
```

## شرح تفصيلي للكود

العنصر ذو z-index الأعلى يظهر في المقدمة. هذا الترتيب ضروري لتصميم القوائم والنوافذ المنبثقة.

- z-index: 3 يضع العنصر في الطبقة العليا
- z-index: 1 يضع العنصر في الطبقة الدنيا
- تغيير القيم يغير ترتيب التراكب فورا

## معاينة المخرجات

تظهر العناصر متراكبة بناء على قيم z-index المعطاة لها في الكود.

## أفضل الممارسات

استخدم قيم z-index بحكمة وبشكل منطقي لتجنب تعقيد التنسيقات في المشاريع الكبيرة.

- استخدم أرقاما متسلسلة ومنطقية
- وثق ترتيب الطبقات في ملف CSS
- تجنب استخدام قيم ضخمة مثل 9999
