# التحكم في overflow-x و overflow-y في CSS

المصدر: https://www.w3schools.com/css/css_overflow_xy.asp

## مقدمة حول التحكم في التدفق

نتعرف اليوم على كيفية التحكم في تدفق المحتوى باستخدام الخصائص overflow-x و overflow-y في CSS.

- التحكم المستقل في اتجاهات التدفق
- إدارة المحتوى الزائد عن حجم العنصر
- تحسين تجربة المستخدم في صفحات الويب

## مفاهيم overflow-x و overflow-y

تسمح خصائص overflow-x و overflow-y بتحديد سلوك تدفق المحتوى بشكل منفصل لكل اتجاه.

- overflow-x للتحكم في التدفق الأفقي
- overflow-y للتحكم في التدفق الرأسي
- إمكانية دمج القيم للتحكم الكامل

## تطبيق إخفاء التدفق الأفقي

مثال يوضح كيفية إخفاء شريط التمرير الأفقي وتفعيل شريط التمرير الرأسي.

```css
div {
  overflow-x: hidden;
  overflow-y: scroll;
}
```

## حالات الاستخدام الشائعة

تستخدم هذه الخصائص عند الحاجة لسلوك تمرير مختلف للمحتوى الأفقي والرأسي.

- عرض جداول البيانات العريضة
- تصميم واجهات المستخدم المخصصة
- التحكم في المساحات المحدودة

## تطبيق إظهار التدفق الأفقي فقط

مثال يوضح كيفية تفعيل شريط التمرير الأفقي فقط وإخفاء الرأسي.

```css
div {
  overflow-x: scroll;
  overflow-y: hidden;
}
```

## خلاصة الدرس

تعد هذه الخصائص أدوات أساسية للتحكم الدقيق في تصميم صفحات الويب. جرب الأكواد بنفسك.

- التحكم الدقيق في واجهات المستخدم
- تحسين تجربة التصفح
- تجربة الأكواد عبر الرابط المرفق
