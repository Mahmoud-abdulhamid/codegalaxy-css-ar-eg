# CSS float Property

المصدر: https://www.w3schools.com/css/css_float.asp

## مقدمة حول خاصية float

تستخدم خاصية float في CSS لتحديد كيفية تموضع العناصر داخل الحاويات والسماح للنصوص بالالتفاف حولها.

- خاصية float تتحكم في تدفق العناصر
- تسمح بوضع العناصر يمينا أو يسارا
- تستخدم بكثرة لالتفاف النصوص حول الصور

## استخدام float: right

تؤدي القيمة float: right إلى دفع العنصر نحو الجانب الأيمن من الحاوية مع التفاف المحتوى حوله.

```css
img {
  float: right;
}
```

## استخدام float: left

تؤدي القيمة float: left إلى دفع العنصر نحو الجانب الأيسر من الحاوية.

```css
img {
  float: left;
}
```

## القيمة الافتراضية float: none

القيمة float: none هي القيمة الافتراضية، حيث يظهر العنصر في مكانه الطبيعي داخل الحاوية.

```css
img {
  float: none;
}
```

## ترتيب العناصر بجانب بعضها

يمكن استخدام float: left لجعل عناصر div تترتب بجانب بعضها البعض بدلا من أخذ سطر كامل.

```css
div {
  float: left;
  padding: 15px;
}
.div1 {
  background: red;
}
.div2 {
  background: yellow;
}
.div3 {
  background: green;
}
```

## خلاصة الدرس

تعد خاصية float أداة أساسية في CSS للتحكم في التخطيط، جرب تطبيقها بنفسك لفهم تأثيرها على تدفق العناصر.

- استخدم float: left أو right للتحكم في التموضع
- استخدم float: none لإلغاء التأثير
- تذكر أن float تؤثر على العناصر المجاورة
