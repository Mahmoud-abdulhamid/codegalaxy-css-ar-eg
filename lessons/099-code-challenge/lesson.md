# CSS Float Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_float.asp

## مقدمة في CSS Float

مرحبا بكم في درس CSS Float حيث سنتعلم كيفية التحكم في تخطيط العناصر باستخدام خاصية float.

- خاصية float تسمح للعناصر بالانزياح لليمين أو اليسار
- تستخدم لإنشاء تخطيطات مرنة في صفحات الويب
- تؤثر على تدفق العناصر المحيطة بها

## مفاهيم أساسية حول Float

خاصية float تخرج العنصر من التدفق الطبيعي وتسمح له بالتموضع جهة اليمين أو اليسار.

- float: left لتحريك العنصر لليسار
- float: right لتحريك العنصر لليمين
- float: none هي القيمة الافتراضية

## كود CSS Float

مثال برمجي يوضح كيفية تطبيق float على عنصر div للتحكم في موقعه.

```css
.box {
  float: left;
  width: 50%;
  background-color: #f1f1f1;
  padding: 20px;
}
```

## شرح تفصيلي للكود

شرح خصائص الكود: float للتموضع، وwidth لتحديد العرض، وpadding للمساحة الداخلية.

- float: left يوجه العنصر لليسار
- width: 50 يحدد عرض العنصر
- padding يضيف مسافة داخلية للعنصر

## معاينة المخرجات

المعاينة تظهر العنصر محاذيا لليسار مع ترك مساحة لبقية المحتوى.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="box">
      هذا محتوى يطفو لليسار
    </div>
    <p>نص إضافي يظهر بجانب العنصر</p>
  </body>
</html>
```

## أفضل الممارسات

استخدم خاصية clear لتنظيف التدفق بعد العناصر التي تستخدم float.

- استخدم clear: both لإيقاف تأثير float
- تأكد من إغلاق الحاويات بشكل صحيح
- استخدم Flexbox كبديل حديث لـ float

## خلاصة الدرس

تعلمنا اليوم أساسيات float. جربوا الأكواد بأنفسكم لتطوير مهاراتكم في CSS.

- float أداة قوية للتحكم في التخطيط
- الممارسة العملية هي مفتاح الإتقان
- راجع الرابط في الوصف لمزيد من التحديات
