# CSS Inline-block Layout Challenge

المصدر: https://www.w3schools.com/css/css_challenges_inline-block.asp

## مقدمة في CSS Inline-block

مرحبا بكم في درس CSS الجديد حول استخدام خاصية inline-block لتنسيق عناصر صفحات الويب.

- فهم دور display: inline-block
- الفرق بين العناصر inline و block
- تطبيق التحديات البرمجية العملية

## مفهوم Inline-block

تجمع خاصية inline-block بين ميزات العناصر inline والعناصر block في CSS.

## كود التحدي البرمجي

مثال برمجي يوضح كيفية تطبيق display: inline-block على العناصر.

```css
.box {
  display: inline-block;
  width: 100px;
  height: 100px;
  background-color: blue;
  margin: 5px;
}
```

## شرح تفصيلي للخصائص

شرح تأثير الخصائص width و height و margin عند استخدام inline-block.

- width و height للتحكم في الحجم
- margin لإضافة مسافات بين العناصر
- تجنب تداخل العناصر بفضل inline-block

## معاينة المخرجات

المخرجات المتوقعة: مربعات زرقاء متجاورة في صف واحد.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
  </body>
</html>
```

## أفضل الممارسات

نصيحة تقنية: التعامل مع المسافات البيضاء عند استخدام inline-block.

- الانتباه للمسافات البيضاء في HTML
- استخدام font-size: 0 في الأب
- اختبار التخطيط على متصفحات مختلفة
