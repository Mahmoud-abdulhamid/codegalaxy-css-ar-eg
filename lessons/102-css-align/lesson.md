# CSS Centering Elements

المصدر: https://www.w3schools.com/css/css_align.asp

## مقدمة في محاذاة العناصر

مرحبا بكم في درس محاذاة العناصر باستخدام CSS. سنتعلم اليوم تقنيات احترافية لمحاذاة العناصر أفقيا وعموديا.

- محاذاة العناصر أفقيا وعموديا
- استخدام تقنيات CSS الحديثة
- تحسين مظهر صفحات الويب

## مفهوم Flexbox

تعد تقنية Flexbox الطريقة الأكثر كفاءة لمحاذاة المحتوى. نستخدم display: flex على العنصر الأب لإنشاء بيئة مرنة.

- استخدام display: flex
- التحكم في توزيع العناصر
- توفير بيئة مرنة للمحتوى

## كود المحاذاة باستخدام Flexbox

هذا الكود يوضح كيفية توسيط عنصر div باستخدام Flexbox عبر الخصائص justify-content و align-items.

```css
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

## شرح تفصيلي للخصائص

تتحكم justify-content في المحور الرئيسي، بينما تتحكم align-items في المحور المتعامد لتحقيق التوسيط المثالي.

- justify-content للمحور الرئيسي
- align-items للمحور المتعامد
- التكامل لتحقيق التوسيط

## معاينة النتيجة

تظهر النتيجة توسيط العنصر بدقة في منتصف الحاوية، مما يضمن تناسق التصميم عبر المتصفحات.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="center">
      <p>I am vertically and horizontally centered.</p>
    </div>
  </body>
</html>
```

## أفضل الممارسات

تعد Flexbox أفضل ممارسة لتوسيط المحتوى، فهي تدعم المتصفحات وتقلل تعقيد الأكواد وتسهل الصيانة.

- استخدام Flexbox كمعيار
- دعم واسع للمتصفحات
- سهولة صيانة الأكواد

## خلاصة الدرس

تعلمنا اليوم استخدام Flexbox للتوسيط. جربوا الأكواد بأنفسكم عبر الرابط في الوصف لتطوير مهاراتكم.

- مراجعة مفاهيم Flexbox
- تطبيق التوسيط الأفقي والعمودي
- تجربة الأكواد عبر الرابط
