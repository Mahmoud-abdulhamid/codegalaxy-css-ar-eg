# CSS Alignment Challenge

المصدر: https://www.w3schools.com/css/css_challenges_align.asp

## مقدمة في تحدي المحاذاة

نبدأ اليوم تحدي CSS Alignment لاختبار مهاراتكم في محاذاة العناصر داخل صفحات الويب.

- أهمية المحاذاة في تصميم واجهات الويب
- استخدام CSS للتحكم في مواقع العناصر
- تحدي عملي لتطبيق مفاهيم Alignment

## مفاهيم المحاذاة الأساسية

تعتمد المحاذاة في CSS على خصائص مثل text-align وmargin وتقنيات متقدمة مثل Flexbox وGrid.

- استخدام text-align للنصوص
- استخدام margin: auto للعناصر
- قوة Flexbox في التوزيع
- مرونة CSS Grid في التخطيط

## هيكل الكود البرمجي

نبدأ بهيكل HTML الأساسي مع إضافة قسم style لتطبيق قواعد CSS المطلوبة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <style>
      .container {
        text-align: center;
        border: 1px solid black;
      }
    </style>
  </head>
  <body>
    <div class="container">
      <h1>CSS Alignment</h1>
    </div>
  </body>
</html>
```

## تطبيق خصائص المحاذاة

تطبيق خاصية text-align: center يجعل المحتوى يظهر في منتصف الحاوية بشكل مباشر.

```css
.container {
  text-align: center;
  padding: 20px;
  background-color: #f1f1f1;
}
h1 {
  color: darkblue;
}
```

## معاينة النتيجة

تظهر النتيجة النهائية مع تمركز العنوان داخل الحاوية بفضل قواعد CSS المطبقة.

```text
---------------------------
|      CSS Alignment      |
---------------------------
```

## أفضل الممارسات

استخدم Flexbox للتحكم الكامل في المحاذاة، وجرب الأكواد بنفسك لتعزيز فهمك التقني.

- تفضيل Flexbox للمشاريع الحديثة
- اختبار التجاوب مع مختلف الشاشات
- استخدام أدوات المطور في Web Browser
- الممارسة المستمرة لتثبيت المعلومات
