# CSS Pseudo-elements Challenge

المصدر: https://www.w3schools.com/css/css_challenges_pseudo_elements.asp

## مقدمة في Pseudo-elements

مرحبا بكم في درس تحدي Pseudo-elements، وهي أداة قوية لتنسيق أجزاء محددة من العناصر دون الحاجة لإضافة HTML إضافي في صفحة الويب.

- Pseudo-elements تتيح تنسيق أجزاء معينة من العناصر
- تستخدم لإضافة محتوى تجميلي أو وظيفي
- تتميز باستخدام النقطتين المزدوجتين :: في CSS
- لا تتطلب تعديل هيكل HTML

## القواعد الأساسية

تسمح Pseudo-elements مثل ::before و ::after بإدراج محتوى قبل أو بعد محتوى العنصر الأصلي، وهي مهارة أساسية لكل مطور ويب محترف.

- ::before يضيف محتوى قبل محتوى العنصر
- ::after يضيف محتوى بعد محتوى العنصر
- خاصية content ضرورية لظهور المحتوى
- تستخدم للزخرفة وتنسيق النصوص

## كود تجريبي

نستخدم ::before مع خاصية content لإضافة نص معين قبل محتوى الفقرة p في صفحة الويب.

```css
p::before {
  content: "مرحباً: ";
  color: red;
  font-weight: bold;
}
p::after {
  content: "!";
  color: blue;
}
```

## معاينة المخرجات

تظهر النتيجة في المتصفح مع الإضافات المحددة، مما يبرز قوة CSS في التحكم بالمحتوى المرئي بدقة عالية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <p>هذا هو النص الأصلي</p>
  </body>
</html>
```

## أفضل الممارسات

تذكر دائما أن خاصية content هي الأساس لظهور Pseudo-elements، واستخدم :: للتمييز بينها وبين Pseudo-classes.

- خاصية content إلزامية للظهور
- استخدم :: للـ Pseudo-elements
- استخدم : للـ Pseudo-classes
- حافظ على نظافة الكود وتنسيقه

## خلاصة الدرس

أتممنا التحدي، ندعوكم لتجربة الأكواد عبر الرابط في الوصف. استمروا في التطبيق والتعلم، وإلى اللقاء في درس قادم مع محمود عبد الحميد.

- راجع مفاهيم Pseudo-elements
- طبق التحدي البرمجي بنفسك
- استخدم الرابط في الوصف للمزيد
- تابع الدورة لتطوير مهاراتك
