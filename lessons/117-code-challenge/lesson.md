# CSS Opacity Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_image_transparency.asp

## مقدمة حول خاصية Opacity

مرحبا بكم في درس جديد من دورة CSS. سنتعلم اليوم كيفية التحكم في شفافية العناصر باستخدام خاصية opacity.

- تستخدم خاصية opacity لتحديد مستوى شفافية العنصر
- تتراوح القيم من 0.0 كشفافية كاملة إلى 1.0 كظهور كامل
- تؤثر هذه الخاصية على العنصر بالكامل بما في ذلك المحتوى

## قواعد استخدام Opacity

عند استخدام opacity، نحدد قيمة رقمية. القيمة 1 تعني أن العنصر ظاهر تماما، بينما القيمة 0.5 تجعله نصف شفاف.

## كود تطبيق الشفافية

لننظر إلى هذا الكود. نقوم بتحديد selector للصورة، ثم نضبط خاصية opacity على 0.5.

```css
img {
  opacity: 0.5;
  filter: alpha(opacity=50);
}
```

## شرح تفصيلي للكود

في هذا الكود، قمنا بتطبيق opacity على كل Elements من نوع img. السطر الثاني يعمل كمعوض للمتصفحات القديمة.

- img: هو selector يستهدف جميع عناصر الصور
- opacity: 0.5: يحدد درجة الشفافية بـ 50 بالمئة
- filter: يستخدم لدعم المتصفحات القديمة جدا

## معاينة النتيجة

عند تشغيل هذا الكود، ستشاهد الصورة في متصفح الويب بشفافية منخفضة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <img src="image.jpg" alt="Example">
    <!-- النتيجة: صورة بشفافية 50% -->
  </body>
</html>
```

## أفضل الممارسات

يجب أن نكون حذرين عند استخدام opacity، لأنها تؤثر على كل ما بداخل العنصر. استخدم rgba لخلفية شفافة فقط.

- استخدم opacity للتحكم في شفافية العنصر بالكامل
- استخدم rgba للتحكم في شفافية الخلفية فقط
- اختبر دائما التباين لضمان سهولة قراءة النصوص

## خلاصة الدرس

في ختام هذا التحدي، تعلمنا كيفية التحكم في opacity لتحسين تصميم الويب. شكرا لمتابعتكم.

- تمت تغطية خاصية opacity
- تم شرح كيفية تطبيقها على الصور
- تمت مناقشة الفرق بين opacity و rgba
- نوصي بممارسة التحديات البرمجية بانتظام
