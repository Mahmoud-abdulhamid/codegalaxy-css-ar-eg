# CSS Advanced Dropdowns

المصدر: https://www.w3schools.com/css/css_dropdowns_advanced.asp

## مقدمة القوائم المنسدلة المتقدمة

مرحبا بكم في درس CSS Advanced Dropdowns لتعلم الخصائص المتقدمة.

- تطوير مهارات تصميم الواجهات
- التحكم الكامل باتجاه Dropdowns
- إضافة صور وعناصر متقدمة

## مفهوم المحاذاة اليمنى Right-aligned Dropdown

شرح فكرة محاذاة القائمة المنسدلة من اليمين لليسار باستخدام الخاصية المناسبة.

- تغيير اتجاه الحركة في Dropdowns
- التحكم الدقيق بموقع العنصر
- مناسب لتصميمات اللغات العربية

## كتابة كود المحاذاة لليمين

تطبيق كود CSS لتوجيه المحتوى المنسدلة نحو اليمين مباشرة.

```css
.dropdown-content {
  right: 0;
}
```

## إضافة الصور داخل Dropdown

إضافة صور ومحتويات إضافية داخل صندوق القائمة المنسدلة.

- إدراج عناصر الوسائط المتعددة
- تحسين التفاعل عند المرور بالفأرة
- تنظيم محتوى الويب باحترافية

## مثال تفاعلي للصور داخل القائمة

تفعيل تفاعل الصور عند مرور مؤشر الفأرة ضمن القائمة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="dropdown">
      <img src="img_avatar.png" alt="Avatar">
      <div class="dropdown-content">
        <p>Hello World!</p>
      </div>
    </div>
  </body>
</html>
```

## دمج Dropdown داخل Navbar

كيفية دمج القوائم المنسدلة داخل شريط التنقل العلوي.

- بناء أشرطة تنقل متقدمة Navbar
- دمج العناصر ضمن تصميم متناسق
- تنظيم الروابط بشكل هرمي واضح

## خلاصة الدرس وأفضل الممارسات

خلاصة شاملة لمهارات القوائم المنسدلة المتقدمة في CSS.

- استخدام right: 0 للمحاذاة الصحيحة
- تضمين الصور بكفاءة عالية
- تابعوا تطبيق الأكواد بأنفسكم
