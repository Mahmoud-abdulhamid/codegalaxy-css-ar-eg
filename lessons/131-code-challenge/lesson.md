# CSS Attribute Selectors Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_attribute_selectors.asp

## مقدمة تحدي محددات الخصائص

مرحبا بكم في تحدي محددات الخصائص في CSS لاختبار مهاراتنا العملية.

- اختبار مهارات CSS عبر تحدي عملي مباشر
- استهداف العناصر بدقة باستخدام Attribute Selectors
- تحسين القدرة على كتابة أكواد نظيفة وفعالة

## قواعد كتابة Attribute Selectors

نستخدم الأقواس المربعة لاستهداف العناصر بناء على سماتها مثل inputtype='text'.

```css
input[type="text"] {
  background-color: #f0f0f0;
}
a[target] {
  color: #ff0000;
}
```

## المطابقة التامة للقيم

نستخدم علامة التساوي للمطابقة التامة لقيمة Attribute داخل الأقواس المربعة.

```css
a[class="btn-primary"] {
  padding: 10px 20px;
  background-color: blue;
}
```

## البحث المتقدم باستخدام الرمز =

استخدام الرمز = لاستهداف القيم التي تبدأ بنص محدد مثل الروابط الآمنة.

```css
a[href^="https"] {
  color: green;
  font-weight: bold;
}
```

## البحث المتقدم باستخدام الرمز =

استخدام الرمز = لاستهداف العناصر التي تنتهي بقيمة معينة مثل ملفات pdf.

```css
a[href$="pdf"] {
  background: url(pdf-icon.png);
}
```

## البحث الشامل باستخدام الرمز *=

استخدام الرمز *= للبحث عن نص معين داخل القيمة في أي موقع.

```css
div[class*="col-"] {
  float: left;
  padding: 15px;
}
```

## أفضل الممارسات البرمجية

أفضل الممارسات تتطلب اختيار المحدد الأنسب لضمان أداء عالي وسرعة في المتصفح.

- اختر المحدد الأنسب لطبيعة العنصر بدقة
- تجنب التعقيد الزائد لتحسين أداء صفحة الويب
- اختبر الأكواد باستمرار في مختلف متصفحات الويب

## خلاصة التحدي والخطوات القادمة

نختتم التحدي بنجاح ونشجعكم على ممارسة الأكواد بأنفسكم.

- إتمام تحدي CSS Attribute Selectors بنجاح
- مراجعة الرموز المتقدمة مثل = و = و *=
- استعد للانتقال إلى الدروس القادمة في دورة CSS
