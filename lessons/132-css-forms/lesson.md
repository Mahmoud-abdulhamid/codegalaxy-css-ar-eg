# تنسيق النماذج في لغة CSS

المصدر: https://www.w3schools.com/css/css_forms.asp

## مقدمة تنسيق النماذج

مرحبا بكم في درس تنسيق النماذج باستخدام CSS وكيفية تحسين مظهر HTML forms.

- تستخدم لغة CSS لتنسيق HTML forms بشكل كامل
- تحسين المظهر العام لعناصر الإدخال في صفحات الويب
- رفع مستوى تجربة المستخدم أثناء تفاعله مع النماذج

## أهمية تنسيق النماذج

تساعد لغة CSS في تحسين مظهر النماذج بشكل جذري وجعلها أكثر عصرية.

- تحويل النماذج العادية إلى تصميمات عصرية
- جذب انتباه المستخدمين في مواقع الويب
- إضفاء طابع احترافي على واجهات المستخدم

## تنسيق حقول الإدخال

يمكنك باستخدام CSS تنسيق مختلف أنواع input types مثل text fields وpassword fields.

- تنسيق حقول النصوص text fields
- تنسيق حقول كلمات المرور password fields
- تنسيق مربعات الاختيار checkboxes

## تنسيق الأزرار والتسميات

يمكنك أيضا تنسيق input labels وform buttons لتحقيق تصميم متكامل.

- تنسيق تسميات حقول الإدخال input labels
- تنسيق أزرار النماذج form buttons
- خلق تناسق بصري كامل في النماذج

## خصائص CSS الشائعة

استخدام خصائص مثل width وpadding وmargin للتحكم في أبعاد ومسافات حقول الإدخال.

- استخدام خاصية width لتحديد العرض
- استخدام خاصية padding للمسافات الداخلية
- استخدام خاصية margin للمسافات الخارجية

## خصائص الحدود والألوان

استخدام border وborder-radius وbackground-color لتنسيق الحدود والألوان.

- تنسيق الحدود باستخدام border وborder-radius
- تغيير ألوان الخلفية باستخدام background-color
- تحديد حجم الخط وألوان النصوص باستخدام font-size وcolor

## مثال عملي لتنسيق النماذج

مثال عملي يوضح تطبيق خصائص CSS على حقول الإدخال في صفحات الويب.

```css
input[type=text] {
  width: 100%;
  padding: 12px 20px;
  margin: 8px 0;
  box-sizing: border-box;
  border: 2px solid #ccc;
  border-radius: 4px;
}
```

## خلاصة الدرس

خلاصة الدرس حول تنسيق النماذج في CSS ودعوة لتجربة الأكواد بأنفسكم.

- مراجعة شاملة لخصائص تنسيق النماذج
- أهمية تطبيق المعايير الحديثة في CSS
- تجربة الأكواد العملية عبر رابط المصدر
