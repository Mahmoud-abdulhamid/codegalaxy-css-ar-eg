# CSS Units Explained

المصدر: https://www.w3schools.com/css/css_units.asp

## مقدمة في CSS Units

مقدمة حول استخدام CSS Units لتحديد أبعاد العناصر في صفحات الويب.

- تستخدم CSS Units لتحديد الطول والحجم
- تؤثر على خصائص مثل font-size و width
- تنقسم إلى نوعين رئيسيين

## فهم Absolute Units

شرح Absolute Units مثل px التي تتميز بالثبات وعدم التغير مع أحجام الشاشات.

- قيم ثابتة لا تتغير
- px هي الوحدة الأكثر استخداما
- غير مناسبة للتصاميم المتجاوبة
- تستخدم غالبا في تنسيقات الطباعة

## قوة Relative Units

تعتمد Relative Units على عناصر أخرى مما يجعلها مثالية للتصميم المتجاوب.

- تعتمد على أبعاد عناصر أخرى
- مثالية للتصميم المتجاوب
- أهم الوحدات هي em و rem

## تطبيق عملي للأكواد

مثال برمجي يوضح الفرق في كتابة القيم باستخدام وحدات القياس المختلفة.

```css
h1 {
  font-size: 32px;
}
p {
  font-size: 1.5rem;
  margin: 10px;
  padding: 2em;
}
```

## تحليل الكود البرمجي

شرح تفصيلي لكل سطر في الكود وكيفية تأثير الوحدات على العناصر.

- 32px: حجم ثابت للعنوان
- 1.5rem: حجم نسبي للفقرة
- 2em: مساحة داخلية نسبية

## معاينة المخرجات

النتيجة المتوقعة للعناصر عند استخدام وحدات القياس المختلفة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>عنوان ثابت</h1>
    <p>نص متجاوب يعتمد على rem</p>
  </body>
</html>
```

## أفضل الممارسات

نصائح هندسية لاستخدام الوحدات بشكل صحيح في مشاريع الويب.

- فضل استخدام rem للتصميم المتجاوب
- استخدم px فقط للأحجام التي لا يجب أن تتغير
- اختبر التصميم على أحجام شاشات مختلفة

## خلاصة الدرس

ملخص سريع لما تم تعلمه في درس وحدات القياس في CSS.

- Absolute units ثابتة
- Relative units مرنة
- استخدم rem لبناء مواقع متجاوبة
