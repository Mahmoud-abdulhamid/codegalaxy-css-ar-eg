# CSS Absolute Units

المصدر: https://www.w3schools.com/css/css_units_absolute.asp

## مقدمة حول Absolute Units

مرحبا بكم في درس CSS الجديد حول Absolute Units، وهي وحدات قياس ثابتة لا تتغير بتغير حجم الشاشة.

- Absolute Units هي وحدات قياس ثابتة
- لا تتغير بتغير حجم الشاشة
- وحدة px هي الأكثر استخداما
- تستخدم غالبا في الطباعة

## مفهوم px في التصميم

استخدام px يمنحك تحكما كاملا في حجم النص، لكنه قد يواجه صعوبة في التجاوب مع مختلف أحجام الشاشات.

- px تمنح تحكما دقيقا في حجم النص
- لا تتجاوب بشكل جيد مع الشاشات المختلفة
- لا يمكن للمستخدم تعديل حجم النص عبر المتصفح
- يمكن للمستخدم استخدام أداة zoom

## تطبيق عملي باستخدام px

تطبيق عملي لتحديد حجم الخط باستخدام px. تذكر أنه لا يجب ترك مسافة بين الرقم والوحدة.

```css
h1 {
  font-size: 40px;
}
h2 {
  font-size: 30px;
}
p {
  font-size: 17px;
}
```

## شرح تفصيلي للكود

شرح القيم المستخدمة في الكود: 40px لـ h1، و30px لـ h2، و17px لـ p، مما يضمن ثبات الحجم في كل مكان.

## معاينة المخرجات

هكذا تظهر العناصر في المتصفح بأحجام ثابتة ومحددة بدقة عند استخدام وحدات px.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>Header 1</h1>
    <h2>Header 2</h2>
    <p>This is a paragraph.</p>
  </body>
</html>
```

## أفضل الممارسات

نصيحة: استخدم Relative Units مثل em أو rem بدلا من Absolute Units لتحسين تجاوب الموقع.

- استخدم Relative Units للتصميم المتجاوب
- جرب استخدام em و rem
- تجنب px في التصاميم التي تتطلب مرونة
- استخدم Absolute Units فقط للطباعة

## خلاصة الدرس

خلاصة: Absolute Units ثابتة ولا تتغير. جرب الأكواد بنفسك عبر الرابط في الوصف.

- Absolute Units ثابتة وغير مرنة
- px هي الوحدة الأكثر استخداما
- استخدم Relative Units للمواقع المتجاوبة
- راجع الرابط في الوصف للتطبيق العملي
