# CSS Relative Units

المصدر: https://www.w3schools.com/css/css_units_relative.asp

## مقدمة في Relative Units

تعد Relative Units الخيار الأفضل لبناء صفحات ويب متجاوبة ومرنة.

- Relative Units تعتمد على خصائص أخرى
- تضمن مرونة التصميم عبر الشاشات المختلفة
- تعتبر em و rem أدوات أساسية للمطورين

## فهم وحدة em

وحدة em ترتبط بحجم الخط الخاص بالعنصر الأب.

- em تعتمد على font-size للعنصر الأب
- تسمح للمستخدم بتعديل حجم الخط في المتصفح
- مثالية لضبط التباعد والخطوط بشكل نسبي

## تطبيق عملي باستخدام em

تطبيق عملي لاستخدام em في تحديد أحجام الخطوط.

```css
body {
  font-size: 16px;
}
h1 {
  font-size: 2.5em;
}
h2 {
  font-size: 1.875em;
}
p {
  font-size: 1em;
}
```

## فهم وحدة rem

وحدة rem ترتبط دائما بحجم الخط الخاص بالعنصر html.

- rem تعتمد على font-size للعنصر html
- لا تتأثر بموقع العنصر داخل المستند
- تسهل عملية جعل التصميم متجاوبا بالكامل

## تطبيق عملي باستخدام rem

تطبيق عملي لاستخدام rem في تحديد أحجام الخطوط.

```css
html {
  font-size: 16px;
}
h1 {
  font-size: 2.5rem;
}
h2 {
  font-size: 1.875rem;
}
p {
  font-size: 1rem;
}
```

## معاينة المخرجات

نتائج تطبيق وحدات القياس النسبية على عناصر الصفحة.

## خلاصة الدرس

استخدم rem للأحجام العامة و em للعناصر المعتمدة على السياق.

- rem توفر تحكما مركزيا في أحجام الخطوط
- em توفر مرونة داخلية للعناصر
- استخدم الرابط في الوصف لتجربة الأكواد
