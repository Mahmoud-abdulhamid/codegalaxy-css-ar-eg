# CSS Inheritance Challenge

المصدر: https://www.w3schools.com/css/css_challenges_inheritance.asp

## مقدمة حول CSS Inheritance

مرحبا بكم في درس CSS Inheritance. سنتعرف اليوم على مفهوم التورث وكيفية انتقال الخصائص من العناصر الآباء إلى الأبناء.

- مفهوم Inheritance في CSS
- كيفية انتقال الخصائص بين العناصر
- أهمية فهم التورث في تصميم صفحات الويب

## قواعد التورث في CSS

تنتقل خصائص مثل color و font-family تلقائيا، بينما لا تورث خصائص مثل border أو margin في CSS.

## تطبيق عملي على Inheritance

عند تحديد لون للنص في body، ترث العناصر الداخلية مثل h1 و p هذا اللون تلقائيا.

```css
body {
  color: blue;
  font-family: Arial;
}
h1 {
  /* يرث اللون من body */
}
p {
  /* يرث اللون من body */
}
```

## معاينة النتائج

يظهر النص باللون الأزرق في المتصفح، مما يثبت نجاح عملية التورث للخاصية color.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <h1>عنوان الصفحة</h1>
    <p>هذا نص فقرة يرث اللون.</p>
  </body>
</html>
```

## أفضل الممارسات

استخدم التورث للخصائص العامة، وقم بتخصيص العناصر الفردية عند الحاجة لضمان كود نظيف.

- حدد الخصائص العامة في body
- استخدم التورث لتقليل تكرار الكود
- خصص العناصر الفردية عند الحاجة
- اختبر التورث دائما في المتصفح

## خلاصة الدرس

لقد تعلمنا أساسيات التورث في CSS. جربوا الأكواد بأنفسكم عبر الرابط المرفق في الوصف.

- فهم التورث في CSS
- الفرق بين الخصائص الموروثة وغير الموروثة
- تطبيق التورث في المشاريع الحقيقية
