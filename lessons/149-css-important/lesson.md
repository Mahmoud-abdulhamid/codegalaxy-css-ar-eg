# قاعدة المهم في لغة CSS

المصدر: https://www.w3schools.com/css/css_important.asp

## مقدمة حول الأهمية القصوى

مرحبا بكم في درس قاعدة important في لغة CSS وكيفية منح القيمة الأولوية القصوى.

- منح الأولوية القصوى لخصائص CSS
- تجاوز جميع قواعد التنسيق السابقة
- فهم تأثير الأولوية على عناصر الويب

## الصيغة البرمجية لقاعدة important

تضاف الكلمة المفتاحية important قبل الفاصلة المنقوطة في إعلان CSS.

```css
selector {
  property: value !important;
}
```

## مثال عملي وتجاوز التنسيقات

تتجاوز القاعدة جميع محددات التحديد الأخرى لتطبيق اللون المطلوب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    p {
    background-color: yellow !important;
    }
    #myid {
    background-color: blue;
    }
    .myclass {
    background-color: gray;
    }
  </body>
</html>
```

## مخاطر الإفراط في الاستخدام

استخدم القاعدة بحذر لتجنب تعقيد ملفات التنسيق وصعوبة تتبع الأخطاء.

- تجعل تتبع الأخطاء أمرا صعبا
- تزيد من تعقيد ملفات التنسيق الضخمة
- تصعب تجاوز التنسيقات لاحقا

## حالات الاستخدام العادل والمبرر

تكون القاعدة مفيدة في تجاوز تنسيقات أنظمة إدارة المحتوى.

- تجاوز تنسيق لا يمكن تعديله بطريقة أخرى
- التعامل مع ملفات أنظمة إدارة المحتوى CMS
- احترام تفضيلات المستخدم وتقليل الحركات

## احترام تفضيلات المستخدم

استخدام القاعدة لتعطيل الحركات للمستخدمين الذين يعانون من حساسية الحركة.

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
```

## تنسيق أزرار الروابط

فرض مظهر موحد وثابت لجميع أزرار الروابط بغض النظر عن الحاويات.

```css
a.button {
  background-color: #8c8c8c !important;
  color: white !important;
  padding: 5px !important;
  border: 1px solid black !important;
  text-decoration: none !important;
}
```

## خلاصة الدرس

خلاصة استخدام قاعدة الأهمية في CSS ودعوة لمتابعة الدروس القادمة.

- استخدم الأداة بحكمة ودون إفراط
- احرص على تنظيم هيكل ملفات التنسيق
- تابع معنا الدروس القادمة في دورة CSS
