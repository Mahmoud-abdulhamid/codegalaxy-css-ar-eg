# دورة CSS - دوال الحسابات الرياضية CSS Math Functions

المصدر: https://www.w3schools.com/css/css_math_functions.asp

## مقدمة حول الدوال الرياضية في CSS

تسمح دوال الحسابات الرياضية في CSS باستخدامهاتعابير رياضية كقيم للخصائص.

- فهم الدوال الرياضية في CSS
- استخدام التعبيرات الرياضية كقيم للخصائص
- التعرف على دوال calc و max و min و clamp

## دالة calc الحسابية

دالة calc تقوم بإجراء العمليات الرياضية ودعم دمج الوحدات المختلفة مثل pixels و percentages.

- إجراء حسابات رياضية معقدة
- دعم عمليات الجمع والطرح والضرب والقسمة
- دمج وحدات قياس مختلفة مثل pixels و percentages

## مثال عملي على دالة calc

استخدام calc لتحديد عرض وارتفاع العنصر div مع دمج الوحدات المختلفة.

```css
#div1 {
  margin: auto;
  width: calc(100% - 100px);
  height: calc(30vh + 50px);
  border: 1px solid black;
  padding: 10px;
}
```

## دالة max ودالة min

دالة max تختار القيمة الأكبر بينما دالة min تختار القيمة الأصغر من قائمة القيم.

- دالة max لاختيار القيمة الأكبر من بين عدة قيم
- دالة min لاختيار القيمة الأصغر من بين عدة قيم
- استخدام القيم المفصولة بفواصل داخل الدوال

## مثال على دالة max

استخدام دالة max لتعيين العرض إلى القيمة الأكبر بين 50 أو 300px.

```css
#div1 {
  height: 100px;
  width: max(50%, 300px);
  border: 1px solid black;
  padding: 10px;
}
```

## دالة clamp المتجاوبة

دالة clamp تستخدم لضبط قيمة متجاوبة بين حد أدنى وقيمة مفضلة وحد أقصى.

- ضبط قيمة متجاوبة تتكيف مع حجم الشاشة
- تحتوي على ثلاثة معاملات: الحد الأدنى والمفضل والأقصى
- تحسين تجربة التصميم المتجاوب Responsive Design

## مثال شامل على دالة clamp

تطبيق دالة clamp على حجم الخط وعرض العناصر لضمان تجاوب مثالي.

```css
h2 {
  font-size: clamp(1.5rem, 5vw, 3rem);
}
div {
  border: 1px solid green;
  padding: 10px;
  font-size: clamp(1rem, 2.5vw, 2rem);
  width: clamp(200px, 50%, 600px);
}
```

## خلاصة الدرس

ملخص الدوال الرياضية في CSS وكيفية استخدامها لبناء تصميمات مرنة.

- استخدام calc للعمليات الحسابية المباشرة
- استخدام max و min لاختيار القيم القصوى والدنيا
- استخدام clamp للتحكم المتجاوب بالقياسات والنصوص
- مراجعة المرجع الشامل لدوال CSS للمزيد من التفاصيل
