# تحدي تصميم صفحات الويب باستخدام CSS

المصدر: https://www.w3schools.com/css/css_challenges_website_layout.asp

## مقدمة في تحدي تصميم الويب

مرحبا بكم في تحدي تصميم صفحات الويب باستخدام CSS لاختبار مهاراتكم في التنسيق.

- فهم هيكل صفحة الويب
- تطبيق CSS في التخطيط
- حل تحديات البرمجة
- تحسين مهارات التصميم

## مفاهيم تخطيط صفحات الويب

تعتمد عملية التخطيط على توزيع العناصر داخل body باستخدام خصائص CSS مثل display وflexbox.

- استخدام display للتحكم في العرض
- تطبيق float لتحديد المواقع
- استخدام flexbox للتخطيط المرن
- تنظيم العناصر داخل body

## هيكل الكود الأساسي

هيكل المستند يبدأ بـ DOCTYPE HTML مع تنظيم المحتوى داخل head وbody.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Layout Challenge</title>
  </head>
  <body>
    <header>Header</header>
    <nav>Navigation</nav>
    <main>Content</main>
    <footer>Footer</footer>
  </body>
</html>
```

## تنسيق التخطيط بـ CSS

نستخدم CSS لتنسيق العناصر وتحديد الأبعاد والألوان لكل جزء في الصفحة.

```css
header, footer {
  background: #333;
  color: white;
  padding: 20px;
}
nav {
  float: left;
  width: 20%;
}
main {
  float: left;
  width: 80%;
}
```

## معاينة النتيجة

تظهر النتيجة النهائية بتخطيط منظم يضم الرأس والقائمة والمحتوى والقدم.

```text
-------------------
|      Header     |
-------------------
| Nav |  Content  |
-------------------
|      Footer     |
-------------------
```

## أفضل الممارسات البرمجية

استخدام Semantic Tags يحسن من فهم المتصفح ومحركات البحث لهيكلية الصفحة.

- استخدام Semantic Tags
- تنظيم ملفات CSS
- التحقق من توافق المتصفحات
- كتابة كود نظيف وقابل للصيانة

## خاتمة التحدي

شكرا لمتابعتكم، ندعوكم لتجربة الأكواد وتطوير مهاراتكم في تصميم الويب.

- طبق الأكواد بنفسك
- طور مهاراتك في CSS
- راجع الرابط في الوصف
- تابع دروسنا القادمة
