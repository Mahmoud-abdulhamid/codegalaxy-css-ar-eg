# CSS Rounded Corners Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_rounded_corners.asp

## مقدمة حول Rounded Corners

مرحبا بكم في درس CSS الجديد. سنتعلم اليوم كيفية إنشاء زوايا دائرية للعناصر باستخدام خاصية border-radius لتحسين تصميم صفحات الويب.

- خاصية border-radius تمنح العناصر زوايا دائرية
- تستخدم هذه الخاصية في CSS3 بشكل واسع
- تساعد في جعل التصميم أكثر حداثة وجاذبية
- تطبيق عملي عبر تحدي برمجي بسيط

## مفهوم border-radius

تعمل خاصية border-radius على تدوير زوايا العنصر. يمكن تحديد القيمة بالبكسل أو النسبة المئوية للتحكم في مدى انحناء الزاوية.

- القيمة الافتراضية هي 0
- يمكن استخدام وحدات مثل px أو em أو
- تؤثر على خلفية العنصر والحدود معا
- يمكن تطبيقها على زاوية واحدة أو جميع الزوايا

## كود تطبيق الزوايا الدائرية

نستخدم خاصية border-radius بقيمة 25px لتطبيق انحناء متساو على جميع زوايا العنصر div.

```css
div {
  width: 200px;
  height: 100px;
  background-color: blue;
  border-radius: 25px;
}
```

## معاينة النتيجة

تظهر النتيجة في المتصفح كعنصر مستطيل بزوايا دائرية ناعمة، مما يضفي لمسة عصرية على التصميم.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div style="width:200px; height:100px; background:blue; border-radius:25px;">
      <!-- Rounded Box -->
    </div>
  </body>
</html>
```

## تخصيص الزوايا بشكل فردي

يمكن التحكم في كل زاوية على حدة عبر تمرير أربع قيم لخاصية border-radius.

```css
div {
  /* top-left, top-right, bottom-right, bottom-left */
  border-radius: 10px 20px 30px 40px;
}
```

## أفضل الممارسات

استخدم قيما متناسقة للحصول على تصميم احترافي، وتأكد من اختبار التوافقية عبر المتصفحات المختلفة.

- استخدم قيم متناسبة مع حجم العنصر
- جرب استخدام النسبة المئوية للدوائر الكاملة
- اختبر التصميم على Chrome و Firefox و Edge
- حافظ على بساطة التصميم

## خلاصة الدرس

تعلمنا اليوم كيفية استخدام border-radius. ندعوكم لتجربة التحدي البرمجي عبر الرابط في الوصف لتطوير مهاراتكم.

- تعلمنا أساسيات border-radius
- طبقنا الزوايا الدائرية على العناصر
- تعرفنا على تخصيص الزوايا الفردية
- شجعنا على الممارسة العملية
