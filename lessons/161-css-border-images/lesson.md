# شرح خاصية CSS border-image بالتفصيل

المصدر: https://www.w3schools.com/css/css3_border_images.asp

## مقدمة عن CSS border-image

تعرف على كيفية استخدام خاصية border-image لتحديد صورة كإطار للعناصر بدلا من الحدود التقليدية.

- استخدام الصور كإطارات متقدمة للعناصر في صفحات الويب
- تجاوز الحدود العادية والتقليدية في التصميم
- إمكانية تخصيص الأشكال والألوان عبر ملفات الصور الخارجية

## آلية عمل خاصية border-image

تقوم الخاصية بتقسيم الصورة إلى تسعة أقسام وتوزع الزوايا والأجزاء الوسطى بناء على التوجيهات.

- تقسيم الصورة إلى تسعة أقسام مثل رقعة اللعبة
- تثبيت الزوايا في الأماكن المخصصة لها تماما
- تكرار أو تمدد الأجزاء الوسطى لملء المساحة المتاحة

## الشروط الأساسية والمتطلبات

يجب تعيين خاصية border العادية أولا مع لون شفاف لكي تعمل خصائص الإطار المصور بنجاح.

- ضرورة تحديد border عادي لا يقل عن سمك معين
- استخدام قيمة transparent للون الحد الأساسي
- تحديد مصدر الصورة بدقة عبر دالة url

## مثال استخدام round مع border-image

نستعرض كود CSS لاستخدام صورة الإطار مع قيمة round لتكرار الجزء الأوسط.

```css
#borderimg {
  border: 10px solid transparent;
  padding: 15px;
  border-image: url(border.png) 30 round;
}
```

## مثال استخدام stretch مع border-image

تتيح قيمة stretch تمدد الجزء الأوسط من الصورة لملء الفراغ بدلا من تكراره.

```css
#borderimg {
  border: 10px solid transparent;
  padding: 15px;
  border-image: url(border.png) 30 stretch;
}
```

## تغيير قيم التقطيع Slice Values

تغيير قيم التقطيع بالبكسل أو النسبة المئوية يؤثر بشكل جذري على شكل الإطار النهائي.

```css
#borderimg1 {
  border: 10px solid transparent;
  padding: 15px;
  border-image: url(border.png) 50 round;
}
#borderimg2 {
  border: 10px solid transparent;
  padding: 15px;
  border-image: url(border.png) 20% round;
}
```

## أفضل الممارسات وخلاصة الدرس

احرص على استخدام الحدود الشفافة واختيار قيم التقطيع المناسبة للحصول على أفضل تصميم.

- استخدام border الشفاف كمتطلب أساسي للخاصية
- تجربة نسب مئوية وبكسلات مختلفة للوصول للشكل المطلوب
- اختبار التوافقية والتصاميم على متصفحات الويب المختلفة
