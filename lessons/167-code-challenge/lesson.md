# CSS Backgrounds Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_backgrounds.asp

## مقدمة في تحدي الخلفيات

مرحبا بكم في درس تحدي CSS Backgrounds لاختبار مهاراتكم في تنسيق خلفيات عناصر الويب.

- مراجعة خصائص الخلفيات في CSS
- تطبيق تحدي عملي لتعزيز الفهم
- تحسين المظهر البصري لعناصر HTML

## المفاهيم الأساسية للخلفيات

نستخدم خصائص مثل background-color و background-image للتحكم في مظهر خلفيات العناصر.

## هيكل الكود الأساسي

نبدأ بتجهيز عنصر div وتطبيق تنسيقات CSS الأساسية عليه.

```css
.box {
  width: 300px;
  height: 200px;
  background-color: lightblue;
  border: 2px solid black;
}
```

## خصائص متقدمة للخلفية

استخدام خصائص متقدمة مثل background-repeat و background-position للتحكم الدقيق في الخلفية.

```css
.box {
  background-image: url('bg.png');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

## معاينة النتيجة

معاينة النتيجة النهائية للعنصر بعد تطبيق تنسيقات الخلفية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="box">
      <h1>محتوى العنصر</h1>
    </div>
  </body>
</html>
```

## أفضل الممارسات

أفضل الممارسات تشمل مراعاة التباين بين النص والخلفية وتحسين حجم الصور.

- استخدام تباين ألوان مناسب
- تحسين حجم الصور لسرعة التحميل
- اختبار التجاوب مع مختلف الشاشات

## خلاصة الدرس

خلاصة الدرس: تعلم التحكم في الخلفيات باستخدام CSS. جرب الأكواد بنفسك عبر الرابط في الوصف.

- تمت تغطية خصائص الخلفية الأساسية
- تم شرح كيفية تطبيق التنسيقات
- رابط التحدي متاح في الوصف
