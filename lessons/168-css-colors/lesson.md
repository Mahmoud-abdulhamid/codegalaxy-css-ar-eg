# التحكم في الألوان والشفافية باستخدام CSS

المصدر: https://www.w3schools.com/css/css3_colors.asp

## مقدمة في ألوان CSS

مرحبا بكم في درس التحكم في الألوان والشفافية باستخدام CSS.

- دعم CSS لأكثر من 140 اسما للألوان
- استخدام قيم RGB و HEX و HSL
- إضافة قناة الشفافية alpha channel

## فهم قيم RGBA

تستخدم قيم RGBA لتحديد الشفافية عبر قناة alpha.

```css
#p1 {
  background-color: rgba(255, 0, 0, 0.3);
}
#p2 {
  background-color: rgba(0, 255, 0, 0.3);
}
#p3 {
  background-color: rgba(0, 0, 255, 0.3);
}
```

## استخدام قيم HEXA

تسمح قيم HEXA بإضافة الشفافية مباشرة في كود اللون.

- التنسيق: #rrggbbaa
- 00 تعني شفافية كاملة
- FF تعني غير شفاف إطلاقا
- 80 تعني شفافية 50

## التعامل مع HSLA

نموذج HSLA يجمع بين تدرج اللون والتشبع والإضاءة مع الشفافية.

```css
#p1 {
  background-color: hsla(120, 100%, 50%, 0.3);
}
#p2 {
  background-color: hsla(120, 100%, 75%, 0.3);
}
#p3 {
  background-color: hsla(120, 100%, 25%, 0.3);
}
```

## خاصية opacity

خاصية opacity تؤثر على العنصر بالكامل بما فيه النص.

```css
#p1 {
  background-color: rgb(255,0,0); opacity: 0.6;
}
#p2 {
  background-color: rgb(0,255,0); opacity: 0.6;
}
```

## خلاصة الدرس

خلاصة: اختر الطريقة المناسبة للشفافية بناء على احتياجك التصميمي.

- RGBA/HSLA للتحكم في لون الخلفية فقط
- opacity للتحكم في العنصر بالكامل
- تذكر دائما تجربة الأكواد في المتصفح
