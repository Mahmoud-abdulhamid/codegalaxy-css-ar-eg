# CSS Gradients Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_gradients.asp

## مقدمة في CSS Gradients

مرحبا بكم في درس CSS Gradients، سنتعلم اليوم كيفية بناء التدرجات اللونية لتصميم واجهات الويب.

- CSS Gradients تسمح بدمج لونين أو أكثر
- تستخدم لإنشاء خلفيات احترافية
- تغني عن استخدام الصور الثابتة
- تزيد من سرعة تحميل صفحات الويب

## أنواع التدرجات في CSS

تتنوع التدرجات في CSS بين Linear و Radial و Conic Gradients، حيث يوفر كل نوع تأثيرا بصريا فريدا.

- linear-gradient: تدرج في اتجاه خطي
- radial-gradient: تدرج من المركز للخارج
- conic-gradient: تدرج حول نقطة مركزية

## كتابة كود التدرج الخطي

نستخدم خاصية background مع الدالة linear-gradient لتطبيق التدرج اللوني على العناصر.

```css
.gradient-box {
  width: 300px;
  height: 200px;
  background: linear-gradient(to right, red, yellow);
}
```

## شرح تفصيلي للكود

تحدد القيمة to right اتجاه التدرج، بينما تقوم الألوان المحددة بإنشاء الانتقال اللوني السلس.

- to right: يحدد اتجاه التدرج
- red: اللون الأول للبداية
- yellow: اللون الثاني للنهاية
- background: الخاصية المسؤولة عن التدرج

## معاينة النتيجة

تظهر النتيجة في المتصفح كمربع ملون بتدرج انسيابي من الأحمر إلى الأصفر.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="gradient-box"></div>
  </body>
</html>
```

## أفضل الممارسات

استخدم ألوانا متناسقة، ويمكنك دمج أكثر من لونين للحصول على تأثيرات بصرية احترافية.

- استخدم ألوانا متناغمة
- جرب إضافة ألوان متعددة
- تحقق من التباين للنصوص فوق التدرج
- استخدم أدوات توليد التدرجات عبر الويب

تعلمنا اليوم أساسيات CSS Gradients. لا تنسوا تجربة التحديات البرمجية عبر الرابط في الوصف.

- راجعنا أنواع التدرجات
- طبقنا كود التدرج الخطي
- ناقشنا أفضل الممارسات
