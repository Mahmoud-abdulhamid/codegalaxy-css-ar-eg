# CSS Shadow Effects

المصدر: https://www.w3schools.com/css/css3_shadows.asp

## مقدمة في تأثيرات الظلال

تسمح خاصية text-shadow بإضافة تأثيرات ظل احترافية للنصوص في صفحات الويب.

- خاصية text-shadow تمنح النصوص عمقا بصريا
- يمكن التحكم في اتجاه الظل ولونه ودرجة التمويه
- تستخدم لتحسين تجربة المستخدم في واجهات الويب

## القواعد الأساسية لخاصية text-shadow

تتطلب خاصية text-shadow تحديد الإزاحة الأفقية والعمودية كقيم أساسية.

```css
h1 {
  text-shadow: 2px 2px red;
}
```

## إضافة التمويه للظلال

القيمة الثالثة في text-shadow تحدد درجة التمويه (blur) للظل.

```css
h1 {
  text-shadow: 2px 2px 5px red;
}
```

## تأثيرات النيون المتوهجة

لإنشاء تأثير نيون، نضبط الإزاحة على صفر ونزيد قيمة التمويه.

```css
h1 {
  text-shadow: 0 0 3px #ff0000;
}
```

## استخدام ظلال متعددة

يمكن دمج عدة ظلال في خاصية واحدة باستخدام الفاصلة.

```css
h1 {
  text-shadow: 0 0 3px #ff0000, 0 0 5px #0000ff;
}
```

## إنشاء حدود نصية بالظلال

يمكن محاكاة حدود النص باستخدام عدة ظلال دقيقة الاتجاه.

```css
h1 {
  color: coral;
  text-shadow: -1px 0 black, 0 1px black, 1px 0 black, 0 -1px black;
}
```

## خلاصة الدرس

جرب تغيير قيم الإزاحة واللون والتمويه للحصول على تأثيرات فريدة.

- استخدم text-shadow لإضافة عمق للنصوص
- جرب دمج الظلال للحصول على تأثيرات نيون
- استخدم الظلال لإنشاء حدود نصية مبتكرة
- راجع الرابط في الوصف لمزيد من الأمثلة
