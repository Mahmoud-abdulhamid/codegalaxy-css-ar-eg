# CSS Shadows Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_shadows.asp

## مقدمة تحدي الظلال في CSS

مرحبا بكم في هذا التحدي العملي لاختبار مهارات تصميم وتنسيق Shadows في لغة CSS.

- اختبار المهارات العملية في لغة CSS
- تطبيق خصائص Shadows باحترافية
- تحسين المظهر البصري لعناصر الويب

## فهم خصائص box-shadow و text-shadow

تعتمد خصائص الظلال على خاصية box-shadow للعناصر وخاصية text-shadow للنصوص.

- خاصية box-shadow لتنسيق حدود العناصر
- خاصية text-shadow لتنسيق النصوص وإبرازها
- تحديد القيم مثل المسافة واللون والتمويه

## كتابة كود التحدي الأول

كتابة كود CSS لتطبيق خاصية box-shadow على عنصر الـ div داخل صفحة الويب.

```css
.box {
  width: 200px;
  height: 100px;
  background-color: #3498db;
  box-shadow: 5px 5px 15px rgba(0, 0, 0, 0.3);
}
```

## تنسيق النصوص باستخدام text-shadow

استخدام خاصية text-shadow لتنسيق نصوص الويب وإضافة عمق بصري جذاب.

```css
h1 {
  font-size: 40px;
  color: #2c3e50;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
```
