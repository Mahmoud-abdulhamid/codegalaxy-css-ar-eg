# شرح CSS 2D Transforms وتطبيق الدوال الأساسية

المصدر: https://www.w3schools.com/css/css3_2dtransforms.asp

## مقدمة حول CSS 2D Transforms

مرحبا بكم في درس CSS 2D Transforms وكيفية تطبيق التحولات على عناصر الويب.

- تستخدم خاصية transform لتطبيق تحولات 2D أو 3D
- تتيح الخاصية تدوير وتحريك وتغيير حجم العناصر
- تدعم لغة CSS العديد من دوال التحويل الأساسية

## التعرف على دوال التحويل 2D Transforms Functions

تتيح خاصية transform استخدام عدة دوال للتحكم في هيئة وموقع عناصر الويب.

- دالة translate لتحريك العناصر من موضعها الحالي
- دالة rotate لتدوير العناصر حسب الدرجات المحددة
- دوال إضافية مثل scale و skew لتغيير الحجم والميل

## دالة التحريك translate() Function

تقوم دالة translate بنقل العنصر من موضعها الحالي حسب محوري X و Y.

- تتحكم القيمة الأولى في الحركة على محور X الأفقي
- تتحكم القيمة الثانية في الحركة على محور Y العمودي
- يمكن استخدام وحدات قياس مختلفة مثل pixels

## مثال برمجي على دالة translate

مثال برمجي لتحريك عنصر div بمقدار 50px أفقيا و 100px عموديا.

```css
div {
  transform: translate(50px, 100px);
}
```

## دالة التدوير rotate() Function

دالة rotate تقوم بتدوير العنصر اتجاه عقارب الساعة أو عكسها بزوايا محددة.

- تدوير العناصر باتجاه عقارب الساعة باستخدام قيم موجبة
- استخدام وحدة deg للإشارة إلى الدرجات الزاوية
- تطبيق تأثيرات بصرية جذابة على عناصر صفحات الويب

## مثال تدوير العنصر باتجاه عقارب الساعة

تدوير عنصر div بمقدار 20 درجة مع اتجاه عقارب الساعة.

```css
div {
  transform: rotate(20deg);
}
```

## استخدام القيم السالبة في دالة rotate

استخدام القيم السالبة لتدوير العنصر عكس اتجاه عقارب الساعة.

```css
div {
  transform: rotate(-20deg);
}
```

## خلاصة الدرس ودعوة للتجربة

خلاصة درس CSS 2D Transforms ودعوة لتجربة الأكواد بأنفسكم.

- فهمنا تطبيق خاصية transform على عناصر الويب
- طبقنا دالة translate لتحريك العناصر بدقة
- استخدمنا دالة rotate بالقيم الموجبة والسالبة
- نلتقي في الدرس القادم لمتابعة دوال scale و skew
