# CSS 2D Transform Scale

المصدر: https://www.w3schools.com/css/css3_2dtransforms_scale.asp

## مقدمة حول تحويلات scale

مرحبا بكم في درس جديد من دورة CSS حول تحويلات scale للأبعاد.

- التعرف على دوال التحويل ثنائي الأبعاد
- فهم دالة scale وتأثيرها على العرض والارتفاع
- تطبيق قيم التكبير والتصغير على عناصر الويب

## دالة scale الأساسية

تقوم دالة scale بتكبر أو تصغير حجم العنصر حسب قيم العرض والارتفاع.

- تستقبل دالة scale وسيطين width و height
- تؤثر على أبعاد العنصر النسبية
- تستخدم لتغيير الحجم دون التأثير على التخطيط

## مثال تكبير الأبعاد

يوضح هذا المثال كيفية مضاعفة العرض مرتين والارتفاع ثلاث مرات.

```css
div {
  transform: scale(2, 3);
}
```

## مثال تصغير الأبعاد

يمكن تصغير العناصر باستخدام قيم عشرية مثل نصف الحجم الأصلي.

```css
div {
  transform: scale(0.5, 0.5);
}
```

## دالة scaleX للعرض فقط

تقوم دالة scaleX بتغيير عرض العنصر فقط دون الارتفاع.

```css
div {
  transform: scaleX(2);
}
```

## تصغير العرض بـ scaleX

نستخدم scaleX بالقيمة zero point five لتصغير عرض العنصر إلى النصف.

```css
div {
  transform: scaleX(0.5);
}
```

## دالة scaleY للارتفاع فقط

تقوم دالة scaleY بالتحكم في ارتفاع العنصر رأسيا فقط.

```css
div {
  transform: scaleY(3);
}
```

## خلاصة تحويلات scale

خلاصة استخدام دوال scale و scaleX و scaleY في تصميم الويب الحديث.

- دالة scale تعدل العرض والارتفاع معا
- scaleX تخص العرض الأفقي فقط
- scaleY تخص الارتفاع الرأسي فقط
- قيم عشرية للتصغير وقيم صحيحة للتكبير
