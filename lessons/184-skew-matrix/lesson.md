# CSS 2D Transform Skew and Matrix Functions

المصدر: https://www.w3schools.com/css/css3_2dtransforms_skew.asp

## مقدمة حول تحويلات الإمالة ثنائية الأبعاد في CSS

مرحبا بكم في درس تحويلات الإمالة ثنائية الأبعاد في CSS ودوال Skew و Matrix.

- التعرف على دوال skew المختلفة في CSS
- إمالة العناصر على محور X ومحور Y
- استخدام دالة matrix لدمج التحويلات
- تطبيق التحويلات ثنائية الأبعاد باحترافية

## شرح دالة skewX لإمالة العناصر أفقيا

تستخدم دالة skewX لإمالة العناصر على المحور الأفقي X بالزاوية المحددة.

```css
div {
  transform: skewX(20deg);
}
```

## شرح دالة skewY لإمالة العناصر عموديا

تقوم دالة skewY بإمالة العناصر على المحور الرأسي Y بالزاوية المحددة.

```css
div {
  transform: skewY(20deg);
}
```

## استخدام دالة skew للجمع بين المحورين

تسمح دالة skew بإمالة العناصر على محوري X و Y في نفس الوقت.

```css
div {
  transform: skew(20deg, 10deg);
}
```

## تطبيق دالة skew بمعامل واحد

إذا لم يتم تحديد المعامل الثاني لدالة skew، فسيتم اعتباره صفرا وتطبيق الإمالة أفقيا.

```css
div {
  transform: skew(20deg);
}
```

## التعرف على دالة matrix الشاملة

تدمج دالة matrix جميع دوال التحويل ثنائي الأبعاد في دالة واحدة بستة معاملات.

- تجمع كافة وظائف التحويل ثنائي الأبعاد
- تستقبل ستة معاملات رياضية دقيقة
- تدعم التدوير، التحجيم، التحريك والإمالة
- مفهوم Matrix(scaleX, skewY, skewX, scaleY, translateX, translateY)

## تطبيق عملي على دالة matrix

مثال عملي لاستخدام دالة matrix مع ستة معاملات رياضية مختلفة للتحويل.

```css
div {
  transform: matrix(1, -0.3, 0, 1, 0, 0);
}
```

## خلاصة تحويلات الإمالة والمصفوفات في CSS

خلاصة درس تحويلات Skew و Matrix ودورها في تصميم واجهات الويب العصرية.

- إتقان دوال skewX و skewY و skew
- فهم تركيب واستخدام دالة matrix
- تحسين المظهر البصري لعناصر صفحات الويب
- تطبيق الأمثلة والتدريب المستمر بمدونة الكود
