# تأثيرات الصور في CSS

المصدر: https://www.w3schools.com/css/css3_images_effects.asp

## مقدمة حول تأثيرات الصور

مرحبا بكم في درس تأثيرات الصور باستخدام CSS، حيث سنتعلم التحكم في شفافية العناصر.

- تأثيرات الصور تعزز من تجربة المستخدم
- خاصية opacity تتحكم في شفافية العناصر
- تطبيق التأثيرات مباشرة على عناصر img

## مفهوم خاصية opacity

خاصية opacity تحدد شفافية العنصر بقيم تتراوح من 0.0 إلى 1.0.

## تطبيق الكود العملي

نستخدم الكود التالي لتطبيق شفافية بنسبة 50 على جميع الصور.

```css
img {
  opacity: 0.5;
}
```

## معاينة النتيجة

تظهر الصور بشفافية مخفضة عند تطبيق الكود، مما يضيف لمسة جمالية.

```text
Image appearance: 50% transparency
Visual effect: Semi-transparent image
Browser rendering: Applied to all img elements
```

## تأثيرات إضافية باستخدام filter

يمكن استخدام خاصية filter لإضافة تأثيرات بصرية متقدمة مثل التمويه وتشبع الألوان.

- استخدام filter للتمويه (blur)
- تعديل تشبع الألوان (saturation)
- دمج تأثيرات متعددة في سطر واحد

## أفضل الممارسات

نصيحة: جربوا قيم opacity مختلفة لتحسين تجربة المستخدم في تصميمكم.

- اختبار التباين لضمان وضوح المحتوى
- استخدام أدوات المطورين في المتصفح
- التأكد من توافق التأثيرات مع مختلف المتصفحات

## خلاصة الدرس

تعلمنا اليوم أساسيات شفافية الصور. جربوا الأكواد بأنفسكم عبر الروابط المرفقة.

- تم شرح خاصية opacity
- تم توضيح قيم الشفافية
- تم عرض مثال عملي للصور
- تمت الإشارة لخاصية filter المتقدمة
