# CSS Image Hover Effects and Responsive Galleries

المصدر: https://www.w3schools.com/css/css3_images_hover.asp

## مقدمة في تأثيرات الصور

مرحبا بكم في درس جديد من دورة CSS. سنتعلم اليوم كيفية إضافة تأثيرات جمالية على الصور عند تمرير الفأرة، وكيف نبني معارض صور متجاوبة مع مختلف أحجام الشاشات.

- إنشاء تأثيرات Overlay احترافية
- استخدام CSS لتحويل الصور
- بناء معارض صور متجاوبة Responsive

## مفهوم الـ Hover Overlay

تعتمد فكرة الـ Overlay على إظهار محتوى إضافي فوق الصورة عند حدوث حدث الـ hover. يمكننا استخدام خصائص CSS مثل opacity أو transform لخلق تجربة مستخدم تفاعلية ومميزة.

- استخدام pseudo-class المسمى :hover
- التحكم في الشفافية عبر opacity
- استخدام الانتقالات عبر transition

## قلب الصور باستخدام transform

لقلب الصورة أفقيا، نستخدم خاصية transform مع الدالة scaleX. عند ضبط القيمة على سالب واحد، تنعكس الصورة تلقائيا عند تمرير الفأرة عليها.

```css
img:hover {
  transform: scaleX(-1);
}
```

## بناء معرض صور متجاوب

لجعل معرض الصور متجاوبا، نستخدم media queries. هذه التقنية تسمح لنا بتغيير عرض العناصر بناء على عرض الشاشة، مما يضمن ظهور الصور بشكل مناسب على الهواتف والحواسيب.

```css
@media only screen and (max-width: 768px) {
  div.gallery-item {
    width: calc(50% - 20px);
  }
}
```

## تخصيص العرض للشاشات الصغيرة

عندما تصل الشاشة إلى عرض 480px، نقوم بتعديل العرض ليصبح 100. هذا يعني أن كل صورة ستأخذ سطرا كاملا لتسهيل التصفح على الهواتف.

```css
@media only screen and (max-width: 480px) {
  div.gallery-item {
    width: calc(100% - 20px);
  }
}
```

## أفضل الممارسات

يجب دائما استخدام transition مع تأثيرات الـ hover لجعل الحركة سلسة وغير مفاجئة. كما يفضل اختبار المعرض على متصفحات مختلفة لضمان توافق الأكواد.

- استخدام transition لضمان سلاسة الحركة
- اختبار التجاوب عبر أدوات المطورين
- الحفاظ على تنظيم ملفات CSS
