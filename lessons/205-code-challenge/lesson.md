# CSS Image Styling Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_images.asp

## مقدمة في تحدي تنسيق الصور

مرحبا بكم في درس تحدي تنسيق الصور باستخدام CSS.

- التعرف على تحديات CSS
- تطبيق مهارات تنسيق الصور
- تحسين تجربة المستخدم عبر CSS

## المفاهيم الأساسية لتنسيق الصور

نستخدم خصائص CSS مثل width و height و border للتحكم في مظهر الصور.

- استخدام width و height للتحكم في الحجم
- إضافة border لتحديد إطار الصورة
- التحكم في الشفافية عبر خاصية opacity

## كود تنسيق الصورة الأساسي

مثال برمجي لتنسيق صورة باستخدام CSS.

```css
img {
  width: 300px;
  height: auto;
  border-radius: 8px;
  box-shadow: 0 4px 8px rgba(0,0,0,0.2);
}
```

## شرح تفصيلي للخصائص

شرح تأثير border-radius و box-shadow على مظهر الصورة.

- border-radius: 8px لجعل الزوايا مستديرة
- box-shadow: لإضافة تأثير الظل
- تحسين التباين البصري للصورة

## معاينة النتيجة

النتيجة النهائية تظهر صورة بتصميم عصري وجذاب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <img src="image.jpg" alt="CSS Image">
    <!-- النتيجة: صورة بزوايا مستديرة وظل -->
  </body>
</html>
```

## أفضل الممارسات

أفضل الممارسات تشمل تحسين الصور وإمكانية الوصول.

- استخدام alt attribute للصور
- تحسين حجم الملف لسرعة التحميل
- التأكد من توافق التصميم مع الشاشات

## خلاصة الدرس

شكرا لمتابعتكم، استمروا في ممارسة مهارات CSS.

- تمت تغطية أساسيات تنسيق الصور
- تم شرح خصائص CSS المهمة
- شجعنا على الممارسة العملية
