# CSS Image Centering Challenge

المصدر: https://www.w3schools.com/css/css_challenges_imagecenter.asp

## مقدمة حول توسيط الصور

مرحبا بكم في درس اليوم حول تقنيات توسيط الصور باستخدام CSS.

- توسيط الصور يعزز من جمالية التصميم
- نستخدم CSS للتحكم في تموضع العناصر
- تحدي اليوم يختبر قدرتك على تطبيق هذه المفاهيم

## القواعد الأساسية للتوسيط

لتحويل الصورة إلى عنصر block نستخدم خاصية display، ثم نستخدم margin auto للتوسيط.

- الصورة الافتراضية هي inline
- يجب تغيير display إلى block
- ضبط margin-left و margin-right على auto

## كود CSS لتوسيط الصورة

هذا هو الكود البرمجي الأساسي لتوسيط الصورة باستخدام CSS.

```css
img {
  display: block;
  margin-left: auto;
  margin-right: auto;
  width: 50%;
}
```

## شرح تفصيلي للخصائص

شرح وظيفة display و margin في عملية التوسيط.

- display: block تمنع العناصر المجاورة من الاصطفاف
- margin: auto توزع الهوامش تلقائيا
- width: 50 تحدد عرض الصورة بالنسبة للحاوية

## معاينة النتيجة

النتيجة النهائية: الصورة تظهر في منتصف الصفحة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <!-- النتيجة المرئية -->
    <img src="image.jpg" alt="Centered Image">
    /* النتيجة: الصورة في المنتصف */
  </body>
</html>
```

## أفضل الممارسات

نصيحة: تأكد دائما من تحديد عرض الصورة عند توسيطها.

- تحديد width ضروري لنجاح التوسيط
- استخدم وحدات قياس مرنة مثل النسبة المئوية
- اختبر التصميم على مختلف أحجام الشاشات

## خلاصة الدرس

شكرا لمتابعتكم، جربوا الكود بأنفسكم عبر الرابط.

- تم شرح تقنية display: block
- تم شرح استخدام margin: auto
- تم توضيح أهمية تحديد العرض
- شجعنا على التطبيق العملي
