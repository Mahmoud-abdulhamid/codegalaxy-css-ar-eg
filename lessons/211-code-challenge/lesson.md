# CSS Image Filters Challenge

المصدر: https://www.w3schools.com/css/css_challenges_imagefilters.asp

## مقدمة في CSS Image Filters

مرحبا بكم في درس CSS Image Filters حيث سنتعلم كيفية تحسين صور الويب برمجيا.

- تعريف CSS Image Filters
- أهمية الفلاتر في تصميم الويب
- الاستعداد لتنفيذ التحدي البرمجي

## مفاهيم أساسية في الفلاتر

تستخدم خاصية filter دوالا مثل blur و brightness للتحكم في مظهر العناصر.

- استخدام خاصية filter
- دالة blur للتمويه
- دالة brightness للسطوع
- دالة contrast للتباين

## كود تطبيق الفلاتر

تطبيق فلتر grayscale على عنصر img لتحويله إلى الأبيض والأسود.

```css
img {
  filter: grayscale(100%);
}
img:hover {
  filter: none;
}
```

## شرح تفصيلي للكود

شرح استخدام hover لإلغاء الفلتر عند التفاعل مع الصورة.

- تحديد img كعنصر مستهدف
- تطبيق فلتر grayscale
- استخدام hover للتفاعل
- إعادة الفلتر إلى none

## معاينة المخرجات

المعاينة: الصورة تظهر باللون الرمادي وتعود لألوانها الأصلية عند التفاعل.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <img src="nature.jpg" alt="Nature">
    <!-- النتيجة: صورة رمادية تتحول للألوان -->
  </body>
</html>
```

## أفضل الممارسات

استخدام transition يجعل تأثير الفلاتر أكثر احترافية ونعومة.

- إضافة transition للنعومة
- مراعاة توافق المتصفحات
- اختبار الأداء عند استخدام فلاتر متعددة

## خلاصة الدرس

خلاصة: CSS Filters أداة قوية لتحسين التصميم. جربوا دالات أخرى مثل sepia.

- مراجعة ما تم تعلمه
- تشجيع على التجربة الذاتية
- رابط التحدي في الوصف
