# CSS Image Shapes

المصدر: https://www.w3schools.com/css/css3_image_shapes.asp

## مقدمة قص الصور في CSS

مرحبا بكم في درس تشكيل وقص الصور باستخدام CSS وصياغة الأشكال الهندسية.

- قص الصور إلى دوائر وأشكال بيضاوية
- استخدام خواص الديكور الهندسي الحديثة
- التحكم الكامل في مظهر عناصر الويب

## خاصية clip-path والدالة circle()

تتيح خاصية clip-path قص العناصر، وتحدد الدالة circle() نصف القطر للدائرة.

```css
img {
  clip-path: circle(50%);
}
```

## تحديد مركز الدائرة ومركز القص

يمكن تحديد مركز الدائرة باستخدام القيم أو الكلمات مثل right وleft.

```css
img {
  clip-path: circle(50% at right);
}
```

## استخدام clip-path مع ellipse()

تستخدم الدالة ellipse() لإنشاء شكل بيضاوي بنصف قطري المحورين x وy.

```css
img {
  clip-path: ellipse(50% 35%);
}
```

## تحديد مركز الشكل البيضاوي

يمكن تحديد مركز الشكل البيضاوي باتجاه اليمين باستخدام تعبير at right.

```css
img {
  clip-path: ellipse(50% 35% at right);
}
```

## التعامل مع الدالة polygon()

تسمح الدالة polygon() بإنشاء أشكال مضلعة عبر تحديد إحداثيات النقاط.

```css
img {
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}
```

## توجيه النصوص مع shape-outside

تستخدم خاصية shape-outside لتلتف النصوص حول الشكل الهندسي للصورة.

```css
img {
  float: left;
  clip-path: circle(40%);
  shape-outside: circle(45%);
}
```

## خلاصة الدرس والدعوة للتجربة

بهذا نكون قد أتمنا دراسة قص الصور الهندسية وتشكيل النصوص بنجاح تام.

- استخدام clip-path لأنماط القص المختلفة
- تطبيق circle و ellipse و polygon
- تنسيق التفاف النصوص بـ shape-outside
