# CSS object-fit Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_objectfit.asp

## مقدمة حول CSS object-fit

مرحبا بكم في درس CSS object-fit حيث سنتعلم التحكم في مظهر الصور داخل صفحات الويب.

- خاصية object-fit تحدد كيفية ملاءمة الصورة داخل صندوقها
- تساعد في الحفاظ على تناسق التصميم
- تمنع تشوه الصور عند تغيير أبعادها

## مفاهيم object-fit الأساسية

تتحكم خاصية object-fit في كيفية ملاءمة العناصر المستبدلة مثل img داخل الحاويات.

- القيمة fill: هي القيمة الافتراضية وتؤدي لتمدد الصورة
- القيمة contain: تجعل الصورة تظهر كاملة مع الحفاظ على النسبة
- القيمة cover: تملأ الحاوية بالكامل مع قص الأطراف الزائدة

## تطبيق عملي على الكود

نستخدم object-fit: cover لملء الحاوية مع الحفاظ على نسبة أبعاد الصورة.

```css
img {
  width: 300px;
  height: 200px;
  object-fit: cover;
}
```

## شرح تفصيلي للقيم

الفرق الجوهري بين cover وcontain في التعامل مع مساحة الحاوية.

## معاينة المخرجات

تظهر الصورة بشكل متناسق داخل الحاوية بعد تطبيق التنسيق.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <img src="image.jpg" alt="Example">
    </div>
  </body>
</html>
```

## أفضل الممارسات

استخدم object-position مع object-fit للتحكم في نقطة التركيز.

- استخدم object-position للتحكم في نقطة التركيز
- اختبر التصميم على شاشات بأحجام مختلفة
- تأكد من توافق المتصفحات مع الخاصية
