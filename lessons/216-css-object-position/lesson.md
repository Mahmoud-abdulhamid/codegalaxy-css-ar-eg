# شرح خاصية object-position في CSS بالتفصيل

المصدر: https://www.w3schools.com/css/css3_object-position.asp

## مقدمة عن خصائص الويب والتحكم في العناصر المرئية

مرحبا بكم في درس جديد حول خاصية object-position في CSS للتحكم في موضع الصور والفيديوهات.

- نتعرف اليوم على خاصية object-position في CSS
- نستخدم الخاصية مع object-fit لتحديد الموضع بدقة
- التحكم في إحداثيات الصور والفيديوهات داخل عناصر الويب

## دور خاصية object-position مع إحداثيات x و y

تستخدم object-position مع object-fit لتحديد موضع عناصر الصور والفيديوهات باستخدام إحداثيات x و y.

- تحديد كيفية تمركز العناصر داخل الحاوية
- القيمة الأولى تتحكم في المحور الأفقي x
- القيمة الثانية تتحكم في المحور الرأسي y

## أنواع القيم المستخدمة ووحدات القياس

تقبل الخاصية قيم نصية مثل center أو أرقام بوحدات px والنسب المئوية، بالإضافة إلى القيم السالبة.

- قبول قيم نصية مثل left و center و right
- استخدام وحدات القياس مثل البكسل px والنسب المئوية
- إمكانية استخدام القيم السالبة لتحريك العناصر بحرية

## كتابة الكود البرمجي لتحديد حجم الحاوية والخصائص

نكتب كود CSS لتحديد أبعاد حاوية الصور بـ 200 بكسل عرضا و300 بكسل ارتفاعا.

```css
.image-container {
  width: 200px;
  height: 300px;
  border: 1px solid black;
}
.image-container img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

## استخدام خاصية object-position بنسب مئوية دقيقة

نستخدم object-position بقيم 80 للمحور الأفقي و100 للمحور الرأسي لإبراز المعلم المطلوب.

```css
.image-container img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: 80% 100%;
}
```

## تطبيق مثال إضافي لتغيير الموضع بنسبة أخرى

مثال إضافي لتغيير الموضع باستخدام قيم 15 و100 لعرض جزء مختلف من الصورة.

```css
.image-container img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: 15% 100%;
}
```

## خلاصة الدرس وأفضل الممارسات البرمجية

خلاصة الدرس: استخدم object-position للتحكم الكامل بموضع العناصر وجرب مختلف القيم.

- التحكم الكامل في موضع الصور والفيديوهات
- ضرورة استخدام الخاصية مع object-fit
- تجربة النسب المختلفة للوصول للتصميم المثالي
