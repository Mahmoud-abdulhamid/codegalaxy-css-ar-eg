# احتراف تقنية CSS Masking وتخصيص طبقات الأقنعة

المصدر: https://www.w3schools.com/css/css3_masking.asp

## مقدمة في تقنية CSS Masking

تعلم كيفية استخدام تقنية CSS Masking لإخفاء أو إظهار أجزاء من العناصر في صفحة الويب.

- تسمح تقنية CSS Masking بإنشاء طبقات أقنعة فوق العناصر
- يمكن إخفاء أو إظهار أجزاء محددة من أي عنصر مرئي
- تدعم التقنية صور PNG و SVG وتدرجات الألوان

## خاصية mask-image وقنوات الشفافية

تعتمد خاصية mask-image على قنوات الشفافية أو السطوع لتحديد الأجزاء المرئية والمخفية.

- خاصية mask-image تحدد صورة طبقة القناع للعنصر
- المناطق الشفافة في القناع تخفي أجزاء العنصر المقابلة
- المناطق المعتمة أو غير الشفافة تبقي محتوى العنصر ظاهرا

## استخدام صور PNG كقناع بدون تكرار

تطبيق صورة PNG كقناع باستخدام url ومع إيقاف التكرار عبر no-repeat.

```css
.mask1 {
  -webkit-mask-image: url(w3logo.png);
  mask-image: url(w3logo.png);
  mask-repeat: no-repeat;
}
```

## تكرار طبقة القناع أفقيا وعموديا

عند إغفال خاصية mask-repeat تتكرر صورة القناع على كامل مساحة العنصر.

```css
.mask1 {
  -webkit-mask-image: url(w3logo.png);
  mask-image: url(w3logo.png);
}
```

## تحديد موضع طبقة القناع mask-position

استخدام خاصية mask-position لضبط موضع القناع في المنتصف بدقة.

```css
.mask1 {
  -webkit-mask-image: url(w3logo.png);
  mask-image: url(w3logo.png);
  mask-repeat: no-repeat;
  mask-position: center;
}
```

ملخص أهم الممارسات لاستخدام بادئات المتصفحات وضمان التوافقية في CSS Masking.

- استخدام بادئة -webkit-mask-image لدعم متصفحات Chrome وسفاري القديمة والحديثة
- دمج الخصائص في قواعد CSS واضحة ونظيفة للصيانة السريعة
- تجربة الأكواد بأنفسكم عبر روابط المصادر المرفقة بالأسفل
