# CSS Button Hover Effects

المصدر: https://www.w3schools.com/css/css3_buttons_hover.asp

## مقدمة في تأثيرات الأزرار

سنتعلم اليوم كيفية تحسين تجربة المستخدم عبر إضافة تأثيرات جمالية للأزرار مثل تأثير الحركة عند التحويم، وإضافة الظلال، وتحديد حالة التعطيل، وتنسيق العرض.

- تأثيرات التحويم باستخدام :hover
- إضافة الظلال باستخدام box-shadow
- تنسيق الأزرار المعطلة باستخدام opacity
- التحكم في عرض الأزرار باستخدام width

## تأثير التحويم باستخدام :hover

نستخدم pseudo-class التي تسمى :hover لتغيير شكل الزر عند مرور مؤشر الفأرة فوقه، ونستخدم transition-duration لتحديد سرعة التأثير.

```css
.button {
  transition-duration: 0.4s;
}
.button:hover {
  background-color: #4CAF50;
  color: white;
}
```

## إضافة الظلال للأزرار

نستخدم خاصية box-shadow لإضافة عمق للأزرار، ويمكن تطبيق الظل بشكل دائم أو عند التحويم لإعطاء انطباع بارتفاع الزر.

```css
.button1 {
  box-shadow: 0 8px 16px 0 rgba(0,0,0,0.6);
}
.button2:hover {
  box-shadow: 0 8px 16px 0 rgba(0,0,0,0.6);
}
```

## حالة الأزرار المعطلة

نستخدم opacity لتقليل الشفافية و cursor مع القيمة not-allowed لإظهار الزر كمعطل وإعطاء إشارة للمستخدم.

```css
.disabledbtn {
  opacity: 0.6;
  cursor: not-allowed;
}
```

## التحكم في عرض الأزرار

يحدد عرض الزر افتراضيا بناء على النص، ويمكننا استخدام width لتحديد عرض ثابت بالبكسل أو عرض مرن بالنسبة المئوية.

```css
.button1 {
  width: 250px;
}
.button2 {
  width: 50%;
}
.button3 {
  width: 100%;
}
```

## خلاصة الدرس

تعلمنا كيفية جعل الأزرار أكثر تفاعلية وجمالية. جربوا هذه الخصائص في مشاريعكم لتحسين تصميم واجهات الويب.

- استخدام :hover للتفاعل
- تطبيق الظلال بـ box-shadow
- إدارة حالة التعطيل بـ opacity
- التحكم في العرض بـ width
