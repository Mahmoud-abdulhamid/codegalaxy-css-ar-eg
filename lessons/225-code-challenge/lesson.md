# CSS Buttons Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_buttons.asp

## مقدمة في تحدي CSS Buttons

مرحبا بكم في درس تحدي CSS Buttons لتطوير مهارات تصميم الأزرار في صفحات الويب.

- أهمية الأزرار في تجربة المستخدم
- استخدام CSS لتخصيص مظهر العناصر
- تطبيق تحدي CSS Buttons العملي

## القواعد الأساسية لتنسيق الأزرار

تعتمد الأزرار في CSS على خصائص مثل background-color وpadding وborder مع تأثيرات hover.

- استخدام background-color للون الخلفية
- ضبط padding لتحديد المساحة الداخلية
- تخصيص border لإطار الزر
- إضافة تأثيرات تفاعلية عبر hover

## هيكل الكود البرمجي للأزرار

هيكل الكود يتضمن عنصر button في HTML وتنسيقات CSS المقابلة له.

```css
.button {
  background-color: #4CAF50;
  border: none;
  color: white;
  padding: 15px 32px;
  text-align: center;
  display: inline-block;
  font-size: 16px;
}
```

## إضافة تأثير التفاعل hover

نستخدم pseudo-class المسماة hover لتغيير مظهر الزر عند مرور الفأرة.

```css
.button:hover {
  background-color: #45a049;
  cursor: pointer;
}
```

## معاينة النتيجة في المتصفح

معاينة الزر في المتصفح تظهر التفاعل السلس عند مرور الفأرة.

- الزر يظهر بلون أخضر ثابت
- تغير اللون عند التفاعل
- سهولة الاستخدام والتفاعل

## أفضل الممارسات البرمجية

أفضل الممارسات تشمل تنظيم الكود واستخدام أسماء فئات واضحة وتجربة أحجام متنوعة.

- استخدام أسماء Classes معبرة
- الحفاظ على تناسق الألوان
- تجربة التصميم على شاشات مختلفة

## خلاصة الدرس

تعلمنا تصميم الأزرار بـ CSS. جرب الكود بنفسك عبر الرابط في الوصف.

- تم تغطية أساسيات CSS Buttons
- شرح تأثير hover التفاعلي
- دعوة للتطبيق العملي عبر الرابط
