# CSS Multiple Columns Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_columns.asp

## مقدمة في CSS Multiple Columns

مرحبا بكم في درس CSS Multiple Columns حيث سنتعلم تقسيم النصوص إلى أعمدة متعددة لتحسين تجربة المستخدم.

- تنسيق النصوص في أعمدة متعددة
- تحسين قابلية القراءة في صفحات الويب
- استخدام خصائص CSS الحديثة
- تطبيق تحديات برمجية عملية

## الخصائص الأساسية للأعمدة

نستخدم خاصية column-count لتحديد عدد الأعمدة و column-gap للتحكم في المسافة الفاصلة بينها.

## كتابة كود الأعمدة

نطبق خصائص الأعمدة على عنصر div مع تحديد عدد الأعمدة والمسافة الفاصلة بينها.

```css
.newspaper {
  column-count: 3;
  column-gap: 40px;
  column-rule: 1px solid lightblue;
}
```

## هيكل HTML المرتبط

نضع النص داخل عنصر div ليتم توزيعه تلقائيا على الأعمدة المحددة في ملف CSS.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="newspaper">
      <p>هذا نص طويل سيتم توزيعه
        على ثلاثة أعمدة بفضل CSS
        Multiple Columns.</p>
    </div>
  </body>
</html>
```

## معاينة النتيجة

تظهر النتيجة في المتصفح كنص مقسم إلى ثلاثة أعمدة متناسقة مع مسافات فاصلة واضحة.

```text
عمود 1 | عمود 2 | عمود 3
نص طويل | نص طويل | نص طويل
موزع بدقة | موزع بدقة | موزع بدقة
```

## أفضل الممارسات

استخدم Media Queries لضبط عدد الأعمدة بما يتناسب مع أحجام الشاشات المختلفة.

- استخدام Media Queries للتجاوب
- اختيار عرض مناسب للـ column-gap
- اختبار التصميم على متصفحات مختلفة
- تجنب كثرة الأعمدة في الشاشات الصغيرة

## خلاصة الدرس

تعلمنا اليوم أساسيات CSS Multiple Columns. جربوا الأكواد بأنفسكم عبر الرابط في الوصف لتطوير مهاراتكم.
