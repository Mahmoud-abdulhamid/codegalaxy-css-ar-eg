# CSS Variables Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_css3_variables.asp

## مقدمة تحدي المتغيرات في CSS

مرحبا بكم في هذا التدريب العملي لتقييم مهاراتكم في لغة CSS وتطبيق CSS Variables.

- اختبار الفهم العملي لمتغيرات CSS
- تطبيق القواعد البرمجية الصحيحة
- تحسين بنية ورقة الأنماط

## فهم متطلبات التحدي البرمجي

يتطلب منا هذا التحدي اختبار الفهم الشامل لقواعد CSS Variables وتعريف المتغيرات في النطاق العام.

- تحديد نطاق المتغيرات داخل selector مناسب
- استخدام الرمز المزدوج للشرطة لدفق المتغيرات
- ربط القيم بالعناصر المرئية بكفاءة عالية

## كتابة هيكل الكود الأساسي للمتغيرات

نبدأ كتابة الأكواد بتعريف المتغيرات داخل root واستدعائها باستخدام دالة var داخل الخصائص.

```css
:root {
  --main-bg-color: #2b2b2b;
  --main-text-color: #ffffff;
}
body {
  background-color: var(--main-bg-color);
  color: var(--main-text-color);
}
```

## استكمال وتفصيل الأكواد البرمجية

نتابع كتابة بقية الأكواد لتخصيص الحاويات والأزرار وتوحيد مظهر صفحة الويب.

```css
.container {
  background-color: var(--main-bg-color);
  padding: 20px;
}
.btn {
  background-color: var(--main-text-color);
  color: var(--main-bg-color);
  border: none;
  padding: 10px 20px;
}
```

## معاينة وتحليل المخرجات البرمجية

ننتقل لمشاهدة النتيجة النهائية وظهور العناصر متناسقة في متصفح الويب.

- توافق تام في الألوان عبر العناصر
- استجابة سريعة لتغيير قيم المتغيرات العامة
- تجربة مستخدم منظمة ونظيفة

## أمثلة إضافية وتطبيقات متقدمة

عرض مثال إضافي حول إعادة تعيين المتغيرات داخل عناصر فرعية لتغيير الثيمات بسهولة.

```css
.dark-theme {
  --main-bg-color: #000000;
  --main-text-color: #00ff00;
}
.card {
  background-color: var(--main-bg-color);
  color: var(--main-text-color);
}
```

## أفضل الممارسات البرمجية والملاحظات

عند العمل بـ CSS Variables احرص دائما على اختيار أسماء دلالية ووضعها في root.

- استخدام أسماء واضحة وموثوقة للمتغيرات
- الاعتماد على root لتعريف النطاق العام
- تجنب التكرار المفرط للقيم الثابتة

## خلاصة الدرس ودعوة للتطبيق العملي

في ختام الدرس أتممنا التحدي البرمجي بنجاح ونلتقي في الدرس القادم مع المدرب محمود عبدالحميد.

- إتمام التحدي البرمجي بنجاح تام
- مراجعة الأمثلة وتطبيقها عمليا
