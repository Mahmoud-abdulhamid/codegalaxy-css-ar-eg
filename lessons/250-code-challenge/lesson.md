# CSS Flex Container Challenge

المصدر: https://www.w3schools.com/css/css_challenges_flexbox_container.asp

## مقدمة في Flex Container

مرحبا بكم في درس جديد من دورة CSS. اليوم سنتقن مفهوم Flex Container وكيفية استخدامه لبناء تصاميم مرنة ومتجاوبة لصفحات الويب.

- Flexbox هو نموذج تنسيق قوي في CSS
- يسمح بتوزيع العناصر داخل الحاويات بمرونة
- يستخدم Flex Container لتنظيم العناصر
- يسهل محاذاة العناصر أفقيا وعموديا

## القواعد الأساسية لـ Flexbox

لتحويل أي Element إلى Flex Container، نستخدم خاصية display بقيمة flex. هذا يفعل نظام التوزيع المرن لجميع العناصر الأبناء داخل هذه الحاوية.

- استخدام display: flex لتفعيل الحاوية
- العناصر الأبناء تصبح Flex Items
- التحكم في المحور الرئيسي عبر flex-direction
- التحكم في المحاذاة عبر justify-content

## هيكل الكود الأساسي

لنقوم بتعريف حاوية div بكلاس معين، ثم نطبق التنسيقات في قسم style. لاحظ كيف نضبط display إلى flex لتفعيل الخصائص.

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 200px;
  background: #f1f1f1;
}
```

## شرح تفصيلي للخصائص

خاصية justify-content تتحكم في توزيع العناصر على المحور الرئيسي، بينما align-items تتحكم في المحور المتعامد. هذه الخصائص هي الأساس لتصميم أي واجهة ويب.

## معاينة النتيجة

عند تطبيق هذه الأكواد، ستجد أن العناصر داخل الـ container قد تمت محاذاتها بدقة في المنتصف. هذا هو الجمال في استخدام Flexbox لتنظيم المحتوى.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <div>Item 1</div>
      <div>Item 2</div>
    </div>
  </body>
</html>
```

## أفضل الممارسات

ينصح دائما بتجربة قيم مختلفة لخاصية flex-direction، مثل row أو column، لفهم كيف يتغير سلوك العناصر. التجربة العملية هي السبيل الأمثل لإتقان هذه المهارة.

- استخدم flex-direction لتغيير اتجاه المحور
- جرب قيم flex-wrap للتحكم في التفاف العناصر
- استخدم gap لإضافة مسافات بين العناصر
- اختبر التصميم على متصفحات مختلفة
