# CSS Flex Items Challenge

المصدر: https://www.w3schools.com/css/css_challenges_flexbox_items.asp

## مقدمة في Flex Items

مرحبا بكم في درس CSS الجديد حول Flex Items وكيفية التحكم في العناصر داخل Flex Container.

- Flexbox يوفر نظام تخطيط مرن
- Flex Items هي العناصر المباشرة داخل Flex Container
- التحكم في المحاذاة والتوزيع
- تطبيق التحديات البرمجية

## مفاهيم Flexbox الأساسية

نستخدم display: flex لتفعيل النظام، وتصبح العناصر المباشرة Flex Items قابلة للتحكم بخصائص مرنة.

- display: flex لتفعيل الحاوية
- flex-grow للتحكم في التمدد
- flex-shrink للتحكم في الانكماش
- flex-basis لتحديد الحجم الأساسي

## هيكل الكود البرمجي

هيكل الكود يوضح كيفية تعريف الحاوية وتطبيق الخصائص على العناصر.

```css
.container {
  display: flex;
}
.item {
  flex: 1;
  padding: 10px;
  background: #f1f1f1;
}
```

## شرح تفصيلي للخصائص

خاصية flex: 1 تجعل العناصر تتوزع بالتساوي داخل الحاوية.

- flex: 1 يوزع المساحة بالتساوي
- تجنب التداخل بين العناصر
- تحسين تجربة المستخدم في الويب
- مرونة عالية في العرض

## معاينة المخرجات

تظهر العناصر بجانب بعضها وتتوزع بالتساوي داخل الحاوية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <div class="item">1</div>
      <div class="item">2</div>
      <div class="item">3</div>
    </div>
  </body>
</html>
```

## أفضل الممارسات

استخدم خاصية gap لإضافة مسافات بين العناصر بدلا من الاعتماد على margin.

- استخدام gap للمسافات
- اختبار التجاوب مع الشاشات
- تجنب القيم الثابتة للعرض
- استخدام Flexbox للترتيب

## خلاصة الدرس

تعلمنا التحكم في Flex Items. جربوا الكود وحلوا التحديات عبر الرابط في الوصف.

- Flexbox أداة قوية للويب
- التطبيق العملي يثبت المعلومة
- راجعوا الرابط لمزيد من التحديات
- شكرا لمتابعتكم
