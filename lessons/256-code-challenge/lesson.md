# مقدمة وتحدي CSS Grid

المصدر: https://www.w3schools.com/css/css_challenges_grid_intro.asp

## مقدمة تحدي CSS Grid

مرحبا بكم في درس اليوم. سنتعرف على تحدي البداية لأسايسات CSS Grid وكيف نختبر مهاراتنا.

- التعرف على أساسيات CSS Grid
- اختبار المهارات عبر تحدي برمجي عملي
- بناء تخطيطات مرنة لصفحات الويب

## مفاهيم أساسيات Grid

يعتد بنظام CSS Grid كأحدث وأقوى أدوات التخطيط في لغة CSS لتقسيم الشاشة بدقة.

- تخطيط ثنائي الأبعاد للأعمدة والصفوف
- توزيع العناصر بمرونة وسهولة فائقة
- التحكم الكامل في المسافات والمحاذاة

## تهيئة ملف CSS Grid

نبدأ بكتابة الشفرة البرمجية وتعريف الحاوية باستخدام display grid لتفعيل النظام.

```css
.grid-container {
  display: grid;
  grid-template-columns: auto auto auto;
  gap: 10px;
}
```

## شرح تفاصيل الخصائص

خاصية grid-template-columns تحدد عدد الأعمدة وعرضها، وخاصية gap تحدد المسافات.

- تحديد الأعمدة باستخدام grid-template-columns
- ضبط المسافات الفاصلة باستخدام خاصية gap
- الحفاظ على تنسيق متناسق لجميع العناصر

## هيكل عناصر HTML للتحدي

ننتقل إلى بناء عناصر HTML بوضع الحاوية الرئيسية وبداخلها العناصر الفرعية.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="grid-container">
      <div class="item">1</div>
      <div class="item">2</div>
      <div class="item">3</div>
    </div>
  </body>
</html>
```

## معاينة المخرجات المرئية

عند تنفيذ الشفرة في المتصفح، نصطف العناصر في ثلاثة أعمدة متساوية بمسافات واضحة.

```text
+-------+ +-------+ +-------+
|   1   | |   2   | |   3   |
+-------+ +-------+ +-------+
```

## أفضل الممارسات البرمجية

احرص دائما على استخدام الوحدات المرنة والنسب المئوية مع Grid وتجنب نسيان display grid.

- استخدام الوحدات المرنة لتصميم متجاوب
- التحقق من صحة تعريف الحاوية الرئيسية
- اختبار التخطيط على مختلف الأجهزة

## خلاصة الدرس والدعوة للتجربة

بهذا نكون أتممنا درس مقدمة وتحدي Grid. ندعوكم لتجربة الأكواد بأنفسكم من الرابط في الوصف.

- إتمام تحدي CSS Grid بنجاح تام
- تجربة الأكواد العملية عبر الرابط أدناه
- انتظرونا في الدروس القادمة من الدورة
