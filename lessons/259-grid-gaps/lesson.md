# CSS Grid Gap

المصدر: https://www.w3schools.com/css/css_grid_gap.asp

## مقدمة عن CSS Grid Gaps

مرحبا بكم في درس CSS Grid Gaps للتعرف على طريقة إضافة المسافات والفراغات بين العناصر في الشبكة.

- تعلم التحكم بالمسافات في CSS Grid
- فهم مفهوم gaps أو gutters
- تحسين المظهر البصري لتصميم صفحات الويب

## ما هي الفراغات في Grid

تسمى المسافات بين الصفوف والأعمدة في الحاوية بـ gaps وتنشأ حصرا بين عناصر الشبكة وليس على الحواف الخارجية.

- المسافات تسمى gaps أو gutters
- تنشأ بين الصفوف والأعمدة داخل الشبكة
- الحجم الافتراضي للفاصل هو صفر

## خاصية column-gap

تحدد خاصية column-gap المسافة الفاصلة بين الأعمدة في الشبكة بدقة وسهولة.

```css
.container {
  display: grid;
  column-gap: 50px;
}
```

## خاصية row-gap

تستخدم خاصية row-gap لتحديد المسافة الفاصلة بين الصفوف في الشبكة بشكل مستقل.

```css
.container {
  display: grid;
  row-gap: 50px;
}
```

## خاصية gap المختصرة بقيمة واحدة

تعتبر خاصية gap اختصارا لخاصيتي row-gap و column-gap وعند إعطاء قيمة واحدة تطبق على الصفوف والأعمدة.

```css
.container {
  display: grid;
  gap: 50px;
}
```

## خاصية gap بقيمتين مختلفتين

إذا تم توفير قيمتين لخاصية gap، فالأولى للصفوف والثانية للأعمدة.

```css
.container {
  display: grid;
  gap: 30px 100px;
}
```

## خلاصة وخاتمة الدرس

خلاصة الدرس: استخدام properties المختلفة للتحكم بالفراغات في CSS Grid بمرونة تامة.

- استخدام column-gap للفراغات الأفقية
- استخدام row-gap للفراغات الرأسية
- استخدام gap كخاصية مختصرة بقيمة أو قيمتين
