# ترتيب عناصر CSS Grid باستخدام خاصية order

المصدر: https://www.w3schools.com/css/css_grid_item_order.asp

## مقدمة عن ترتيب عناصر Grid

مرحبا بكم في درس جديد من دورة CSS لتعلم كيفية ترتيب عناصر Grid.

- نتعلم اليوم كيفية التحكم في الترتيب البصري لعناصر Grid
- استخدام خاصية order لتغيير مكان ظهور العناصر
- التحكم الكامل في تصميم وتخطيط صفحات الويب

## مفهوم الترتيب البصري

العنصر الأول في مصدر HTML لا يجب حتما أن يظهر كأول عنصر داخل الحاوية.

- العنصر الأول في الكود لا يشترط ظهوره أولا
- خاصية order تفصل بين الترتيب البرمجي والترتيب المرئي
- مرونة عالية في توزيع وتصميم العناصر

## كتابة كود order للعناصر الأولى

تطبيق خاصية order على العناصر الأولى بقيم مختلفة.

```css
.item1 {
  order: 3;
}
.item2 {
  order: 6;
}
.item3 {
  order: 1;
}
```

## استكمال كود order لبقية العناصر

استكمال تطبيق خاصية order على باقي العناصر في الشبكة.

```css
.item4 {
  order: 2;
}
.item5 {
  order: 4;
}
.item6 {
  order: 5;
}
```

## معاينة المخرجات والنتيجة المرئية

النتيجة المرئية لترتيب العناصر بناء على قيم order.

```text
Visual Layout Order:
[Item 3] (order: 1)
[Item 4] (order: 2)
[Item 1] (order: 3)
[Item 5] (order: 4)
[Item 6] (order: 5)
[Item 2] (order: 6)
```

## ملاحظات إمكانية الوصول

تنبيه مهم: خاصية order تغير الترتيب البصري فقط ولا تغير الترتيب المنطقي في DOM.

- خاصية order تؤثر على الترتيب البصري فقط
- الترتيب المنطقي في كود HTML يبقى كما هو
- يجب الانتباه لمستخدمي قارئات الشاشة وأدوات المساعدة

## أفضل الممارسات البرمجية

أفضل الممارسات لضمان تجربة مستخدم سليمة ومتوافقة مع معايير الويب.

- تجنب الاختلافات الكبيرة بين الترتيب المرئي والمنطقي
- اختبار الموقع باستخدام لوحة المفاتيح وقارئات الشاشة
- الحفاظ على تجربة مستخدم مريحة لجميع الزوار

## خلاصة الدرس

خلاصة درس ترتيب عناصر CSS Grid باستخدام خاصية order.

- تعلمنا تطبيق خاصية order على عناصر Grid
- فهمنا تأثير الخاصية على الترتيب المرئي والمنطقي
- أهمية مراعاة إمكانية الوصول في تصميم الويب
