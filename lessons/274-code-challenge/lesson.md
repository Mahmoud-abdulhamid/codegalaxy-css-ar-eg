# CSS RWD Viewport Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_rwd_viewport.asp

## مقدمة تحدي Viewport

مرحبا بكم في درس تحدي Viewport ضمن دورة CSS لبناء صفحات الويب المتجاوبة.

- اختبار الفهم العملي لـ viewport meta tag
- بناء صفحات ويب متجاوبة Responsive Web Design
- تحسين تجربة المستخدم على الهواتف المحمولة

## مفاهيم Viewport الأساسية

دور viewport meta tag في التحكم بعرض الصفحة ومستوى التكبير الافتراضي.

- يكتب Tag داخل قسم head في مستند HTML
- يحدد العرض ليتطابق مع عرض الجهاز width=device-width
- يضبط مستوى التكبير الابتدائي بـ initial-scale=1.0

## كتابة هيكل HTML الأساسي

كتابة الهيكل الأساسي لمستند HTML مع تعريف DOCTYPE.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Viewport Challenge</title>
  </head>
  <body>
    <h1>Responsive Web Design</h1>
    <p>This is a viewport challenge page.</p>
  </body>
</html>
```

## أفضل الممارسات البرمجية

أفضل الممارسات لضمان تجاوب صفحات الويب بكفاءة عالية.

- وضع viewport meta tag في جميع صفحات الويب
- التاكد من صحة القيم width و initial-scale
- اختبار التجاوب عبر Web Browser Developer Tools
