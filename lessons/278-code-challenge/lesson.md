# CSS Media Queries Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_rwd_mediaqueries.asp

## مقدمة حول Media Queries

مرحبا بكم في درس جديد من دورة CSS. اليوم سنعزز مهاراتنا في Responsive Web Design من خلال حل تحدي Media Queries، وهي أداة جوهرية لتكيف صفحة الويب مع مختلف الأجهزة.

- تعد Media Queries حجر الأساس في Responsive Web Design
- تسمح بتطبيق أنماط CSS مختلفة بناء على خصائص الجهاز
- تضمن تجربة مستخدم مثالية على الهواتف والحواسيب
- تحدي اليوم يختبر قدرتك على كتابة هذه القواعد

## القواعد الأساسية لـ Media Queries

تعتمد Media Queries على بنية برمجية بسيطة. نستخدم الكلمة المحجوزة media ثم نحدد الشرط، مثل max-width أو min-width، وداخل الأقواس المتعرجة نكتب كود CSS الذي سيتفعل فقط عند تحقق هذا الشرط.

- استخدام media للبدء في تعريف الاستعلام
- تحديد نوع الجهاز أو خصائص الشاشة مثل العرض
- كتابة قواعد CSS داخل الأقواس المتعرجة
- تطبيق التغييرات عند مطابقة الشاشة للشرط

## كتابة كود Media Query

لننظر إلى هذا المثال العملي. نقوم بتعريف التنسيق العام للعنصر، ثم نضيف Media Query لتغيير لون الخلفية أو حجم الخط عندما يكون عرض الشاشة أقل من 600px، وهذا يساعد في تحسين القراءة.

```css
body {
  background-color: lightblue;
}
@media only screen and (max-width: 600px) {
  body {
    background-color: lightcoral;
  }
}
```

## تحليل الكود البرمجي

في هذا الكود، قمنا بتحديد background-color للعنصر body. بعدها، استخدمنا media مع الشرط max-width: 600px. هذا يعني أن التنسيق الجديد سيطبق فقط عندما تكون الشاشة ضيقة، وهي تقنية معيارية في تطوير الويب.

- التنسيق الافتراضي يعمل على جميع الشاشات
- قاعدة media تستهدف الشاشات الصغيرة فقط
- استخدام max-width يحدد الحد الأقصى للعرض
- تغيير الخصائص داخل الاستعلام يغطي التنسيق الأساسي

## معاينة المخرجات

عند فتح هذه الصفحة في Web Browser، سترى خلفية زرقاء على الشاشات الكبيرة. ولكن عند تصغير نافذة المتصفح لتصل إلى 600px أو أقل، سيتحول لون الخلفية تلقائيا إلى اللون المرجاني، وهذا هو سحر Responsive Web Design.

```text
Screen > 600px: Background is lightblue
Screen <= 600px: Background is lightcoral
```

## أفضل الممارسات

يا أصدقائي، نصيحتي لكم هي دائما البدء بتصميم الهواتف أولا، ثم التدرج نحو الشاشات الأكبر. استخدموا min-width للأجهزة الكبيرة، وتأكدوا من تنظيم كود CSS ليكون سهل القراءة والصيانة داخل مشاريعكم البرمجية.

- اتباع نهج Mobile-First في التصميم
- استخدام وحدات قياس مرنة مثل أو rem
- اختبار التصميم على أحجام شاشات مختلفة
- الحفاظ على نظافة الكود وتوثيقه
