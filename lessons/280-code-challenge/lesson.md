# CSS Responsive Images Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_rwd_images.asp

## مقدمة تحدي الصور المتجاوبة

مرحبا بكم في تحدي الصور المتجاوبة Responsive Images ضمن دورة CSS لتطوير الويب.

- اختبار المهارات العملية في Responsive Images
- ضمان توافق الصور مع الشاشات المختلفة
- تطبيق أفضل الممارسات في تصميم الويب

## القواعد الأساسية للصور المتجاوبة

استخدام max-width بقيمة 100 مع height بقيمة auto يجعل الصور مرنة ومتجاوبة.

- خاصية max-width: 100 تمنع خروج الصورة عن حدود الحاوية
- خاصية height: auto تحافظ على أبعاد الصورة الأصلية
- تجنب تشوه الصور عند تغير مقاسات المتصفح

## كتابة هيكل الكود البرمجي

كتابة كود CSS لاستهداف عناصر الصور وتطبيق قواعد Responsive Images.

```css
img {
  max-width: 100%;
  height: auto;
  display: block;
}
```

## شرح تفصيلي لأسطر الكود

تحليل أسطر كود CSS ووظيفة كل خاصية في تحقيق تجاوب مثالي للصورة.

- max-width: 100 تحدد أقصى عرض بنسبة مئوية دقيقة
- height: auto تحافظ على التناسق الهندسي للصورة
- display: block تلغي الفراغات غير المۆرغوبة تحت الصور

## معاينة المخرجات المرئية

معاينة تفاعلية تظهر استجابة الصورة لتغيرات حجم الشاشة والمتصفح بسلاسة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <img src="landscape.jpg" alt="Nature">
    </div>
  </body>
</html>
```

## أفضل الممارسات والنصائح المتقدمة

استخدام عناصر متقدمة مثل picture لتحسين أداء تحميل صفحات الويب.

- استخدام عنصر picture لتحميل صور مخصصة حسب الشاشة
- تحسين سرعة تحميل مواقع الويب للأجهزة الذكية
- تقليل استهلاك بيانات الإنترنت للمستخدمين

## خلاصة الدرس ودعوة للتجربة

خلاصة تحدي الصور المتجاوبة مع دعوة لتطبيق الأكواد وزيارة روابط المصدر.

- إنجاز تحدي Responsive Images في لغة CSS
- فهم خصائص max-width و height المتجاوبة
- تابعونا للمزيد من الدروس العملية مع محمود عبدالحميد
