# Responsive Web Design - Videos in CSS

المصدر: https://www.w3schools.com/css/css_rwd_videos.asp

## مقدمة عن تصميم الفيديو المتجاوب

مرحبا بكم في درس جديد من دورة CSS حول تصميم مقاطع الفيديو المتجاوبة.

- تصميم مقاطع الفيديو المتجاوبة عبر Responsive Web Design
- التعامل مع شاشات الهواتف والأجهزة اللوحية والحواسيب
- تحسين تجربة المستخدم وعرض الوسائط بكفاءة عالية

## استخدام خاصية width مع عناصر الفيديو

إذا تم ضبط خاصية width إلى 100 فإن مشغل الفيديو سيكون متجاوبا ويتغير حجمه.

```css
video {
  width: 100%;
  height: auto;
}
```

## تحليل سلوك خاصية width

لاحظ أن خاصية width قد تمدد الفيديو أكبر من حجمه الأصلي على الشاشات الكبيرة.

- مشغل الفيديو يتمدد مع اتساع الشاشة والحاوية المحيطة
- احتمالية فقدان جزء من جودة العرض إذا تجاوز الحجم الأصلي
- الحاجة الملحة لحل تقني يتحكم في الحد الأقصى للتمدد

## استخدام خاصية max-width كحل مثالي

استخدام خاصية max-width بقيمة 100 هو الحل الأفضل لمنع التمدد المفرط.

```css
video {
  max-width: 100%;
  height: auto;
}
```

## مقارنة السلوك بين width و max-width

عند استخدام max-width يصغر الفيديو عند الحاجة لكنه لا يتكبر فوق حجمه الأصلي.

- خاصية max-width تسمح بانكماش الفيديو على الشاشات الصغيرة
- تمنع بدقة تكبير الفيديو فوق حجمه الطبيعي الأصلي
- تضمن تجربة مرئية عالية الجودة وثابتة للمستخدم

## إضافة فيديو إلى صفحة الويب العملية

نضيف عنصر الفيديو إلى صفحة الويب ليتأقلم مع المساحة المتاحة.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <video controls>
      <source src="movie.mp4" type="video/mp4">
      Your browser does not support video.
    </video>
  </body>
</html>
```

## أهمية خاصية height بقيمة auto

ضبط height على auto يضمن الحفاظ على نسبة الأبعاد الأصلية لفيديو دون تشويه.

- خاصية height: auto ضرورية جدا مع العرض المتجاوب
- تحافظ على نسبة الأبعاد Aspect Ratio وتمنع تشوه الفيديو
- تعتبر ممارسة معيارية أساسية في تطوير واجهات الويب

## خلاصة الدرس وأفضل الممارسات

خلاصة الدرس: استخدم max-width مع height: auto لفيديوهات متجاوبة وعالية الجودة.

- استخدام width: 100 لتمدد الفيديو حسب الحاوية
- استخدام max-width: 100 لمنع التمدد الزائد والحفاظ على الجودة
- دائما اربط التعديل بقيمة height: auto لمنع التشويه المرئي
