# CSS Responsive Videos Code Challenge

المصدر: https://www.w3schools.com/css/css_challenges_rwd_videos.asp

## مقدمة تحدي الفيديوهات المتجاوبة

مرحبا بكم في درس جديد من دورة CSS لتطبيق تحدي Responsive Videos بشكل عملي واحترافي.

- مرحبا بكم في دورة CSS
- موضوع الدرس هو Responsive Videos
- تطبيق تحدي برمجي عملي
- شرح مفصل لجميع القواعد التقنية

## القواعد الأساسية للتحكم في الفيديو

لجعل عناصر video تتجاوب مع الشاشة، نستخدم خاصية max-width بقيمة 100 لمنع تجاوز الحاوية.

- استخدام خاصية max-width مع العنصر video
- ضبط القيمة على 100 بانتظام
- ضمان التكيف التام مع جميع الأجهزة
- منع ظهور أشرطة التمرير الأفقية

## الكود الأساسي لتنسيق الفيديو

نكتب تنسيق CSS الخاص بعنصر video لتحديد العرض الأقصى والارتفاع التلقائي بدقة.

```css
video {
  width: 100%;
  height: auto;
  max-width: 100%;
}
```

## شرح تفصيلي لسطور الكود

تحديد العرض 100 والارتفاع auto يحافظ على أبعاد الفيديو الأصلية أثناء التجاوب.

- تحديد width على 100 للملء الكامل
- ضبط height على auto للمحافظة على الأبعاد
- تأكيد max-width على 100 كحد أقصى
- تجنب تشوه الصورة عند التكبير

## معاينة المخرجات المرئية

تتغير أحجام الفيديو بسلاسة داخل Web Browser عند تغيير حجم النافذة بفضل تنسيق CSS.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div>
      <video controls>
        <source src="movie.mp4" type="video/mp4">
        Your browser does not support video.
      </video>
    </div>
  </body>
</html>
```

## أفضل الممارسات البرمجية

استخدام حاوية div إضافية يساعد في التحكم بدقة أكبر في الأبعاد والمرونة العامة.

- استخدام عناصر div كحاويات رئيسية
- التحكم في العرض الكلي عبر الحاوية
- الحفاظ على نظافة كود CSS
- اختبار التوافقية عبر Chrome و Firefox
