## مقدمة حول محرر CSS Editor

مرحبا بكم في درس محرر CSS Editor وكيفية تعديل أكواد الويب ومعاينتها في متصفح الويب.

- التعرف على محرر CSS Editor المدمج على الويب
- تعديل أكواد HTML و CSS و JavaScript بسهولة
- معاينة النتائج بشكل فوري داخل متصفح الويب

## المفاهيم الأساسية للمحرر وتنسيق الصفحات

يتيح المحرر تجربة تفاعلية فورية عبر زر Try it Yourself لفهم كيفية عمل التنسيقات.

- التجربة التفاعلية الفورية لتنسيق صفحات الويب
- استخدام زر Try it Yourself لاختبار الأكواد
- فهم تأثير خصائص CSS على عناصر HTML المختلفة

## كتابة تنسيق الخلفية والعنوان الرئيسي

نكتب كود CSS لتنسيق خلفية body باللون الأزرق الفاتح وتوسيط عنوان h1 بلون أبيض.

```css
body {
  background-color: lightblue;
}
h1 {
  color: white;
  text-align: center;
}
```

## تنسيق فقرات النص والخطوط

نضيف تنسيق فقرات النص p باستخدام خاصية font-family لتحديد نوع الخط verdana.

```css
p {
  font-family: verdana;
}
```

## معاينة النتيجة في المتصفح

نتيجة المعاينة في المتصفح تظهر خلفية زرقاء فاتحة وعنوانا أبيض في المنتصف.

- خلفية الصفحة تصبح بلون lightblue
- العنوان الرئيسي h1 بلون أبيض وفي المنتصف
- فقرات النص تظهر بنوع الخط verdana المفضل
