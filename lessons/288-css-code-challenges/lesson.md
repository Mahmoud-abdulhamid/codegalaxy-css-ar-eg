## ما هي تحديات الكود؟

تمثل Code Challenges تمارين برمجية تفاعلية حيث تكتبون كود CSS حقيقيا لتحقيق تصميم معين مطلوب.

## آلية عمل التحديات

في كل تحد برمجى، ستواجهون هدفا بصريا واضحا يتطلب كتابة CSS selectors و properties المناسبة لتحقيقه.

- تحديد هدف بصري معين
- كتابة CSS selectors المناسبة
- تطبيق properties للحصول على التصميم

## مثال عملي لتحدي تنسيق زر

مثال لتحدي تنسيق زر: نكتب كود CSS لتعديل background-color وإضافة padding مناسب للعنصر.

```css
button {
  background-color: #4CAF50;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
}
```

## نتيجة تنفيذ الكود

عند كتابة الكود الصحيح، ستظهر النتيجة مباشرة في المتصفح لتوضيح كيفية عمل خصائص CSS بشكل عملي.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <button style="background-color: #4CAF50; color: white; padding: 10px 20px; border: none; border-radius: 4px;">Click Me</button>
  </body>
</html>
```
