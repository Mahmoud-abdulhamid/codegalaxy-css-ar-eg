## مقدمة في استضافة المواقع

مرحبا بكم في درس استضافة مواقع الويب باستخدام HTML و CSS.

- استضافة مواقع الويب عبر منصات متخصصة
- أهمية استخدام HTML و CSS في بناء الهيكل
- التعرف على بيئة العمل السحابية

## الهيكل الأساسي للمستند

الهيكل الأساسي للمستند يبدأ بـ DOCTYPE HTML.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>My Website</title>
  </head>
  <body>
    <h1>Welcome</h1>
    <p>Hello World</p>
  </body>
</html>
```
