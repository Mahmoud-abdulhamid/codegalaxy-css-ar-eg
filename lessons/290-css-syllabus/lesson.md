# مقدمة شاملة ودليل دراسة CSS من W3Schools

المصدر: https://www.w3schools.com/css/css_syllabus.asp

## مقدمة دورة CSS

مرحبا بكم في دورة CSS من W3Schools للتعرف على دليل الدراسة الشامل.

- دورة CSS شاملة ومصممة للمبتدئين
- لا تتطلب أي خبرة برمجية سابقة
- محتوى مقسم لخطوات سهلة ومبسطة

## مخرجات التعلم

تتيح المنهجية المعتمدة فرصة بناء معرفة أساسية قوية في تنسيق الويب.

- اكتساب أساسيات تصميم وتنسيق صفحات الويب
- محتوى محدث باستمرار وفق أحدث المعايير
- توجيه خطوة بخطوة نحو تطبيقك البرمجي الأول

## بيئة العمل التفاعلية

أفضل طريقة لتعلم لغات البرمجة هي التدريب العملي باستخدام محرر Try it Yourself.

- التدريب العملي المباشر مع الأكواد
- استخدام محرر Try it Yourself للتجربة السريعة
- رؤية النتائج الفورية في المتصفح دون تثبيت برامج

## ميزة Spaces السحابية

يتاح لنا نظام Spaces السحابي لبناء واختبار ونشر مواقع الويب الساكنة.

- بيئة Spaces آمنة ومجانية للتطوير السحابي
- دعم كامل للنشر الفوري وشهادات الحماية SSL
- تشغيل مباشر داخل متصفح الويب بكل سهولة

## مثال عملي لكود CSS

لاحظ معي في هذا المثال كيف نقوم بتصميم عنصر body وتحديد لون الخلفية.

```css
body {
  background-color: lightblue;
}
h1 {
  color: white;
  text-align: center;
}
p {
  font-family: verdana;
  font-size: 20px;
}
```

## شرح تفصيلي للأكواد

في كود CSS هذا، قمنا بتغيير لون خلفية الصفحة وتنسيق العناوين والفقرات.

- تغيير خلفية المستند باستخدام background-color
- توسيع العناوين وتغيير لونها بخصائص text-align وcolor
- تخصيص الخطوط وأحجامها باستخدام font-family وfont-size

## شهادات CSS المعتمدة

يقدم الموقع برنامج شهادات مميزا ينطوي على اختبارات نهائية للمطورين.

- برنامج شهادات معتمدة لنهاية المسار التعليمي
- احصل على لقب Certified CSS Developer بعد النجاح
- اختبارات تقييمية تناسب كافة المستويات البرمجية

## خلاصة الدرس والدعوة للتجربة

في الختام، يعتبر هذا الدليل خطوتك الأولى نحو احتراف تنسيق الويب.

- ابدأ رحلة التعلم اليوم مع منهجية W3Schools
- استفد من بيئة Spaces وتدرب على الأكواد
- تابع معنا باقي الدروس لتصبح مطور وب محترفا
