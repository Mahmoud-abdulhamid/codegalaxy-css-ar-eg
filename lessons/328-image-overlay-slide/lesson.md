# تصميم تأثيرات Image Overlay Slide باستخدام CSS

المصدر: https://www.w3schools.com/howto/howto_css_image_overlay_slide.asp

## مقدمة في تأثيرات الصور

مرحبا بكم في درس تصميم تأثيرات Image Overlay Slide باستخدام CSS.

- تأثيرات التراكب تعزز تجربة المستخدم
- نستخدم CSS للتحكم في حركة العناصر
- التأثير يعتمد على خاصية hover
- يمكن التحكم في اتجاه الانزلاق

## المفاهيم الأساسية

نستخدم خاصية position و transition لإنشاء حركة انزلاق سلسة.

- استخدام position: relative للحاوية
- استخدام position: absolute للعنصر المتراكب
- خاصية transition للتحكم في سرعة الحركة
- خاصية overflow: hidden لإخفاء المحتوى الزائد

## هيكلة الكود البرمجي

هيكلة HTML الأساسية للحاوية والعنصر المتراكب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="container">
      <img src="img.jpg" alt="Avatar">
      <div class="overlay">
        <div class="text">Hello World</div>
      </div>
    </div>
  </body>
</html>
```

## تنسيقات CSS

تنسيق CSS للتحكم في حالة الانزلاق عند التفاعل.

```css
.overlay {
  height: 0;
  width: 100%;
  position: absolute;
  top: 0;
  transition: .5s ease;
}
.container:hover .overlay {
  height: 100%;
}
```

## معاينة النتيجة

النتيجة النهائية: انزلاق النص فوق الصورة عند التفاعل.

```text
[ الصورة ]
[ النص يظهر بانزلاق ]
[ عند تحريك الفأرة ]
```

## تغيير اتجاه الانزلاق

يمكن التحكم في اتجاه الانزلاق بتغيير خصائص الموقع.

- الانزلاق من الأعلى: top: 0
- الانزلاق من الأسفل: bottom: 0
- الانزلاق من اليمين: right: 0
- الانزلاق من اليسار: left: 0

## نصائح برمجية

أفضل الممارسات لضمان تجربة مستخدم سلسة.

- استخدم قيم transition مناسبة
- اختبر التوافقية مع المتصفحات
- تأكد من وضوح النص فوق الصورة
- استخدم ألوان تباين عالية

## خلاصة الدرس

شكرا لمتابعتكم، جربوا الأكواد بأنفسكم لتطوير مهاراتكم.

- تعلمنا إنشاء تأثير انزلاق للصور
- فهمنا دور CSS في التفاعلية
- استكشفنا طرق تغيير اتجاه الحركة
- شجعنا على التجربة العملية
