# إضافة تأثيرات بصرية للصور باستخدام CSS Filters

المصدر: https://www.w3schools.com/howto/howto_css_image_effects.asp

## مقدمة حول تأثيرات الصور

مرحبا بكم في درس إضافة تأثيرات بصرية للصور باستخدام CSS Filters.

- تستخدم خاصية filter لإضافة تأثيرات بصرية للعناصر
- يمكن تطبيق التأثيرات على الصور بسهولة
- تساعد هذه التقنية في تحسين تجربة المستخدم البصرية

## مفهوم CSS Filters

تسمح خاصية filter بإضافة تأثيرات بصرية متنوعة للعناصر في صفحات الويب.

- خاصية filter تدعم تأثيرات مثل blur و grayscale
- تطبق التأثيرات على أي Element في الصفحة
- ملاحظة: لا تدعم المتصفحات القديمة مثل Internet Explorer

## تطبيق تأثير Grayscale

استخدام grayscale(100) لتحويل الصور إلى اللونين الأبيض والأسود.

```css
img {
  -webkit-filter: grayscale(100%);
  filter: grayscale(100%);
}
```

## تطبيق تأثير Blur

استخدام blur(5px) لإضافة تأثير الضبابية على الصور.

```css
img {
  -webkit-filter: blur(5px);
  filter: blur(5px);
}
```

## معاينة المخرجات

تظهر النتائج في المتصفح بناء على قيم filter المستخدمة.

```text
Image 1: Black and White (Grayscale)
Image 2: Blurred Effect (5px)
```

## أفضل الممارسات

استخدم البادئات لضمان التوافقية وادمج التأثيرات للحصول على نتائج إبداعية.

- استخدم -webkit-filter لدعم المتصفحات القديمة
- يمكن دمج عدة تأثيرات في سطر واحد
- اختبر التأثيرات على متصفحات مختلفة

## خلاصة الدرس

شكرا لمتابعتكم، جربوا الأكواد بأنفسكم لتطوير مهاراتكم في CSS.

- تمت تغطية خاصية filter
- تم شرح grayscale و blur
- تم التأكيد على أهمية التوافقية
