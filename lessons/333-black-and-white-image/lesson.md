# تصميم صور بالأبيض والأسود باستخدام CSS filter

المصدر: https://www.w3schools.com/howto/howto_css_image_bw.asp

## مقدمة حول تحويل الصور إلى أبيض وأسود

مرحبا بكم في درس تصميم صور بالأبيض والأسود باستخدام لغة CSS وتأثيرات المرشحات.

- التعرف على كيفية تحويل صور الويب إلى أبيض وأسود
- استخدام تأثيرات المرشحات المتقدمة في التصميم
- تحسين المظهر البصري لصفحات الويب باحترافية

## مفهوم خاصية filter و grayscale

تستخدم خاصية CSS filter لتطبيق تأثيرات بصرية مثل grayscale بنسبة مئة بالمئة للتحويل.

- استخدام CSS filter للتحكم بمظهر العناصر
- تطبيق قيمة grayscale(100) لتحويل الصورة بالكامل
- التحكم الكامل بتدرجات الألوان عبر المرشحات

## دعم المتصفحات القديمة عبر webkit-filter

نستخدم البادئة webkit-filter لضمان التوافقية مع إصدارات متصفح Safari القديمة.

```css
img {
  -webkit-filter: grayscale(100%); /* Safari 6.0 - 9.0 */
}
```

## تطبيق خاصية filter القياسية

نكتب خاصية filter القياسية مع قيمة grayscale(100) لتطبيق التأثير على كافة المتصفحات الحديثة.

```css
img {
  -webkit-filter: grayscale(100%); /* Safari 6.0 - 9.0 */
  filter: grayscale(100%);
}
```

## معاينة المخرجات البصرية للكود

تظهر الصورة ملونة في الأصل وتتحول بالكامل إلى درجات الرمادي والأبيض والأسود عند تطبيق الكود.

- الصورة الأصلية تتميز بألوانها الزاهية والحقيقية
- بعد إضافة الكود تتلاشى الألوان وتظهر بتدرج رمادي نقي
- التحويل يحدث برمجيا بالكامل دون تعديل ملف الصورة الأصلي

## نصائح متقدمة لتأثيرات مرشحات الصور

يمكن تعديل النسبة أو دمج عدة مرشحات معا لخلق تأثيرات بصرية متقدمة.

- تغيير النسبة من 0 إلى 100 للتحكم بقوة التدرج
- دمج مرشح grayscale مع brightness أو contrast
- تطبيق التأثير عند تمرير المؤشر عبر hover effect

## خلاصة الدرس ودعوة للتجربة العملية

تعرفنا على استخدام مرشحات CSS لتحويل الصور، ونشجعكم على تجربة الأكواد بأنفسكم.

- استخدام CSS filter لتحويل الصور بكل سهولة
- تطبيق خاصية grayscale لتدرجات الرمادي
- ادعوك لتجربة الكود وزيارة روابط المصدر في الوصف
