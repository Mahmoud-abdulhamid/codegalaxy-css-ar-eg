# Full Page Background Image in CSS

المصدر: https://www.w3schools.com/howto/howto_css_full_page.asp

## مقدمة الدرس

مرحبا بكم في درس جديد لتعلم كيفية إنشاء صورة خلفية تملأ صفحة الويب بالكامل باستخدام CSS.

- تعلم تصميم خلفيات صفحات الويب باحترافية
- استخدام لغة CSS لتنسيق وتغطية إطار المتصفح
- جعل الخلفيات متجاوبة مع مختلف الشاشة

## المفاهيم الأساسية للخلفيات

لضمان تغطية الصورة لنافذة المتصفح بالكامل، يجب تطبيق ارتفاع بنسبة مئة بالمئة على عنصري html و body.

- تطبيق ارتفاع مئة بالمئة على عنصر html
- تطبيق ارتفاع مئة بالمئة على عنصر body
- تهيئة الحاوية لاستيعاب الصورة بالشكل الصحيح

## كتابة كود الـ HTML و CSS الأساسي

نكتب الآن قواعد CSS لتحديد مسار الصورة والارتفاع الكامل لشاشة العرض.

```css
body, html {
  height: 100%;
}
.bg {
  background-image: url("img_girl.jpg");
  height: 100%;
  background-position: center;
  background-repeat: no-repeat;
  background-size: cover;
}
```

## شرح خواص التوسيط والتكبير

نستخدم خصائص التوسيط وعدم التكرار وتغطية المساحة بالكامل للحصول على مظهر مرئي متناسق.

- توسيط الصورة باستخدام background-position center
- منع تكرار الصورة عبر background-repeat no-repeat
- تغطية الشاشة باحترافية عبر background-size cover

## إنشاء خلفية بنصف الصفحة

يمكننا بسهولة إنشاء خلفية لنصف الصفحة فقط من خلال تعديل قيمة الارتفاع إلى خمسين بالمئة.

```css
.bg {
  height: 50%;
}
```

## أفضل الممارسات البرمجية

احرص دائما على التأكد من صحة مسارات الصور وتطبيق الارتفاع الكامل لعنصري html و body.

- التحقق الدائم من مسارات الصور في url
- ضمان تعريف الارتفاع لعنصري html و body معا
- اختبار التصميم على مختلف أحجام الشاشات

## خلاصة الدرس والتطبيقات العملية

تعلمنا في هذا الدرس كيفية تصميم خلفيات صفحات الويب الكاملة والنصفية بأسلوب احترافي وسهل.

- استعراض شامل لتقنيات خلفيات CSS الحديثة
- تطبيق خصائص التوسيط والتغطية والمرونة
- جاهزية الكود للتنفيذ الفوري في مشاريع الويب
