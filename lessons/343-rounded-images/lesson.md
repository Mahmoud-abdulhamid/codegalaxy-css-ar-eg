# تصميم صور دائرية ومستديرة الزوايا باستخدام CSS

المصدر: https://www.w3schools.com/howto/howto_css_rounded_images.asp

## مقدمة الدرس

مرحبا بكم في درس تصميم صور دائرية ومستديرة الزوايا باستخدام CSS.

- أهلا بكم في درس تصميم الصور في CSS
- سنتعلم كيفية تدوير زوايا الصور بطرق احترافية
- تحسين المظهر البصري لصفحات الويب

## المفاهيم والخصائص الأساسية

نستخدم خاصية border-radius لتحديد مدى انحناء زوايا العناصر والسيادة البصرية.

- التعرف على دور property المسمى border-radius
- تغيير انحناء الزوايا للصور والعناصر
- التحكم الكامل في أبعاد التصميم المرئي

## كتابة هيكل HTML للصورة

نكتب عنصر img في لغة HTML مع تحديد مسصر الصورة عبر src وإضافة alt.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <img src="img_avatar.png" alt="Avatar">
  </body>
</html>
```

## تطبيق زوايا مستديرة باستخدام CSS

نستدعي عنصر img في CSS ونطبق عليه border-radius لتدوير الحواف.

```css
img {
  border-radius: 8px;
}
```

## صنع صورة دائرية كاملة

ضبط قيمة border-radius إلى 50 percent سيجعل الصورة دائرية الشكل تماما.

```css
img {
  border-radius: 50%;
}
```

## أفضل الممارسات البرمجية

تأكد من أن الصورة أصلا مربعة الأبعاد لضمان ظهورها بشكل دائري مثالي.

- استخدام أبعاد متساوية للعرض والارتفاع في الصور
- تجنب التشوه البصري عند تطبيق 50 percent
- التحقق من توافق المتصفحات الحديثة مع الخاصية

## خلاصة الدرس

خلاصة الدرس: كيفية استخدام border-radius لتصميم صور دائرية ومستديرة في CSS.

- تعلمنا إنشاء صور مستديرة الزوايا
- تحويل الصور إلى أشكال دائرية باستخدام نسبة 50 percent
- تطبيق الأكواد بكل سهولة واحترافية
