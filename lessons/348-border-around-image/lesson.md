# إضافة إطار للصور باستخدام CSS

المصدر: https://www.w3schools.com/howto/howto_css_border_image.asp

## مقدمة حول تنسيق الصور

مرحبا بكم في درس إضافة إطار للصور باستخدام CSS. سنتعلم اليوم كيفية استخدام خاصية border لتحسين مظهر الصور في صفحات الويب.

- إضافة إطار للصور يعزز من جمالية التصميم
- استخدام CSS للتحكم في خصائص الصور
- خاصية border هي الأداة الأساسية لهذا الغرض

## مفهوم خاصية border

تسمح خاصية border بالتحكم الكامل في حدود العناصر. عند تطبيقها على img Element، يمكننا تحديد السمك والنمط واللون.

- تحديد سمك الإطار (Width)
- تحديد نمط الخط (Style) مثل solid
- تحديد لون الإطار (Color)

## كود CSS لتنسيق الصورة

نستخدم Selector من نوع img لتطبيق التنسيق. القيمة 5px تحدد السمك، وsolid تحدد نمط الخط، و#555 تحدد اللون.

```css
img {
  border: 5px solid #555;
}
```

## تحليل أجزاء الكود

تحليل قيم خاصية border: 5px للسمك، solid للنمط المتصل، و#555 للون الرمادي الداكن.

- 5px: سمك الإطار
- solid: نمط الخط المتصل
- #555: اللون الرمادي

## معاينة النتيجة

تظهر الصورة في المتصفح بإطار رمادي أنيق. هذا التنسيق يبرز الصورة ويجعلها أكثر وضوحا للمستخدم.

```text
[ الصورة محاطة بإطار رمادي سميك ]
[ Border: 5px solid #555 ]
```

## ملاحظات هندسية

نصائح إضافية: جرب تغيير القيم مثل dashed أو زيادة السمك لتصميمات مختلفة. التنسيق الجيد يحسن تجربة المستخدم.

- تجربة أنماط مختلفة مثل dashed أو dotted
- تغيير الألوان باستخدام Hex أو RGB
- استخدام border-radius لتدوير الزوايا

## خلاصة الدرس

تعلمنا اليوم إضافة إطار للصور باستخدام CSS. جربوا الكود بأنفسكم عبر الرابط في الوصف. شكرا لمتابعتكم.

- تم شرح خاصية border
- تم تطبيق الكود على عنصر img
- تم توضيح كيفية تخصيص الإطار
- شكر خاص للمتابعة
