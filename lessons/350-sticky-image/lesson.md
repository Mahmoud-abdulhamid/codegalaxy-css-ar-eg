# دورة CSS - بناء Sticky Image احترافية

المصدر: https://www.w3schools.com/howto/howto_css_image_sticky.asp

## مقدمة الدرس

مرحبا بكم في درس إنشاء Sticky Image باستخدام CSS وتحسين تجربة المستخدم.

- إنشاء عناصر مرئية ثابتة بذكاء
- فهم تأثير التموضع أثناء التمرير
- تطبيق خصائص CSS الحديثة

## مفهوم Sticky Positioning

العنصر ذو position sticky يتبادل بين relative و fixed بناء على موقع التمرير.

- التبديل التلقائي بين relative و fixed
- الاستجابة الفورية لموقع التمرير في الـ viewport
- الثبات في النقطة المحددة مسبقا

## كتابة كود الـ CSS الأساسي

تحديد Selector الصورة وإسناد قيمة sticky لخاصية position.

```css
img.sticky {
  position: sticky;
  top: 0;
}
```

## شرح تفصيلي للخصائص

يجب تحديد قيمة offset واحدة على الأقل مثل top ليعمل التموضع بنجاح.

- أهمية تحديد خاصية top أو left
- التحكم الكامل في مسافة الالتصاق
- ضمان توافق التصميم مع المتصفحات الحديثة

## معاينة المخرجات في المتصفح

معاينة سلوك الصورة الثابتة أثناء التمرير في متصفح الويب.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <div class="content">
      <img src="photo.jpg" class="sticky" alt="Sticky Image">
      <p>محتوى إضافي للتمرير...</p>
    </div>
  </body>
</html>
```

## التوافقية والملاحظات التقنية

ملاحظة حول دعم المتصفحات وعدم عمل الخاصية في الإصدارات القديمة.

- عدم الدعم في Internet Explorer
- مشاكل التوافق مع Edge 15 والإصدارات الأقدم
- أهمية فحص توافق المتصفحات عبر CanIUse

## خلاصة الدرس

خلاصة الدرس ودعوة لتطبيق الأكواد البرمجية ومواصلة التعلم.

- إتقان خاصية position sticky في CSS
- تحسين التفاعل البصري لمواقع الويب
- تجربة الأكواد بأنفسكم عبر روابط المصدر
