# تصميم أزرار تفاعلية باستخدام CSS

المصدر: https://www.w3schools.com/howto/howto_css_animate_buttons.asp

## مقدمة في تحريك الأزرار

مرحبا بكم في درس اليوم. سنتعلم كيفية إضافة تأثيرات حركية مبتكرة للأزرار لتحسين تجربة المستخدم في صفحات الويب.

- تحسين تجربة المستخدم عبر CSS
- إضافة حيوية لعناصر الواجهة
- استخدام خصائص CSS المتقدمة

## تأثير الضغط على الأزرار

نستخدم Pseudo-class المسمى active لإضافة تأثير ضغط عند النقر، مما يعطي انطباعا بأن الزر ينخفض للأسفل.

```css
.button:active {
  transform: translateY(4px);
}
```

## تأثير التمرير بالسهم

يمكننا إضافة سهم يظهر عند التمرير بالفأرة باستخدام Pseudo-element المسمى after مع خاصية transition.

```css
.button span:after {
  content: '\00bb';
  opacity: 0;
  transition: 0.5s;
}
.button:hover span {
  padding-right: 25px;
}
```

## تأثير الـ ripple

تأثير الـ ripple هو أحد أكثر التأثيرات شيوعا، حيث يعتمد على إنشاء دائرة تتوسع من موقع النقر لإضافة لمسة عصرية.

```css
.ripple {
  position: relative;
  overflow: hidden;
}
.ripple:after {
  content: '';
  position: absolute;
  background: #f1f1f1;
}
```

## معاينة المخرجات

عند تطبيق هذه الأكواد، ستتحول الأزرار إلى عناصر تفاعلية حية تستجيب لحركات المستخدم بشكل فوري وسلس.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <button class="button"><span>Click Me</span></button>
  </body>
</html>
```

## أفضل الممارسات

يجب الحرص على عدم تأثير الحركات على أداء الصفحة، واستخدام transition بحكمة لضمان بقاء الأزرار واضحة وسهلة الاستخدام.

- الحفاظ على سلاسة الأداء
- تجربة الأزرار عبر متصفحات مختلفة
- التركيز على سهولة الوصول

## خاتمة الدرس

أتممنا درس اليوم، أدعوكم لتجربة الأكواد وتعديلها، وزيارة الروابط في الوصف للتعمق أكثر في عالم CSS.

- راجع الأكواد من الرابط المرفق
- طبق التأثيرات في مشروعك الخاص
- تابع الدورة لمزيد من المهارات
