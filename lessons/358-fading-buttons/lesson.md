# تصميم أزرار متلاشية باستخدام CSS

المصدر: https://www.w3schools.com/howto/howto_css_fading_buttons.asp

## مقدمة حول الأزرار المتلاشية

مرحبا بكم في درس تصميم Fading Buttons باستخدام CSS.

- تستخدم CSS لتحسين تجربة المستخدم
- تأثيرات التلاشي تعتمد على خاصية opacity
- تفاعل hover يغير مظهر الزر عند مرور الفأرة

## المفاهيم الأساسية للتلاشي

نستخدم خاصية opacity للتحكم في الشفافية و transition للانتقال السلس.

- opacity: 1 تعني العنصر معتم تماما
- opacity: 0.5 تعني العنصر شبه شفاف
- transition: 0.3s يحدد مدة زمنية للانتقال

## كود CSS للأزرار المتلاشية

كود CSS لتطبيق تأثير التلاشي عند مرور الفأرة.

```css
.button {
  opacity: 0.6;
  transition: 0.3s;
}
.button:hover {
  opacity: 1;
}
```

## هيكل HTML للزر

هيكل HTML بسيط لاستخدام كلاس button.

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
  </head>
  <body>
    <button class="button">اضغط هنا</button>
  </body>
</html>
```

## معاينة النتيجة

النتيجة: الزر يتلاشى ويظهر بوضوح عند التفاعل.

```text
الحالة العادية: الزر شفاف (opacity: 0.6)
الحالة عند hover: الزر معتم (opacity: 1)
الانتقال: سلس خلال 0.3 ثانية
```

## أفضل الممارسات

نصيحة: استخدم قيم زمنية قصيرة لضمان سرعة استجابة الموقع.

- استخدم 0.3s إلى 0.5s كقيمة مثالية
- اختبر التفاعل على متصفحات مختلفة
- تأكد من وضوح النص داخل الزر دائما

## خاتمة الدرس

شكرا لمتابعتكم، جربوا الأكواد بأنفسكم الآن.

- راجعوا الرابط في الوصف للتطبيق العملي
- استمروا في التدريب على خصائص CSS
- نلتقي في الدرس القادم
